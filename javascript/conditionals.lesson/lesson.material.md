# Условное ветвление: if и ?

Программа редко идёт по одной дорожке: в зависимости от данных нужно выполнить один кусок кода или другой. В JavaScript для этого есть оператор `if` и «вопросительный» тернарный оператор `?:`. После урока вы сможете выбирать между ветками, понимать, какие значения считаются «истиной», и не путать условие с присваиванием.

## Оператор if

Конструкция `if (условие) инструкция` вычисляет условие, приводит результат к логическому типу и, если получилось `true`, выполняет инструкцию:

```js
const year = 2024;

if (year === 2024) {
  console.log('Високосный год'); // Високосный год
}
```

Если действий несколько, их заключают в фигурные скобки. Скобки можно опустить, когда инструкция одна, но делать так не стоит: при добавлении второй строки легко забыть скобки и получить ошибку.

```js
const n = 0;

if (n > 0)
  console.log('a'); // не выполнится
  console.log('b'); // выполнится всегда: это уже не часть if

console.log('c');
// b
// c
```

Отступ здесь обманывает глаз: к `if` относится только первая инструкция. Поэтому рекомендуется всегда писать `{ }`, даже для одной строки.

## Приведение к логическому типу

В круглых скобках может стоять любое выражение, не только сравнение. Результат преобразуется в `boolean` по простым правилам.

**Ложными (falsy)** считаются ровно шесть значений:

- `0` (а также `-0`) и `0n` (BigInt-ноль);
- пустая строка `''`;
- `null`;
- `undefined`;
- `NaN`.

(Формально есть ещё `document.all` в браузерах — историческая странность, в Node.js её нет.) Всё остальное — **истинное (truthy)**, включая вещи, которые выглядят «пустыми»:

```js
console.log(Boolean('0'));   // true  — непустая строка
console.log(Boolean(' '));   // true  — пробел тоже символ
console.log(Boolean('false')); // true — это просто текст
console.log(Boolean([]));    // true  — пустой массив это объект
console.log(Boolean({}));    // true
console.log(Boolean(NaN));   // false
```

Поэтому `if ('0')` сработает, а `if (0)` — нет:

```js
if ('0') console.log('строка "0" — истина'); // строка "0" — истина
if (0) {} else console.log('число 0 — ложь'); // число 0 — ложь
```

Условие не обязательно превращать в `boolean` вручную: `if (x)` и `if (Boolean(x))` или `if (!!x)` работают одинаково. Но полезно помнить, что `if (value)` не отличает `0` и `''` от `undefined`. Если `0` — допустимое значение, проверяйте явно: `if (value !== undefined)`.

## else и else if

Блок `else` выполняется, когда условие ложно:

```js
const age = 16;

if (age >= 18) {
  console.log('совершеннолетний');
} else {
  console.log('несовершеннолетний'); // несовершеннолетний
}
```

Несколько вариантов проверяют цепочкой `else if`. Условия вычисляются сверху вниз, выполняется **первая** ветка с истинным условием, остальные пропускаются. Завершающий `else` необязателен:

```js
const score = 72;
let grade;

if (score >= 90) {
  grade = 'A';
} else if (score >= 70) {
  grade = 'B';
} else if (score >= 50) {
  grade = 'C';
} else {
  grade = 'D';
}

console.log(grade); // B
```

Обратите внимание: во второй проверке не нужно писать `score >= 70 && score < 90`. Если мы дошли до неё, первая ветка уже не подошла, значит `score < 90`. Порядок условий — часть логики: переставьте проверки местами, и все оценки станут `'C'`.

## Тернарный оператор ?:

Когда нужно просто выбрать значение по условию, `if` получается многословным. Оператор `условие ? значение1 : значение2` — выражение, то есть возвращает результат:

```js
const age = 20;
const accessAllowed = age > 18 ? 'можно' : 'нельзя';
console.log(accessAllowed); // можно
```

Он единственный в JavaScript, у которого три операнда, поэтому его называют тернарным. Скобки вокруг условия не обязательны (приоритет `?:` низкий, сравнение вычислится раньше), но с ними код читается лучше.

Операторы можно выстраивать в цепочку — это аналог `else if`:

```js
const age = 40;
const label = age < 3 ? 'младенец'
  : age < 18 ? 'ребёнок'
  : age < 100 ? 'взрослый'
  : 'долгожитель';
console.log(label); // взрослый
```

Каждая строка начинается с `:` и читается как «иначе, если…». Цепочки из двух-трёх звеньев допустимы; длиннее — лучше `if/else if` или таблица соответствий.

Тернарный оператор требует обе ветки: вариант `условие ? значение` без `: …` — синтаксическая ошибка. Нужна «пустая» ветка — подставьте `null` или `undefined`, либо используйте `if`.

### if или ?:

Правило простое: `?:` — для **вычисления значения**, `if` — для **выполнения действий**. Такой код работает, но вводит читателя в заблуждение:

```js
const isAdmin = true;
isAdmin ? console.log('панель') : console.log('главная'); // панель
```

Здесь результат выражения выброшен, а использован лишь побочный эффект. Запись через `if` честнее. Зато значение удобно сразу вернуть:

```js
function sign(n) {
  return n > 0 ? 1 : n < 0 ? -1 : 0;
}
console.log(sign(-5)); // -1
```

## Типичные ошибки

**Присваивание вместо сравнения.** Одиночный `=` присваивает, а результат присваивания — присвоенное значение, которое тут же приводится к `boolean`:

```js
let a = 1;
if (a = 0) {
  console.log('A');
} else {
  console.log('B'); // B
}
console.log(a); // 0 — переменная изменилась!
```

Хуже того, ошибки нет, и код выглядит правдоподобно. Проверка равенства — `===`.

**Сравнение с `true` или `false`.** Запись `if (x == true)` вовсе не то же самое, что `if (x)`: при `==` значение `2` будет приведено к числу и сравнено с `1`.

```js
const x = 2;
if (x) console.log('истина');           // истина
if (x == true) {} else console.log('не равно true'); // не равно true
```

**Проверка массива на «пустоту».** `if (arr)` для `[]` истинно. Проверяйте `arr.length`: число `0` ложно, а любое другое — истинно.

```js
const arr = [];
if (arr) console.log('массив — всегда истина'); // массив — всегда истина
if (arr.length) {} else console.log('но он пуст'); // но он пуст
```

**Неверный порядок условий в цепочке.** Если первое условие шире остальных, последующие ветки недостижимы. Идите от частного к общему или от узких диапазонов к широким.

**Забытые скобки у блока.** См. пример выше: без `{ }` в ветку попадает лишь одна инструкция.

## Коротко

- `if` приводит условие к `boolean`; ложны только `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`. Всё прочее, включая `'0'`, `[]`, `{}`, `' '`, — истина.
- В цепочке `if … else if … else` выполняется ровно одна ветка — первая подходящая, поэтому порядок условий важен.
- Всегда ставьте фигурные скобки: без них к `if` относится только одна следующая инструкция.
- Тернарный `условие ? a : b` — выражение, возвращающее значение; обе ветки обязательны. Для действий используйте `if`.
- `=` в условии — присваивание, а не сравнение; сравнивайте через `===`.
- Не сравнивайте с `true`/`false` через `==`: `if (x)` и `x == true` ведут себя по-разному.
