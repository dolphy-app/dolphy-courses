Напишите функцию `fizzBuzz(n)` для целого `n >= 0`:

- если `n` делится и на `3`, и на `5` — верните `'FizzBuzz'`;
- если только на `3` — `'Fizz'`;
- если только на `5` — `'Buzz'`;
- иначе — само число `n`.

```js
fizzBuzz(6);  // 'Fizz'
fizzBuzz(10); // 'Buzz'
fizzBuzz(8);  // 8
```
