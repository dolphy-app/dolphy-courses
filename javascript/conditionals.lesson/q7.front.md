Напишите функцию `describeTemp(t)`, возвращающую строку по температуре `t` в градусах:

- меньше `0` — `'freezing'`;
- от `0` (включительно) до `15` (не включая) — `'cold'`;
- от `15` (включительно) до `25` (не включая) — `'warm'`;
- `25` и выше — `'hot'`.

```js
describeTemp(-5); // 'freezing'
describeTemp(20); // 'warm'
```
