Транспайлер заменяет `value ?? fallback` кодом на старом синтаксисе. Напишите функцию `nullish(value, fallback)`, которая делает то же самое, **не используя** оператор `??`: возвращает `fallback` только если `value` равно `null` или `undefined`, иначе — `value`.

Примеры: `nullish(null, 5)` → `5`, `nullish(0, 5)` → `0`.
