Реализуйте функцию `entriesOf(obj)` — аналог `Object.entries`: она возвращает массив пар `[ключ, значение]` для собственных перечислимых строковых свойств объекта. Использовать `Object.entries` и `Object.values` нельзя — это ваш полифил.

Пример: `entriesOf({ a: 1, b: 2 })` → `[['a', 1], ['b', 2]]`.
