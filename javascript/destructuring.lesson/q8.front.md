Напишите функцию `getCity(user)`: возвращает `user.address.city`. Если адреса нет или города нет (значение `undefined`), вернуть строку `'unknown'`. Значение `null` у города считается заданным и возвращается как есть. Функция не должна падать на пустом объекте.

```js
getCity({ address: { city: 'Омск' } }); // 'Омск'
getCity({});                             // 'unknown'
```
