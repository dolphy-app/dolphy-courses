# Деструктурирующее присваивание

Часто приходится «разбирать» структуру на части: достать из массива первые два элемента, из объекта — несколько полей. Вместо цепочки `const a = arr[0]; const b = arr[1];` в JavaScript есть деструктуризация: левая часть присваивания описывает «форму» данных, и значения раскладываются по переменным автоматически. Приём особенно полезен в параметрах функций, в циклах по `Object.entries` и при работе с вложенными данными.

## Деструктуризация массива

Слева — шаблон в квадратных скобках, справа — любое итерируемое значение. Переменные получают значения по порядку:

```js
const [first, second] = [10, 20, 30];
console.log(first, second); // 10 20
```

Работает не только с массивами, но и с любыми итерируемыми значениями — строками, `Set`, `Map`:

```js
const [c1, c2] = 'hi';
console.log(c1, c2); // h i

const [m1, m2] = new Set([5, 6]);
console.log(m1, m2); // 5 6
```

Исходное значение при этом не меняется — вы лишь копируете из него части.

### Пропуск элементов

Лишние элементы пропускаются запятыми:

```js
const [x, , z] = [1, 2, 3];
console.log(x, z); // 1 3
```

### Остаток `...rest`

Хвост собирается в новый массив. Оператор остатка допустим только последним:

```js
const [head, ...tail] = [1, 2, 3, 4];
console.log(head, tail); // 1 [2, 3, 4]
```

### Значения по умолчанию

Если элемента нет **или он равен `undefined`**, подставляется значение по умолчанию. Оно вычисляется лениво и может ссылаться на предыдущие переменные:

```js
const [a, b = 5] = [1, undefined];
console.log(a, b); // 1 5

const [k1 = 0, k2 = k1 + 1] = [];
console.log(k1, k2); // 0 1
```

Важный нюанс: `null` — это не `undefined`, поэтому умолчание не сработает.

### Обмен значений

Частое применение — поменять переменные местами без временной:

```js
let p = 1;
let q = 2;
[p, q] = [q, p];
console.log(p, q); // 2 1
```

## Деструктуризация объекта

Шаблон в фигурных скобках; переменные берутся **по имени свойства**, порядок не важен:

```js
const user = { name: 'Анна', age: 30, city: 'Омск' };
const { name, age } = user;
console.log(name, age); // Анна 30
```

Можно переименовать переменную (`свойство: переменная`), задать умолчание и всё вместе:

```js
const { name: userName, role = 'guest', age: years = 18 } = { name: 'Борис', age: undefined };
console.log(userName, role, years); // Борис guest 18
```

Остаток собирает не названные свойства в новый объект:

```js
const { title, ...others } = { title: 'T', x: 1, y: 2 };
console.log(title, others); // T { x: 1, y: 2 }
```

Имя свойства можно вычислить: `const { [key]: value } = obj`. Допустимы и индексы: `const { 0: first } = [10, 20]` даст `10`, и свойство `length` у строки: `const { length } = 'abc'` — `3`.

### Присваивание в уже объявленные переменные

Если переменная объявлена заранее, всё выражение берут в круглые скобки, иначе `{` будет воспринят как блок кода:

```js
let u;
({ u } = { u: 7 });
console.log(u); // 7
```

## Вложенные структуры

Шаблон может повторять вложенность данных:

```js
const order = { id: 7, items: [{ sku: 'a1', qty: 2 }, { sku: 'b2', qty: 1 }] };
const { id, items: [{ sku, qty }] } = order;
console.log(id, sku, qty); // 7 a1 2
```

В такой записи имя `items` как переменная не создаётся — это только путь. Если на пути встретится `undefined`, будет ошибка:

```js
// const { a: { b } } = {};
// TypeError: Cannot read properties of undefined (reading 'b')
```

Для необязательных ветвей задавайте умолчание: `const { a: { b } = {} } = {}`.

## Параметры функций

Деструктуризацию можно применить прямо в списке параметров. Это даёт «именованные аргументы»:

```js
function area({ w = 1, h = 2 } = {}) {
  return w * h;
}
console.log(area());         // 2
console.log(area({ w: 5 })); // 10
```

Умолчание `= {}` для всего параметра нужно, чтобы вызов без аргумента не падал: без него попытка разобрать `undefined` вызовет `TypeError`.

## В циклах

Типичная связка с `Object.entries` и `Map`:

```js
for (const [key, value] of new Map([['a', 1]])) {
  console.log(key, value); // a 1
}
```

## Типичные ошибки

> [!WARNING]
>
> - Деструктурировать `null` или `undefined` — всегда `TypeError`.
> - Попытка разобрать объект как массив: `const [x] = {}` — `TypeError`, потому что объект не итерируем.
> - Ожидать, что умолчание сработает для `null` — срабатывает только для `undefined`.
> - Забыть скобки вокруг присваивания в объявленные переменные.
> - Путать порядок: в объекте `{ a: b }` — это «свойство `a` в переменную `b`», а не наоборот.

## Коротко

> [!TIP]
>
> - Массивы разбираются по позиции и по итератору, объекты — по именам свойств.
> - Пропуск — запятые, остаток — `...rest` (всегда последний).
> - Умолчания срабатывают только для `undefined`.
> - Переименование: `{ prop: variable }`; вложенные шаблоны повторяют форму данных.
> - В параметрах функции добавляйте `= {}` для необязательного объекта-аргумента.
> - Деструктуризация копирует ссылки: вложенные объекты остаются теми же.
