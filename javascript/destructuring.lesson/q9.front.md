Напишите функцию `formatProduct`, принимающую один объект-аргумент с полями `title` (обязательно), `price` (по умолчанию `0`) и `tags` (массив, по умолчанию пустой). Деструктурируйте параметры прямо в заголовке. Результат — строка вида `'title: price (tag1, tag2)'`; если тегов нет — без скобок: `'title: price'`. Функция вызывается и без аргументов — тогда `title` не определён и в строке будет `undefined`.

```js
formatProduct({ title: 'Чай', price: 90, tags: ['hot', 'bio'] }); // 'Чай: 90 (hot, bio)'
formatProduct({ title: 'Вода' });                                 // 'Вода: 0'
```
