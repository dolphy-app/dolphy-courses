Напишите функцию `splitFirst(arr)`: возвращает объект `{ first, rest }`, где `first` — первый элемент, `rest` — новый массив из остальных. Для пустого массива `first` равен `undefined`, а `rest` — пустой массив. Используйте деструктуризацию.

```js
splitFirst([1, 2, 3]); // { first: 1, rest: [2, 3] }
```
