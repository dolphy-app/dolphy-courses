Напишите функцию `relativeDays(n)`: она принимает целое число дней относительно сегодня (отрицательное — прошлое) и возвращает английскую фразу, в которой для `-1`, `0`, `1` используются слова, а для остальных — число.

```js
relativeDays(-1); // 'yesterday'
relativeDays(3);  // 'in 3 days'
```
