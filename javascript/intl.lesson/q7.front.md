Напишите функцию `pluralRu(n, forms)`, где `forms` — массив из трёх форм слова `[одна, несколько, много]`. Функция возвращает форму, подходящую к целому числу `n` по правилам русского языка (используйте `Intl.PluralRules`).

```js
pluralRu(1, ['файл', 'файла', 'файлов']);  // 'файл'
pluralRu(3, ['файл', 'файла', 'файлов']);  // 'файла'
pluralRu(11, ['файл', 'файла', 'файлов']); // 'файлов'
```
