JSDoc-комментарий описывает контракт функции так, что тело можно написать, не заглядывая в чужой код. Реализуйте `clamp(value, min, max)` строго по описанию в комментарии заготовки.

```js
clamp(15, 0, 10); // 10
clamp(-4, 0, 10); // 0
clamp(5, 0, 10); // 5
```
