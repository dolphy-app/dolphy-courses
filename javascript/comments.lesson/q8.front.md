Правило високосного года не очевидно из кода, и комментарий над функцией — тот случай, где он по-настоящему нужен. Напишите две функции по комментариям в заготовке:

- `isLeapYear(year)` возвращает `true` для високосного года;
- `daysInMonth(year, month)` возвращает число дней в месяце (`month` от 1 до 12); для другого значения `month` бросает `RangeError`. Использует `isLeapYear`.

```js
isLeapYear(1900); // false
daysInMonth(2024, 2); // 29
```
