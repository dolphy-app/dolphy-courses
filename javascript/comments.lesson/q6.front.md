Вместо комментария «проверяем, является ли число простым» заведите функцию с говорящим именем. Напишите две функции:

- `isPrime(n)` возвращает `true`, если `n` — простое число (больше 1 и делится только на 1 и на себя), иначе `false`;
- `primesBelow(n)` возвращает массив простых чисел **строго меньше** `n` по возрастанию и использует `isPrime`.

```js
isPrime(7); // true
isPrime(1); // false
primesBelow(10); // [2, 3, 5, 7]
```
