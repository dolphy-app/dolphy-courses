Функция `formatPrice(value, currency)` должна вернуть строку: число с двумя знаками после запятой, пробел и код валюты. Но возвращает `undefined`: выражение после `return` перенесено на следующую строку. Исправьте функцию.

```js
formatPrice(10, 'RUB'); // '10.00 RUB'
```
