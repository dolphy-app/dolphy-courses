Функция `countNegatives(values)` должна выводить через `console.log` строку `отрицательное: <число>` **только** для отрицательных чисел и возвращать их количество. Сейчас строка выводится для каждого элемента: код выглядит так, будто вывод относится к `if`, но это не так. Исправьте функцию в духе рекомендованного стиля.

```js
countNegatives([3, -1, -7]);
// выведет: отрицательное: -1
//          отрицательное: -7
// вернёт 2
```
