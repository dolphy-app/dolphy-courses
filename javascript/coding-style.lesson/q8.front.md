Напишите функцию `pow(x, n)`, возводящую `x` в степень `n`. Если `n` не является целым неотрицательным числом, функция бросает `RangeError`. Оформите код по правилам стиля: недопустимый случай обработайте в самом начале и сразу выйдите, а основной сценарий оставьте без лишней вложенности.

```js
pow(2, 10); // 1024
pow(5, 0); // 1
pow(2, -1); // RangeError
```
