Напишите функцию `createThermometer(celsius)`, возвращающую объект с обычным свойством `celsius` и аксессором `fahrenheit`: геттер возвращает температуру в градусах Фаренгейта (`c * 9 / 5 + 32`), сеттер принимает градусы Фаренгейта и обновляет `celsius` (`(f - 32) * 5 / 9`).

```js
const t = createThermometer(100);
t.fahrenheit; // 212
t.fahrenheit = 32;
t.celsius; // 0
```
