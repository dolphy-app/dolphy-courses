Напишите функцию `createUser(name)`. Она возвращает объект со свойством `name` (геттер и сеттер). Сеттер принимает строку и сохраняет её без пробелов по краям; если после обрезки длина меньше 3 символов, бросает `Error`, а прежнее значение остаётся неизменным. Начальное имя тоже должно проходить проверку: `createUser('Ян')` бросает ошибку.
