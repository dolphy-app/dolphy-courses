Напишите функцию `defineComputed(obj, name, fn)`: она добавляет в `obj` перечислимое свойство `name`, которое при каждом чтении возвращает `fn.call(obj)` и не принимает значения (только геттер). Верните `obj`.

```js
const r = defineComputed({ w: 2, h: 5 }, 'area', function () { return this.w * this.h; });
r.area; // 10
r.w = 3;
r.area; // 15
```
