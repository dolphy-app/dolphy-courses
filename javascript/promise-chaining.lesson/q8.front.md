Функция `loadTitle(getUser, getPost)` должна вернуть промис с заголовком поста: `getUser()` возвращает промис с пользователем `{ id }`, а `getPost(id)` — промис с постом `{ title }`. Сейчас цепочка работает неверно. Исправьте функцию, не меняя общую структуру цепочки.
