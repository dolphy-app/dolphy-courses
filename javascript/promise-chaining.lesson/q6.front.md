          const results = [];

            chain = chain

Напишите функцию `sequence(tasks)`. Аргумент `tasks` — массив функций, каждая возвращает промис (или обычное значение). Функция запускает их **по очереди**: следующая стартует только после завершения предыдущей. Результат — промис с массивом результатов в порядке задач. Если одна из задач отклонилась, результат отклоняется той же ошибкой, а оставшиеся задачи не запускаются.
