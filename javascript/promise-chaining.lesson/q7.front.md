Напишите функцию `pipeline(value, steps)`. Она берёт начальное значение `value` и применяет к нему функции из массива `steps` одну за другой: результат каждой передаётся в следующую. Шаги могут быть синхронными или возвращать промис. Функция возвращает промис с итогом. Любое исключение внутри шага должно отклонять результат.

```js
pipeline(2, [(x) => x + 1, (x) => x * 10]).then(console.log); // 30
```
