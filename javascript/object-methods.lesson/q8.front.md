У объекта `account` есть методы `deposit(amount)`, `withdraw(amount)` и `report()` (он выводит `Баланс: <число>`). Измените их так, чтобы вызовы можно было выстраивать в цепочку:

```js
account.deposit(100).deposit(50).withdraw(30).report(); // Баланс: 120
```
