Метод `fullName` привязан к имени переменной `user`, поэтому не работает у других объектов. Исправьте его так, чтобы он брал `first` и `last` у объекта, у которого вызван.

```js
const other = { first: 'Боб', last: 'Смит', fullName: user.fullName };
other.fullName(); // 'Боб Смит'
```
