Создайте объект `rectangle` (константа) с тремя методами:

- `setSize(width, height)` запоминает ширину и высоту в самом объекте;
- `area()` возвращает площадь;
- `perimeter()` возвращает периметр.

```js
rectangle.setSize(3, 4);
rectangle.area();      // 12
rectangle.perimeter(); // 14
```

Методы должны опираться на `this`.
