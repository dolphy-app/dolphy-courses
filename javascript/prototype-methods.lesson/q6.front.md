Напишите функцию `countWords(text)`. Она возвращает объект-словарь «слово → сколько раз встретилось». Слова разделены пробелами, регистр не учитывается. Словарь должен быть создан без прототипа, чтобы слова вроде `constructor` и `__proto__` обрабатывались как обычные ключи.

```js
countWords('a b A'); // { a: 2, b: 1 }
```
