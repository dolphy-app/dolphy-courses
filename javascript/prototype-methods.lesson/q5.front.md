Напишите функцию `cloneFull(obj)`. Она создаёт поверхностную копию объекта с **тем же прототипом**, копируя все собственные свойства, включая неперечислимые, а также геттеры и сеттеры (как есть, без вызова).

```js
const copy = cloneFull(source);
Object.getPrototypeOf(copy) === Object.getPrototypeOf(source); // true
```
