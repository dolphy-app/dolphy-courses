Напишите функцию `createFrom(proto, descriptions)`. Она создаёт объект с прототипом `proto` и добавляет в него **только для чтения** (`writable: false`) перечислимые свойства из `descriptions` (обычный объект «имя → значение»).

```js
const o = createFrom({}, { id: 5 });
o.id; // 5
Object.keys(o); // ['id']
```
Запись в такое свойство должна молча игнорироваться (в нестрогом режиме) и не менять значение.
