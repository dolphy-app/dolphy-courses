Напишите функцию `ownKeysCount(obj, keys)`. Она возвращает, сколько из строк массива `keys` являются **собственными** свойствами `obj`. Функция должна работать и для объектов без прототипа, и для объектов, у которых затёрт метод `hasOwnProperty`.

```js
ownKeysCount({ a: 1, b: 2 }, ['a', 'c', 'toString']); // 1
```
