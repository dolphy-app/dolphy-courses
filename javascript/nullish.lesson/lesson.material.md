# Оператор нулевого слияния ??

Часто нужно взять значение, а если его нет — подставить запасное. Раньше для этого использовали `||`, но он путает «значения нет» и «значение ложное». Оператор `??` и его присваивающая форма `??=` решают именно эту задачу: подставляют запасное значение только там, где данных действительно нет. После урока вы сможете выбирать между `??` и `||`, расставлять скобки и использовать `??=`.

## Что значит «значения нет»

В JavaScript есть два значения, которыми обозначают отсутствие данных: `undefined` (значение не задано) и `null` (значение намеренно пусто). Для краткости назовём значение **определённым**, если оно не `null` и не `undefined`. Всё остальное — `0`, `""`, `false`, `NaN`, пустой массив — определённые значения: они что-то означают.

## Как работает a ?? b

Выражение `a ?? b` возвращает `a`, если `a` определено, и `b` в противном случае:

```js
let user;

console.log(user ?? "Аноним"); // Аноним
user = "Ирина";
console.log(user ?? "Аноним"); // Ирина
```

То же самое можно записать без нового оператора, но длиннее:

```js
const a = null;
const b = "запас";
const result = (a !== null && a !== undefined) ? a : b;
console.log(result); // запас
console.log(a ?? b); // запас
```

Оператор ленивый (как `||` и `&&`): правая часть вычисляется, только если левая не определена. Побочные эффекты справа не произойдут, если запасное значение не понадобилось:

```js
function fallback() {
  console.log("fallback вызвана");
  return 0;
}

console.log(5 ?? fallback()); // 5 (fallback не вызывалась)
console.log(null ?? fallback()); // fallback вызвана, затем 0
```

Операторы можно соединять в цепочку: результатом будет первое определённое значение, а если таких нет — последнее:

```js
const firstName = null;
const lastName = undefined;
const nickName = "coder";

console.log(firstName ?? lastName ?? nickName ?? "Аноним"); // coder
console.log(null ?? undefined); // undefined
console.log(undefined ?? null); // null
```

Обратите внимание на последние две строки: если определённых значений нет, вернётся самое правое, а не «лучшее».

## Отличие от ||

Оператор `||` возвращает первое **истинное** значение, `??` — первое **определённое**. Разница видна на «ложных, но осмысленных» значениях:

```js
const height = 0;

console.log(height || 100); // 100
console.log(height ?? 100); // 0
```

Нулевая высота, пустая строка в поле, `false` в настройке — это нормальные данные, а не отсутствие. Сравним по таблице (что вернёт `x ?? "запас"` и `x || "запас"`):

| `x` | `x \|\| "запас"` | `x ?? "запас"` |
|---|---|---|
| `null` | `"запас"` | `"запас"` |
| `undefined` | `"запас"` | `"запас"` |
| `0` | `"запас"` | `0` |
| `""` | `"запас"` | `""` |
| `false` | `"запас"` | `false` |
| `NaN` | `"запас"` | `NaN` |
| `"текст"` | `"текст"` | `"текст"` |

Типичная область применения `??` — значения по умолчанию для настроек:

```js
const cfg = { port: 0, host: "", debug: false, name: null };

console.log(cfg.port ?? 8080); // 0
console.log(cfg.host ?? "localhost"); // пустая строка (ничего не видно)
console.log(cfg.debug ?? true); // false
console.log(cfg.name ?? "anon"); // anon
console.log(cfg.missing ?? "def"); // def (свойства нет — undefined)
```

Это не значит, что `||` устарел. Если запасное значение нужно и для `0`, и для `""`, и для `false` (например, пустое поле формы считается «не заполненным»), то `||` — правильный выбор. Решает смысл данных, а не мода.

## Приоритет и скобки

У `??` низкий приоритет: ниже арифметики, сравнений и вызовов, но выше `?:` и `=`. Поэтому в составных выражениях нужны скобки:

```js
const height = null;
const width = null;

const area = (height ?? 100) * (width ?? 50);
console.log(area); // 5000
```

Без скобок `*` выполнится раньше, и результат изменится — причём без ошибки, что хуже всего:

```js
const height = null;
const width = null;

console.log(height ?? 100 * width ?? 50); // 0
// читается как height ?? (100 * width) ?? 50
// 100 * null === 0, а 0 — определённое значение
console.log(1 + null ?? 5); // 1
// читается как (1 + null) ?? 5, то есть 1 ?? 5
```

## Запрет на смесь с && и ||

Если в одном выражении без скобок стоят `??` и `&&`/`||`, это синтаксическая ошибка. Авторы стандарта решили, что порядок вычисления тут слишком легко понять неверно:

```js
try {
  eval("1 && 2 ?? 3");
} catch (e) {
  console.log(e.name); // SyntaxError
}

console.log((1 && 2) ?? 3); // 2
console.log(1 && (2 ?? 3)); // 2
```

Ошибка возникает при разборе программы, то есть весь скрипт не запустится — именно поэтому здесь использован `eval`, чтобы показать её. Достаточно поставить скобки вокруг любой из частей. Цепочки только из `??` (как `a ?? b ?? c`) разрешены.

## Оператор присваивания ??=

Выражение `x ??= y` присваивает `x` значение `y` только если `x` не определено. Это сокращение для `x = x ?? y`, но с важным отличием: присваивание происходит только когда нужно, а правая часть не вычисляется, если `x` уже определено:

```js
let userAge = null;
userAge ??= 18;
console.log(userAge); // 18

userAge ??= 21; // userAge уже определена
console.log(userAge); // 18
```

Удобно заполнять отсутствующие поля объекта:

```js
const options = { retries: 0 };

options.retries ??= 3; // 0 остаётся
options.timeout ??= 1000; // поля не было — появится
console.log(options); // { retries: 0, timeout: 1000 }
```

Рядом есть «братья»: `||=` (присвоить, если значение ложное) и `&&=` (присвоить, если значение истинное). Разницу между `??=` и `||=` видно сразу:

```js
let a = 0;
let b = 0;
a ||= 5;
b ??= 5;
console.log(a, b); // 5 0
```

Типичная идиома — счётчик с ленивой инициализацией:

```js
const counts = {};
for (const word of ["да", "нет", "да"]) {
  counts[word] ??= 0;
  counts[word]++;
}
console.log(counts); // { 'да': 2, 'нет': 1 }
```

## Типичные ошибки

> [!WARNING]
>
> - **Заменять `||` на `??` не глядя.** Если пустая строка или `0` должны заменяться запасным значением, `??` их не заменит.
> - **Забывать скобки в `a ?? b + c`.** Сложение выполнится первым, и запасное значение попадёт в сумму не так, как вы думали.
> - **Писать `a || b ?? c`.** Это `SyntaxError`, нужны скобки.
> - **Ждать от `??` проверки на «пустоту».** Он не отличает `""` и `[]` от обычных значений, а `NaN` для него — полноценное значение.
> - **Использовать `??` с необъявленной переменной.** `undeclared ?? 1` даёт `ReferenceError`: оператор проверяет значение, а не существование имени.
> - **Доступ к свойству у `null`.** `null.name ?? "x"` упадёт с `TypeError` до работы `??`: сначала вычисляется левая часть.

## Коротко

> [!TIP]
>
> - `a ?? b` возвращает `a`, если оно не `null` и не `undefined`, иначе `b`; правая часть вычисляется лениво.
> - В отличие от `||`, оператор `??` сохраняет `0`, `""`, `false` и `NaN`.
> - Приоритет `??` низкий, в составных выражениях нужны скобки: `(a ?? 1) * (b ?? 2)`.
> - Смешивать `??` с `&&` и `||` без скобок нельзя — будет `SyntaxError`.
> - `x ??= y` присваивает только при отсутствии значения и не вычисляет `y`, если `x` определена.
