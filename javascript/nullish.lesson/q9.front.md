Напишите функцию `withDefaults(options)`. Она возвращает новый объект с полями `port`, `host` и `debug`. Если поле в `options` отсутствует или равно `null`, берётся значение по умолчанию: `port` — `80`, `host` — `'localhost'`, `debug` — `false`. Любые другие значения (`0`, `''`, `false`) сохраняются. Исходный объект менять нельзя, другие поля в результат не попадают.

```js
withDefaults({ port: 0 }); // { port: 0, host: 'localhost', debug: false }
```
