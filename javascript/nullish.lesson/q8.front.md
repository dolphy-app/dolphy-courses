Функция `area(width, height)` возвращает площадь прямоугольника. Если `width` равна `null` или `undefined`, нужно использовать `50`; если `height` — `100`. Остальные значения, включая `0`, остаются как есть. Исправьте функцию.

```js
area(3, 4);  // 12
area();      // 5000
area(0, 10); // 0
```
