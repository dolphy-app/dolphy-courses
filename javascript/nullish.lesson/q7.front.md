Напишите функцию `firstDefined(...values)`. Она возвращает первый аргумент, который не равен `null` и `undefined`. Если таких аргументов нет (в том числе при вызове без аргументов) — возвращает `undefined`.

```js
firstDefined(null, undefined, 0, 5); // 0
firstDefined(null, undefined);       // undefined
```
