Напишите функцию `initUser(user)`. Она дополняет переданный объект недостающими полями и возвращает его же: `age` — `18`, `role` — `'guest'`, `tags` — пустой массив. Поле считается недостающим, если оно равно `null` или `undefined`; остальные значения (в том числе `0` и `''`) трогать нельзя.

```js
const u = initUser({ name: 'Аня', age: 0 });
// u: { name: 'Аня', age: 0, role: 'guest', tags: [] }
```
