Напишите функцию `createCounter(start = 0)`. Она возвращает объект с тремя методами:

- `up()` — увеличивает счётчик на 1 и возвращает новое значение;
- `down()` — уменьшает на 1 и возвращает новое значение;
- `value()` — возвращает текущее значение, не меняя его.

Текущее значение должно храниться в замыкании, а не в свойстве объекта. Каждый вызов `createCounter` создаёт независимый счётчик.

```js
const c = createCounter(5);
c.up(); // 6
c.value(); // 6
```
