Напишите функцию `memoize(fn)`, где `fn` принимает один аргумент (число или строку). Она возвращает функцию, которая для каждого нового аргумента вызывает `fn` и запоминает результат, а при повторном аргументе возвращает запомненное значение без вызова `fn`.

```js
const slowSquare = (x) => x * x;
const fast = memoize(slowSquare);
fast(4); // 16, fn вызвана
fast(4); // 16, из кэша
```

Учтите: результат может быть `0`, `''` или `undefined` — такие значения тоже нужно кэшировать.
