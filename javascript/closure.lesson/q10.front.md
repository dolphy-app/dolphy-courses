Функция `makeShooters(count)` должна вернуть массив из `count` функций, где функция с индексом `i` при вызове возвращает число `i`. Но сейчас все функции возвращают одно и то же число. Исправьте код.

```js
const shooters = makeShooters(3);
shooters[0](); // 0
shooters[2](); // 2
```
