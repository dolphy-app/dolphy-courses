Напишите функцию `byField(field)`, которая возвращает функцию-компаратор для `arr.sort`. Компаратор сравнивает два объекта по значению поля `field` по возрастанию (числа — как числа, строки — как строки).

```js
users.sort(byField('age')); // по возрасту, от меньшего к большему
users.sort(byField('name')); // по имени
```
