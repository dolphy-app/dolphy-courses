Напишите функцию `once(fn)`. Она возвращает обёртку, которая при первом вызове запускает `fn` (с переданными аргументами) и запоминает результат. Все последующие вызовы обёртки не запускают `fn`, а просто возвращают запомненный результат.

```js
const init = once(() => 42);
init(); // 42 (fn выполнилась)
init(); // 42 (fn не вызывалась)
```
