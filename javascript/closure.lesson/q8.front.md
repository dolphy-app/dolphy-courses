Напишите две функции-фабрики для `arr.filter`:

- `inBetween(from, to)` — возвращает функцию, которая даёт `true` для значений от `from` до `to` **включительно**;
- `inArray(allowed)` — возвращает функцию, которая даёт `true` для значений, входящих в массив `allowed`.

```js
[1, 2, 3, 4, 5, 6, 7].filter(inBetween(3, 6)); // [3, 4, 5, 6]
[1, 2, 3, 4, 5, 6, 7].filter(inArray([1, 2, 10])); // [1, 2]
```
