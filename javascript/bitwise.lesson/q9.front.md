Цвет хранится одним числом `0xRRGGBB`: по 8 бит на каждый канал (0–255).

- `packRgb(r, g, b)` возвращает число с упакованными каналами;
- `unpackRgb(color)` возвращает объект `{ r, g, b }`.

Пример: `packRgb(255, 128, 7)` равно `0xff8007`, а `unpackRgb(0xff8007)` даёт `{ r: 255, g: 128, b: 7 }`.
