Напишите функцию `splitChars(str)`, которая возвращает массив символов строки, причём символы за пределами BMP (например, эмодзи, занимающие два кодовых блока) должны остаться целыми, не разорванными.

```js
splitChars('abc'); // [ 'a', 'b', 'c' ]
splitChars('a😀b'); // [ 'a', '😀', 'b' ]
```
