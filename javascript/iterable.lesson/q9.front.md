Напишите функцию `zip(a, b)`, которая принимает два перебираемых объекта (массивы, строки, множества) и возвращает массив пар `[x, y]`. Длина результата равна длине более короткого из аргументов.

```js
zip([1, 2, 3], ['a', 'b']); // [ [ 1, 'a' ], [ 2, 'b' ] ]
zip('xy', new Set([10, 20])); // [ [ 'x', 10 ], [ 'y', 20 ] ]
```
