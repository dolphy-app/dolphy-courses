Напишите функцию `take(iterable, n)`, которая возвращает массив из первых `n` элементов любого перебираемого объекта (массива, строки, Set, собственного итератора). Если элементов меньше, вернуть все. Функция должна работать и с **бесконечными** последовательностями, поэтому не обходите всё до конца.

```js
take([5, 6, 7, 8], 2); // [ 5, 6 ]
take('hello', 3); // [ 'h', 'e', 'l' ]
```
