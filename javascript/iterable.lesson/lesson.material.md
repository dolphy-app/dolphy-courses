# Перебираемые объекты

Цикл `for...of` умеет обходить не только массивы, но и строки, множества, словари и вообще любые объекты, которые договорились «показывать» свои элементы по одному. Такие объекты называют **перебираемыми** (iterable). В этом уроке вы узнаете, как устроен этот договор, как сделать перебираемым собственный объект и чем перебираемые объекты отличаются от «псевдомассивов».

## Что такое перебираемый объект

Объект считается перебираемым, если у него есть метод с ключом `Symbol.iterator`. Этот метод возвращает **итератор** — объект с методом `next()`. Каждый вызов `next()` возвращает объект вида `{ done, value }`: пока `done` равно `false`, в `value` лежит очередной элемент; когда элементы закончились, приходит `done: true`.

Цикл `for...of` делает именно это: вызывает `obj[Symbol.iterator]()` один раз, а затем вызывает `next()`, пока не получит `done: true`. Вручную то же самое выглядит так:

```js
const it = 'ab'[Symbol.iterator]();
console.log(it.next()); // { value: 'a', done: false }
console.log(it.next()); // { value: 'b', done: false }
console.log(it.next()); // { value: undefined, done: true }
```

Встроенные перебираемые типы: массивы, строки, `Map`, `Set`, типизированные массивы, а также результаты `arr.keys()`, `arr.entries()` и подобных. А вот обычный объект перебираемым не является:

```js
try {
  for (const x of { a: 1 }) {
  }
} catch (e) {
  console.log(e instanceof TypeError); // true — объект не перебираемый
}
```

## Делаем свой объект перебираемым

Создадим диапазон чисел. Метод `Symbol.iterator` возвращает новый итератор при каждом вызове — поэтому диапазон можно обходить хоть сколько раз:

```js
const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() {
        if (current <= last) {
          return { done: false, value: current++ };
        }
        return { done: true, value: undefined };
      },
    };
  },
};

for (const n of range) {
  console.log(n); // 1, 2, 3
}
console.log([...range]); // [ 1, 2, 3 ]
```

Состояние (`current`) хранится в замыкании итератора, а не в самом объекте. Если бы счётчик лежал в `range`, второй обход начинался бы с того места, где закончился первый.

Тот же итератор проще получить с помощью генератора (специальной функции с `function*` и `yield`; подробнее в отдельном уроке про генераторы): метод `*[Symbol.iterator]() { for (...) yield i; }` делает то же самое в нескольких строках.

## Строки и пары символов Unicode

Строка перебирается по настоящим символам, а не по 16-битным частям, из которых хранится в памяти. Поэтому символы вроде эмодзи, занимающие два кодовых блока, цикл `for...of` не разрывает:

```js
const s = 'a\u{1F600}';
console.log(s.length); // 3
console.log([...s].length); // 2
console.log(Array.from(s)); // [ 'a', '😀' ]
```

Метод `s.split('')` режет строку по кодовым блокам и может разорвать такую пару, поэтому для посимвольной работы с текстом надёжнее `Array.from(s)` или `[...s]`.

## Псевдомассивы и Array.from

Не путайте два понятия:

- **перебираемый** — реализует `Symbol.iterator`;
- **псевдомассив** (array-like) — имеет индексы и свойство `length`, но не обязан быть перебираемым.

```js
const arrayLike = { 0: 'a', 1: 'b', length: 2 };
console.log(arrayLike.length); // 2
try {
  [...arrayLike];
} catch (e) {
  console.log(e instanceof TypeError); // true
}
console.log(Array.from(arrayLike)); // [ 'a', 'b' ]
```

`Array.from(obj, mapFn)` принимает и перебираемые объекты, и псевдомассивы и строит из них настоящий массив. Второй аргумент — функция преобразования, что даёт идиому `Array.from({ length: 3 }, (_, i) => i * 2)` → `[0, 2, 4]`. Настоящий массив нужен, чтобы пользоваться `map`, `filter` и другими методами: у псевдомассива их нет.

## Где ещё работают перебираемые объекты

- оператор расширения: `[...iterable]`, `Math.max(...iterable)`;
- деструктуризация: `const [first, second] = iterable`;
- конструкторы `new Set(iterable)`, `new Map(iterable)`;
- `Object.fromEntries(iterable)` — собирает объект из пар;
- `Promise.all(iterable)` и ряд других API.

Для словаря цикл возвращает пары:

```js
const prices = new Map([['tea', 3], ['coffee', 5]]);
for (const [name, price] of prices) {
  console.log(name, price); // tea 3, coffee 5
}
```

## Типичные ошибки

- Применять `for...of` к обычному объекту. Для объекта используйте `Object.keys()`, `Object.values()` или `Object.entries()`.
- Раскрывать псевдомассив через `...`: получится `TypeError`; нужен `Array.from`.
- Хранить состояние итератора в самом перебираемом объекте: повторный обход сломается.
- Забывать, что `Array.from` и `...` пытаются обойти всю последовательность: на бесконечном итераторе они не завершатся.
- Путать `for...in` (ключи) с `for...of` (значения).

## Коротко

- Перебираемый объект имеет метод `Symbol.iterator`, возвращающий итератор с методом `next()`.
- `next()` возвращает `{ done, value }`; цикл заканчивается, когда `done` равно `true`.
- Массивы, строки, `Map` и `Set` перебираемые; обычные объекты — нет.
- Псевдомассив (индексы и `length`) не обязан быть перебираемым; `Array.from` превращает любой из них в массив.
- Строки обходятся по символам Unicode, а не по кодовым блокам.
