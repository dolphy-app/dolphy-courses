Напишите функцию `mergeUnique(a, b)`: она принимает два массива и возвращает **новый** массив из всех элементов обоих, без повторов. Элементы идут в порядке первого появления.

```js
mergeUnique([1, 2, 3], [3, 4, 1]); // [1, 2, 3, 4]
```

Исходные массивы менять нельзя.
