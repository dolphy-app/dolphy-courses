Напишите функцию `withOptions(defaults, options)`, которая возвращает **новый** объект: все свойства `defaults`, поверх которых записаны свойства `options`. Оба аргумента остаются нетронутыми. Вложенные значения копировать не нужно (поверхностной копии достаточно).

```js
withOptions({ theme: 'dark', size: 12 }, { size: 14 }); // { theme: 'dark', size: 14 }
```
