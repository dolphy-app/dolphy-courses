Напишите функцию `minMax(numbers)`: она принимает массив чисел и возвращает массив `[минимум, максимум]`. Для пустого массива верните `null`.

```js
minMax([4, 9, 2, 7]); // [2, 9]
```

Исходный массив менять нельзя.
