# Остаточные параметры и spread

Многоточие `...` в JavaScript делает две противоположные вещи. В **списке параметров** функции оно собирает «лишние» аргументы в массив (rest). В **вызове функции или литерале** оно, наоборот, раскладывает массив или другой перебираемый объект на отдельные элементы (spread). Обе возможности ES2015 избавляют от ручной возни с `arguments`, `slice`, `apply` и `concat`.

## Остаточные параметры (rest)

Функция может принимать любое число аргументов, даже если в определении перечислено меньше параметров. Лишние аргументы можно собрать в настоящий массив:

```js
function sumAll(...numbers) {
  let total = 0;
  for (const n of numbers) total += n;
  return total;
}

console.log(sumAll()); // 0
console.log(sumAll(1, 2, 3)); // 6
```

Rest можно сочетать с обычными параметрами, но он обязан быть **последним** и только **один** на функцию:

```js
function tag(label, ...items) {
  return label + ': ' + items.join(', ');
}

console.log(tag('цвета', 'красный', 'зелёный')); // цвета: красный, зелёный
console.log(tag('пусто')); // пусто:
```

Если лишних аргументов нет, rest-параметр — пустой массив `[]`, а не `undefined`. Запись вроде `function f(...a, b) {}` — синтаксическая ошибка (`SyntaxError`).

Тот же синтаксис работает в деструктуризации: `const [first, ...others] = [1, 2, 3]` даёт `others` равным `[2, 3]`. Там тоже «остаток» должен стоять в конце.

## Устаревший `arguments`

До rest-параметров все аргументы функции доступны в специальном объекте `arguments`. Он **похож на массив** (есть индексы и `length`), но массивом не является: у него нет `map`, `filter` и прочих методов.

```js
function count() {
  return arguments.length;
}
function isArr() {
  return Array.isArray(arguments);
}

console.log(count(10, 20, 30)); // 3
console.log(isArr(1)); // false
```

У стрелочных функций собственного `arguments` нет: внутри них доступен `arguments` внешней обычной функции (если она есть). Поэтому в новом коде для «всех аргументов» берут rest: он настоящий массив, понятен по сигнатуре и работает в стрелках.

## Spread в вызовах

Если данные уже лежат в массиве, а функция ждёт отдельные аргументы, используйте spread вместо `apply`:

```js
const nums = [4, 9, 2];
console.log(Math.max(...nums)); // 9
console.log(Math.max(0, ...nums, 20)); // 20
console.log(Math.max(...[])); // -Infinity
```

Несколько spread и обычных значений можно смешивать в любом порядке. Spread работает не только с массивами, а с любым **перебираемым** (итерируемым) объектом: строкой, `Set`, `Map`.

```js
console.log([...'abc']); // [ 'a', 'b', 'c' ]
console.log([...new Set([1, 1, 2])]); // [ 1, 2 ]
```

Если значение не перебираемое (число, обычный объект), в массиве или вызове получим `TypeError`.

## Spread в литералах

В литерале массива spread заменяет `concat` и `slice`:

```js
const a = [1, 2];
const b = [0, ...a, ...[3, 4]];
const copy = [...a];

console.log(b); // [ 0, 1, 2, 3, 4 ]
console.log(copy === a); // false
```

В литерале **объекта** spread копирует собственные перечисляемые свойства. Если ключи повторяются, побеждает тот, что записан позже. Так делают «обновлённую копию» без изменения оригинала:

```js
const base = { theme: 'dark', size: 12 };
const user = { ...base, size: 14 };

console.log(user); // { theme: 'dark', size: 14 }
console.log(base); // { theme: 'dark', size: 12 }
console.log({ ...{ a: 1 }, ...{ a: 2 } }); // { a: 2 }
console.log({ a: 1, ...{ a: 2 } }); // { a: 2 }
console.log({ ...{ a: 2 }, a: 1 }); // { a: 1 }
```

Spread объекта терпимо относится к `null` и `undefined`: `{ ...null }` даёт `{}`. А вот массив в литерале объекта превращается в объект с ключами-индексами: `{ ...[7, 8] }` — это `{ '0': 7, '1': 8 }`.

## Копия поверхностная

И `[...arr]`, и `{ ...obj }` создают **поверхностную** копию: верхний уровень новый, а вложенные объекты и массивы остаются теми же ссылками.

```js
const original = { name: 'x', tags: ['a'] };
const clone = { ...original };

clone.name = 'y';
clone.tags.push('b');

console.log(original.name); // x
console.log(original.tags); // [ 'a', 'b' ]
```

Если нужна глубокая независимая копия, придётся копировать вложенные уровни отдельно (или использовать `structuredClone` там, где он есть; в среде Node.js 22 это глобальная функция, но в песочнице заданий курса её нет).

## Типичные ошибки

- Rest-параметр не в конце списка — `SyntaxError`.
- Ожидание, что `arguments` — массив: вызов `arguments.map(...)` приведёт к `TypeError`.
- Попытка «склонировать» вложенные данные одним spread: мутация вложенного объекта затронет и оригинал.
- Порядок в `{ ...defaults, ...options }`: значения из `options` перекроют `defaults`, а не наоборот.

## Коротко

- `...` в параметрах собирает остаток аргументов в массив; он должен быть последним.
- `...` в вызове и литерале раскладывает перебираемый объект на элементы.
- `arguments` — устаревший псевдомассив; у стрелок его нет.
- Spread объекта: при совпадении ключей побеждает последний; копия поверхностная.
- `Math.max(...[])` равно `-Infinity`; пустой rest — это `[]`.
