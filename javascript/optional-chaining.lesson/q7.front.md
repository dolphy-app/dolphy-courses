Напишите функцию `callMethod(obj, name, ...args)`. Она вызывает метод `obj[name]` с аргументами `args` и возвращает результат. Если `obj` равен `null`/`undefined` или такого метода нет, возвращается `undefined`. Метод должен выполняться с `this`, равным `obj`.

```js
const o = { k: 2, mul(x) { return this.k * x; } };
callMethod(o, 'mul', 5); // 10
callMethod(o, 'nope');   // undefined
```
