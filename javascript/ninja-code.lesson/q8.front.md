Исправьте `sortedCopy(arr)`: функция должна возвращать новый массив чисел, отсортированный по возрастанию, и не изменять переданный массив.

```js
const src = [3, 1, 2];
sortedCopy(src); // [1, 2, 3]
src;             // [3, 1, 2]
```
