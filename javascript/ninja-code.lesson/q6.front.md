Перепишите функцию `normalizeIndex(index, length)` без вложенных тернарных операторов. Правила:

- если `index` ложно (`0`, `NaN`, `undefined`), вернуть `0`;
- если `index` отрицательный, вернуть `Math.max(0, length + index)`;
- иначе вернуть `index` без изменений.

Примеры: `normalizeIndex(-2, 5)` → `3`, `normalizeIndex(4, 5)` → `4`.
