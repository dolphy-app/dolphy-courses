Напишите генератор `flatten(array)`, который отдаёт все элементы вложенного массива «плоско», в порядке обхода слева направо. Вложенность произвольной глубины. Не-массивы (в том числе строки) отдаются как есть, строку на символы разбирать не нужно.

```js
[...flatten([1, [2, [3]], 4])]; // [1, 2, 3, 4]
[...flatten(['ab', ['c']])];    // ['ab', 'c']
```
