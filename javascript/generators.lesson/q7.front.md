Напишите бесконечный генератор `pseudoRandom(seed)` — линейный конгруэнтный генератор. Каждое следующее значение вычисляется из предыдущего по формуле:

```
next = (prev * 48271) % 2147483647
```

Начальное `prev` — это `seed`; само `seed` не отдаётся. Для `seed = 1` последовательность начинается так: `48271, 182605794, 1291394886, ...`.

```js
const g = pseudoRandom(1);
g.next().value; // 48271
g.next().value; // 182605794
```
