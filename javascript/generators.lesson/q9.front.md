Напишите генератор `runningAverage()`, работающий как «скользящее среднее» через двусторонний `yield`: внешний код передаёт числа через `next(x)`, а в ответ получает среднее арифметическое всех чисел, переданных с начала.

Первый вызов `next()` без аргумента только запускает генератор; его результат не важен.

```js
const g = runningAverage();
g.next();             // запуск
g.next(10).value;     // 10
g.next(20).value;     // 15
g.next(30).value;     // 20
```
