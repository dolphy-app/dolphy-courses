Напишите генератор `take(iterable, count)`, который отдаёт первые `count` значений из любого итерируемого объекта и завершается. Источник может быть бесконечным.

```js
function* naturals() {
  let n = 1;
  while (true) yield n++;
}

[...take(naturals(), 3)]; // [1, 2, 3]
[...take('hello', 2)];    // ['h', 'e']
```

Не запрашивайте у источника больше значений, чем нужно: при `count = 0` не должно быть ни одного обращения к нему.
