Напишите функцию `tagObject(obj, tag)`: она записывает `tag` в свойство объекта с ключом-символом из глобального реестра `Symbol.for("app.tag")` и возвращает тот же объект. Строковые ключи объекта изменяться не должны.

```js
const o = tagObject({ a: 1 }, "x");
o[Symbol.for("app.tag")]; // "x"
Object.keys(o);           // ["a"]
```
