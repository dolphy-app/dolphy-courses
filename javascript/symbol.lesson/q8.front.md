Напишите функцию `symbolNames(obj)`: она возвращает массив описаний (`description`) всех собственных символьных ключей объекта в порядке их добавления. Строковые ключи игнорируются.

```js
const o = { a: 1, [Symbol("x")]: 2, [Symbol("y")]: 3 };
symbolNames(o); // ["x", "y"]
```
