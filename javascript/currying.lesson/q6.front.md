Напишите `partial(fn, ...preset)`: функцию, которая возвращает новую функцию. При вызове новая функция передаёт в `fn` сначала аргументы `preset`, затем собственные.

```js
const add3 = partial((a, b, c) => a + b + c, 1, 2);
add3(10); // 13
```
