Напишите функцию `curry(fn)`, которая возвращает каррированную версию `fn`. Число нужных аргументов определяйте по `fn.length`.
Результат должен принимать аргументы любыми порциями: `c(1)(2)(3)`, `c(1, 2)(3)`, `c(1)(2, 3)` и `c(1, 2, 3)` дают одно и то же.
Контекст `this` при вызове должен сохраняться.
