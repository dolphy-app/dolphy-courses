Напишите каррированную `makeFormatter(prefix)(suffix)(text)`, которая возвращает `prefix + text + suffix` (текст приводится к строке). Каждый шаг должен возвращать функцию, пригодную для повторного использования.

```js
const bracket = makeFormatter('[')(']');
bracket('ok'); // '[ok]'
```
