Напишите функцию `build(params, body)`: `params` — массив имён параметров, `body` — строка с **выражением**, которое надо вернуть. Результат — новая функция с этими параметрами.

```js
const add = build(['a', 'b'], 'a + b');
add(2, 3); // 5
build([], '42')(); // 42
```
