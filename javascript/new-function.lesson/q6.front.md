Напишите функцию `compile(expr)`. Она принимает строку с арифметическим выражением от переменной `x` и возвращает функцию одного аргумента `x`, вычисляющую это выражение. Используйте `new Function`.

```js
const f = compile('x * 2 + 1');
f(5); // 11
```
