Напишите функцию `invert(obj)`: возвращает новый объект, в котором ключи и значения поменялись местами. Если значения повторяются, остаётся ключ, встретившийся позже.

```js
invert({ a: 'x', b: 'y' }); // { x: 'a', y: 'b' }
```
