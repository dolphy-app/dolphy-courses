          let best = null;
          let max = -Infinity;
          for (const [key, value] of Object.entries(obj)) {
            if (value > max) {
              max = value;
              best = key;
            }
          }
          return best;

Напишите функцию `topKey(obj)`: возвращает имя свойства с наибольшим числовым значением. Для пустого объекта вернуть `null`. Если максимум у нескольких — вернуть первое по порядку `Object.keys`.

```js
topKey({ ann: 90, bob: 120, eva: 70 }); // 'bob'
```
