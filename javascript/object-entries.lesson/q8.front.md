Напишите функцию `mapValues(obj, fn)`: возвращает **новый** объект с теми же ключами, где каждое значение заменено на `fn(value, key)`. Исходный объект не меняется.

```js
mapValues({ a: 1, b: 2 }, (v) => v * 10); // { a: 10, b: 20 }
```
