Напишите функцию `createCache(makeRef)`. Она возвращает объект с методом `get(key, create)`.

- `makeRef(value)` — фабрика слабых ссылок: возвращает объект с методом `deref()` (в реальном коде — `v => new WeakRef(v)`). Используйте только её.
- `get` возвращает живое закэшированное значение по ключу; если записи нет или `deref()` вернул `undefined`, вызывает `create(key)`, сохраняет ссылку на результат и возвращает его.
- Пока значение живо, `create` повторно не вызывается.
