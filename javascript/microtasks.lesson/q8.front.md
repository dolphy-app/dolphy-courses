Функция `getValue(cache, key, callback)` берёт значение из `cache` или, если его там нет, «вычисляет» его асинхронно (`key.toUpperCase()`), кладёт в кэш и передаёт в колбэк. Сейчас значение из кэша передаётся **синхронно**, и поведение функции непредсказуемо. Исправьте её так, чтобы колбэк **всегда** вызывался асинхронно. Для колбэка из кэша достаточно микрозадачи.
