            function next() {

Длинная обработка в одной задаче блокирует таймеры. Напишите функцию `processInChunks(items, size, worker)`: она вызывает `worker(item)` для всех элементов по порядку, но не более `size` штук подряд, а между порциями уступает управление через `setTimeout(..., 0)` (микрозадачи для этого не годятся: они блокируют таймеры).

- Первая порция обрабатывается синхронно при вызове.
- Функция возвращает промис, который выполняется после обработки всех элементов.
- Исключение, брошенное `worker`, отклоняет промис, обработка прекращается.
