# Переменные

Программе нужно где-то хранить данные: цену товара, имя пользователя, результат вычисления. Для этого служат **переменные** — именованные ячейки памяти. После урока вы сможете объявлять переменные, выбирать между `let` и `const` и придумывать понятные имена.

## Объявление: let

Переменную объявляют ключевым словом `let`, а значение записывают оператором присваивания `=`:

```js
let message;
message = 'Привет';
console.log(message); // Привет
```

Объявление и присваивание можно объединить, а несколько переменных — перечислить через запятую (но отдельные строки читать проще):

```js
let price = 120, count = 3;
console.log(price * count); // 360
```

Переменная без значения содержит особое значение `undefined`:

```js
let empty;
console.log(empty); // undefined
```

Значение можно менять сколько угодно раз, причём новое значение может быть другого типа — JavaScript это допускает (язык с динамической типизацией):

```js
let data = 5;
data = 'пять';
console.log(data); // пять
```

При копировании примитивного значения из одной переменной в другую создаётся независимая копия:

```js
let first = 10;
let second = first;
first = 20;
console.log(second); // 10
```

Объявить одну переменную дважды в одной области видимости нельзя — это синтаксическая ошибка:

```js
let user = 'Аня';
let user = 'Борис'; // SyntaxError: Identifier 'user' has already been declared
```

## Константы: const

Если значение не должно меняться, объявляйте переменную через `const`. Попытка присвоить новое значение — ошибка, а объявление без значения невозможно:

```js
const maxUsers = 100;
maxUsers = 200; // TypeError: Assignment to constant variable.
```

```js
const empty; // SyntaxError: Missing initializer in const declaration
```

Важная тонкость: `const` запрещает **переприсваивание**, но не делает значение неизменяемым. Объект, на который указывает константа, можно менять:

```js
const config = { debug: false };
config.debug = true;
console.log(config); // { debug: true }
```

Практическое правило: по умолчанию пишите `const`, а `let` берите только когда значение действительно будет переприсваиваться. Тогда по коду видно, что именно меняется.

Для значений, известных заранее и «зашитых» в программу, принято писать имена заглавными буквами с подчёркиваниями: `const MAX_RETRIES = 3;`. Для значений, которые вычисляются во время работы (например, ответ сервера), используют обычные имена в `camelCase`.

## Правила для имён

- Имя состоит из букв (в том числе не латинских), цифр и символов `$` и `_`.
- Первый символ — не цифра.
- Регистр важен: `age` и `Age` — разные переменные.
- Нельзя использовать зарезервированные слова (`let`, `new`, `class`, `return` и другие).

```js
let $ = 1, _ = 2, имя = 'Аня', π = 3.14;
console.log($ + _, имя, π); // 3 Аня 3.14
let 1st = 1;   // SyntaxError: Invalid or unexpected token
let my-name;   // SyntaxError: Unexpected token '-'
```

Русские буквы в именах допустимы, но делать так не стоит: в коде принят английский язык, чтобы его могли прочитать и поддерживать другие разработчики.

### Как выбирать имена

- Название должно говорить о содержимом: `userName`, `cartTotal`, `isActive`.
- Избегайте общих слов (`data`, `value`, `temp`), если можно быть точнее.
- Не сокращайте без нужды: `curUsr` хуже, чем `currentUser`.
- Договоритесь в команде о стиле и придерживайтесь его: в JavaScript принят `camelCase`.

## А что же var?

В старом коде встречается `var`. Он похож на `let`, но ведёт себя иначе: допускает повторное объявление, «всплывает» (используется до объявления без ошибки, но со значением `undefined`) и не ограничен блоком `{ }`. Подробнее — в уроках про функции и область видимости, а в новом коде используют `let` и `const`.

```js
console.log(early); // undefined
var early = 1;
```

С `let` то же самое — ошибка, и это полезно: опечатки находятся сразу.

```js
console.log(late);
let late = 1; // ReferenceError: Cannot access 'late' before initialization
```

## Типичные ошибки

- Забыть объявление: `count = 1;` без `let` в строгом режиме — `ReferenceError`, а в обычном — случайная глобальная переменная.
- Объявить `let` дважды в одной области видимости.
- Считать, что `const` делает объект неизменным.
- Использовать `const` для значения, которое потом нужно изменить, а затем «чинить» это через `var`.

## Коротко

- `let` — переменная с изменяемым значением, `const` — не переприсваиваемая.
- Без значения переменная равна `undefined`; у `const` значение обязательно.
- `const` не защищает от изменения содержимого объекта.
- Имя: буквы, цифры, `$`, `_`; не начинается с цифры; регистр важен; зарезервированные слова запрещены.
- Имена должны быть понятными, в `camelCase`; `var` в новом коде не нужен.
