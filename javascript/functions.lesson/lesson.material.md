# Функции

Когда один и тот же кусок логики нужен в нескольких местах, его не копируют, а оформляют как функцию: даёшь ему имя и вызываешь, когда нужно. Функции — основные «кирпичики» программы: они убирают дублирование, делят большую задачу на понятные шаги и помогают читать код как текст. После урока вы сможете объявлять функции с параметрами и значениями по умолчанию, возвращать результат и разумно называть функции.

## Объявление и вызов

Объявление функции состоит из ключевого слова `function`, имени, списка параметров в круглых скобках и тела в фигурных скобках. Код тела выполняется только при вызове — `имя()`:

```js
function greet() {
  console.log('Привет!');
}

greet(); // Привет!
greet(); // Привет!
```

Если текст приветствия понадобится поменять, правка делается в одном месте — внутри функции, а не в каждом месте вызова.

Объявление функции (`function name() {}`) «поднимается»: движок обрабатывает его до выполнения остального кода, поэтому вызвать такую функцию можно и выше по тексту, чем она записана:

```js
console.log(hoisted()); // работает

function hoisted() {
  return 'работает';
}
```

Сама функция — тоже значение: `typeof hoisted` равно `"function"`. Об этом мы поговорим подробнее в следующих темах.

## Локальные и внешние переменные

Переменная, объявленная внутри функции, существует только внутри неё. Снаружи к ней не обратиться:

```js
function show() {
  const message = 'внутри';
  return message;
}

console.log(show()); // внутри
console.log(message); // ReferenceError: message is not defined
```

Зато изнутри функция видит переменные, объявленные снаружи, и может их менять:

```js
let counter = 0;

function inc() {
  counter++;
}

inc();
inc();
console.log(counter); // 2
```

Если внутри функции объявлена переменная с тем же именем, она **перекрывает** внешнюю — внешняя остаётся нетронутой:

```js
let user = 'Аня';

function shadow() {
  let user = 'Борис'; // новая локальная переменная
  return user;
}

console.log(shadow(), user); // Борис Аня
```

Переменные вне всех функций называют глобальными. Использовать их стоит минимально: функция, которая молча меняет внешнее состояние (`counter++` выше), даёт побочные эффекты, а такой код сложнее понимать и проверять. Предпочтительна функция, которая получает всё нужное через параметры и отдаёт результат через `return`.

## Параметры и аргументы

**Параметр** — переменная в скобках при объявлении. **Аргумент** — значение, которое передаётся при вызове. При вызове аргументы копируются в параметры, и те становятся локальными переменными функции:

```js
function decorate(name) {
  name = '*' + name + '*'; // меняется только локальная копия
  return name;
}

let n = 'Аня';
console.log(decorate(n), n); // *Аня* Аня
```

Для примитивов (строки, числа, `true`/`false`, `null`, `undefined`) копируется само значение. Для объектов и массивов копируется **ссылка**: внутри функции и снаружи это один и тот же объект. Поэтому изменение его содержимого видно снаружи, а переприсваивание параметра — нет:

```js
function addItem(list) {
  list.push(3); // меняем общий массив
}
function reset(list) {
  list = []; // параметр теперь указывает на новый массив; внешний не затронут
}

const arr = [1, 2];
addItem(arr);
reset(arr);
console.log(arr); // [ 1, 2, 3 ]
```

JavaScript не проверяет число аргументов. Недостающие параметры получают `undefined`, лишние аргументы игнорируются (они доступны через `arguments` и rest-параметры, но это отдельная тема):

```js
function say(from, text) {
  return from + ': ' + text;
}

console.log(say('Аня')); // Аня: undefined
console.log(say('Аня', 'Привет', 'лишнее')); // Аня: Привет
```

## Значения по умолчанию

Чтобы вместо `undefined` подставлялось осмысленное значение, задайте его в списке параметров через `=`:

```js
function say(from, text = 'без текста') {
  return from + ': ' + text;
}

console.log(say('Аня')); // Аня: без текста
console.log(say('Аня', undefined)); // Аня: без текста
console.log(say('Аня', null)); // Аня: null
console.log(say('Аня', '')); // Аня: (после двоеточия пусто)
```

Значение по умолчанию подставляется **только при `undefined`** — при отсутствии аргумента или явной передаче `undefined`. `null`, `0` и `''` считаются обычными значениями и остаются.

Выражение по умолчанию вычисляется заново при каждом вызове, где аргумент не передан, и не вычисляется, если аргумент есть. В нём можно использовать предыдущие параметры:

```js
let calls = 0;
function fallback() {
  calls++;
  return 'запасной';
}
function f(x = fallback()) {
  return x;
}
f();
f();
f('свой');
console.log(calls); // 2

function g(a, b = a * 2) {
  return [a, b];
}
console.log(g(5), g(5, 1)); // [ 5, 10 ] [ 5, 1 ]
```

В старом коде встречается проверка `if (text === undefined)` или `text = text || '...'`. Вариант с `||` подменяет любое ложное значение (`0`, `''`, `false`), что часто неверно. Если default нужен не в сигнатуре, а позже, подходит `??`, который реагирует только на `null` и `undefined`:

```js
function count1(c) { return c || 'неизвестно'; }
function count2(c) { return c ?? 'неизвестно'; }

console.log(count1(0), count2(0), count2(null)); // неизвестно 0 неизвестно
```

## Возврат значения

`return значение` завершает функцию и отдаёт значение туда, где её вызвали. `return` может стоять в любом месте и встречаться несколько раз — на разных ветках. Это удобно для **раннего выхода**: сначала отсекаем особые случаи, остальной код пишем без лишней вложенности:

```js
function describe(age) {
  if (age < 0) return 'ошибка';
  return age >= 18 ? 'взрослый' : 'ребёнок';
}

console.log(describe(-1), describe(20), describe(5)); // ошибка взрослый ребёнок
```

Функция без `return` и функция с пустым `return;` возвращают `undefined`:

```js
function noReturn() {}
function emptyReturn() { return; }

console.log(noReturn(), emptyReturn()); // undefined undefined
```

Есть ловушка: JavaScript автоматически ставит `;` после `return`, если сразу за ним идёт перевод строки. Выражение на следующей строке тогда никогда не выполнится:

```js
function bad() {
  return
    1 + 2;
}
function good() {
  return (
    1 +
    2
  );
}

console.log(bad()); // undefined
console.log(good()); // 3
```

Многострочное выражение начинайте на той же строке, что и `return`, или открывайте скобку сразу после него.

## Как называть функции

Функция — это действие, поэтому имя обычно начинается с глагола и точно описывает, что происходит. Часто используют префиксы:

| Префикс | Обычный смысл | Пример |
|---|---|---|
| `show…` | что-то показывает | `showMessage()` |
| `get…` | возвращает значение | `getAge(user)` |
| `calc…` | вычисляет и возвращает результат | `calcTotal(items)` |
| `create…` | создаёт и возвращает | `createUser(name)` |
| `check…`, `is…` | проверяет, возвращает `true`/`false` | `checkPermission(user)`, `isPrime(n)` |

Правило «одна функция — одно действие»: `getAge`, которая ещё и выводит возраст на экран, или `checkPermission`, которая показывает сообщение, нарушают ожидание читателя. Два независимых действия — две функции; при необходимости их вызывает третья.

Короткие функции с хорошими именами работают как комментарии. Сравните два способа вывести простые числа меньше `n`:

```js
function showPrimes(n) {
  for (let i = 2; i < n; i++) {
    if (!isPrime(i)) continue;
    console.log(i);
  }
}

function isPrime(n) {
  for (let i = 2; i < n; i++) {
    if (n % i === 0) return false;
  }
  return true;
}

showPrimes(10); // 2, 3, 5, 7 (по одному в строке)
```

Читателю не нужно разбирать вложенные циклы с меткой: название `isPrime` уже объясняет шаг. Выделять функцию стоит и тогда, когда она вызывается один раз — ради структуры кода.

## Типичные ошибки

> [!WARNING]
>
> - Ожидать, что присваивание параметру изменит внешнюю переменную. Меняется только локальная копия; содержимое объекта через ссылку — меняется.
> - Забыть `return` и получить `undefined` вместо результата. Особенно легко при записи стрелочных и многострочных выражений.
> - Поставить перевод строки сразу после `return`.
> - Использовать `||` для значений по умолчанию там, где `0`, `''` или `false` — допустимые значения.
> - Опираться на глобальные переменные вместо параметров и `return`.

## Коротко

> [!TIP]
>
> - `function имя(параметры) { тело }` объявляет функцию, `имя(аргументы)` её вызывает.
> - Переменные внутри функции локальны; внешние доступны, но лучше передавать данные через параметры и возвращать через `return`.
> - Недостающий аргумент даёт `undefined`; значение по умолчанию `p = ...` подставляется только при `undefined` и вычисляется при каждом вызове.
> - Объекты и массивы передаются по ссылке: можно изменить содержимое, но не заменить внешнюю переменную.
> - Без `return` (или с пустым `return`) результат — `undefined`; после `return` не ставьте перевод строки.
> - Имя функции — глагол и префикс, отражающий действие; одна функция — одно действие.
