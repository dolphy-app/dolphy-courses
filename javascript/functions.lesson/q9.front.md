Разбейте задачу на две маленькие функции.

1. `isPrime(n)` возвращает `true`, если `n` — простое число (целое больше 1, которое делится только на 1 и на себя), иначе `false`.
2. `getPrimes(max)` **возвращает массив** всех простых чисел от 2 до `max` включительно по возрастанию. Для проверки каждого числа вызывайте `isPrime`.

```js
isPrime(7); // true
isPrime(1); // false
getPrimes(10); // [2, 3, 5, 7]
getPrimes(1); // []
```
