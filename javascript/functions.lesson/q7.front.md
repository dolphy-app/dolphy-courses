Напишите функцию `checkAge(age, hasPermission)`: она возвращает `true`, если посетителю не меньше 18 лет **или** родители разрешили (`hasPermission` равно `true`). Во всех остальных случаях — `false`.

Второй аргумент необязателен: если он не передан, считайте, что разрешения нет. Результат всегда строго `true` или `false`.

```js
checkAge(20, false); // true
checkAge(15, true); // true
checkAge(15, false); // false
checkAge(15); // false
```

В браузере вместо `hasPermission` пришлось бы спрашивать родителей через `confirm`; здесь ответ приходит аргументом.
