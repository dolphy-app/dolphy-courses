Напишите функцию `pow(x, n)`, которая возвращает `x` в степени `n`.

- `n` должно быть натуральным числом (целое, не меньше 1). Иначе функция бросает `RangeError`.
- Функция возвращает значение, а не выводит его.

```js
pow(3, 2); // 9
pow(3, 3); // 27
pow(1, 100); // 1
pow(2, 0); // RangeError
```

Оператор `**` и `Math.pow` использовать не нужно: напишите цикл.
