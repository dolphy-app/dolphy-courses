Функция `withItem(list, item)` должна вернуть новый массив: все элементы `list` и затем `item`. Сейчас она портит переданный массив, потому что `push` изменяет его по ссылке. Исправьте так, чтобы исходный массив остался нетронутым.

```js
const a = [1, 2];
const b = withItem(a, 3);
console.log(b); // [1, 2, 3]
console.log(a); // [1, 2]
```
