Функция `formatGreeting(name, greeting)` собирает строку `"<приветствие>, <имя>!"`. Сейчас при пропущенном аргументе в строку попадает `undefined`. Исправьте её:

- если `name` не передан, он равен `"гость"`;
- если `greeting` не передан, он равен `"Привет"`;
- значения по умолчанию подставляются только вместо `undefined`, а пустая строка остаётся пустой строкой.

```js
formatGreeting('Аня', 'Здравствуйте'); // 'Здравствуйте, Аня!'
formatGreeting('Борис'); // 'Привет, Борис!'
formatGreeting(); // 'Привет, гость!'
```

Порядок параметров `(name, greeting)` оставьте прежним.
