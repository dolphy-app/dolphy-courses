Напишите `async function loadFirstAvailable(load, names)`: по очереди вызывает `load(name)` для имён из `names` и возвращает результат первой успешной загрузки. Следующий вызов начинается только после ошибки предыдущего; после успеха остальные не вызываются.

Если не загрузилось ни одно имя (или список пуст) — функция отклоняется с `Error`.
