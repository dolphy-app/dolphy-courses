`createLazyLoader(load)` принимает функцию `load(name)`, которая возвращает промис модуля (в реальности — обёртку над `import()`). Верните функцию `get(name)`, которая возвращает промис модуля, соблюдая правила:

- для каждого имени `load` вызывается не более одного раза, в том числе при одновременных запросах;
- если загрузка завершилась ошибкой, `get` отклоняется с этой ошибкой, но она **не запоминается**: следующий `get` с тем же именем пробует снова;
- `load` не вызывается, пока не вызван `get`.
