Функция `kind` должна определять вид фигуры: `'circle'`, `'square'`, просто `'shape'` или `'unknown'` для всего остального. Сейчас она всегда отвечает `'shape'` для любой фигуры. Исправьте её.

```js
kind(new Circle()); // 'circle'
kind(new Shape()); // 'shape'
kind(42); // 'unknown'
```
