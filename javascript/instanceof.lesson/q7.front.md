Напишите функцию `isDirectInstance(obj, Class)`. Она возвращает `true`, только если `obj` создан именно классом `Class`, а не его наследником: то есть прототип `obj` — это `Class.prototype`. Для `null`, `undefined` и примитивов — `false`.

```js
class A {}
class B extends A {}
isDirectInstance(new A(), A); // true
isDirectInstance(new B(), A); // false
```
