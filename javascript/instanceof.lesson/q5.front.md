Напишите функцию `isInstance(obj, Class)`. Она возвращает `true`, если `Class.prototype` присутствует в цепочке прототипов `obj`. Для `null`, `undefined` и примитивов результат — `false`. Оператором `instanceof` пользоваться нельзя (подойдут `Object.getPrototypeOf` или `isPrototypeOf`).

```js
isInstance([], Array); // true
isInstance(5, Number); // false
```
