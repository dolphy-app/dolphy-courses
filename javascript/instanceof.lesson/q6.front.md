Напишите функцию `duckType(...methods)`. Она возвращает **класс-проверку** `Duck`, для которого `value instanceof Duck` истинно, если `value` — непустой объект (или функция), у которого есть все перечисленные методы (свойства-функции, в том числе унаследованные). Примитивы и `null` не проходят проверку.

```js
const Flyer = duckType('fly', 'land');
({ fly() {}, land() {} }) instanceof Flyer; // true
({ fly() {} }) instanceof Flyer; // false
```
