# Привет, мир!

Первая программа на любом языке — вывод приветствия. Заодно разберёмся, как JavaScript-код попадает на выполнение: в браузере и в Node.js, с которым мы работаем в этом курсе.

## Скрипт в браузере

Браузер выполняет код, который находится в HTML внутри тега `<script>`. Когда страница доходит до такого тега, она выполняет его содержимое и идёт дальше:

```html
<p>До скрипта</p>
<script>
  alert('Привет, мир!');
</script>
<p>После скрипта</p>
```

`alert` — функция браузера, она показывает окно с сообщением. Остальной код страницы ждёт, пока пользователь закроет окно.

Когда-то тегу добавляли атрибуты `type="text/javascript"` и `language`. Сейчас они не нужны: современные браузеры считают содержимое тега JavaScript-кодом по умолчанию. Атрибут `type="module"` по-прежнему имеет смысл — он включает режим модулей, о котором речь пойдёт позже.

## Внешние скрипты

Объёмный код хранят в отдельных файлах и подключают атрибутом `src`:

```html
<script src="/path/to/script.js"></script>
```

Преимущество в том, что браузер скачает файл один раз и положит в кэш. Другие страницы того же сайта возьмут его из кэша, а не будут загружать снова. Также код проще читать, тестировать и переиспользовать.

Если у тега указан `src`, его внутреннее содержимое игнорируется:

```html
<script src="file.js">
  alert(1); // это никогда не выполнится
</script>
```

Нужен и внешний файл, и встроенный код — используйте два тега.

## Скрипт в Node.js

В Node.js нет страницы и тегов. Код лежит в обычном файле, который запускают командой:

```
node hello.js
```

Вместо `alert` вывод делают через `console.log`: она печатает значение в консоль браузера или в терминал. Эта функция работает в любом окружении, поэтому в курсе мы пользуемся именно ею:

```js
console.log('Привет, мир!'); // Привет, мир!
```

Можно передать несколько значений — они выводятся через пробел:

```js
console.log('Ответ:', 6 * 7); // Ответ: 42
```

## Что мы делаем в упражнениях

Задания курса проверяются автоматически. Вы пишете код в окне, проверка запускает его в Node.js (версия 22) и сравнивает результат с ожидаемым. Иногда нужно вернуть значение из функции, иногда — вывести его в консоль. Обращайте внимание на формулировку: «верните» и «выведите» — разные требования.

## Типичные ошибки

> [!WARNING]
>
> - Забыть закрыть тег: `<script>` без `</script>` ломает всю остальную страницу.
> - Написать код внутри тега с `src` и удивляться, что он не выполняется.
> - Использовать `alert` или `document` в Node.js: этих функций там нет.
> - Ждать вывода от кода, в котором нет `console.log` — результат выражения сам по себе на экран не попадает.

## Коротко

> [!TIP]
>
> - Браузер запускает код из тегов `<script>`; `type` и `language` сегодня не нужны.
> - Большой код выносят во внешние файлы (`src`): они кэшируются.
> - Если задан `src`, содержимое тега игнорируется.
> - В Node.js код запускают командой `node file.js`.
> - `console.log` работает везде и подходит для вывода значений.
