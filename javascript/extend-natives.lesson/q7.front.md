Напишите класс `DefaultMap extends Map`. Конструктор принимает функцию-фабрику `factory`. Метод `get(key)` для отсутствующего ключа вызывает `factory(key)`, **сохраняет** результат в карте и возвращает его; для существующего — просто возвращает значение (в том числе `undefined` и `0`, если оно было записано). Остальные методы `Map` работают как обычно.

```js
const m = new DefaultMap(() => []);
m.get('a').push(1);
m.get('a'); // [1]
m.size; // 1
```
