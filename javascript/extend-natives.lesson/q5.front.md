Напишите класс `StatsArray extends Array` с методами:

- `sum()` — сумма элементов (для пустого — `0`);
- `average()` — среднее арифметическое (для пустого — `0`);
- `last()` — последний элемент или `undefined`.

Методы `filter` и `map` должны по-прежнему возвращать `StatsArray` (поведение по умолчанию).

```js
const a = StatsArray.from([1, 2, 3, 4]);
a.filter((x) => x > 1).sum(); // 9
```
