Напишите класс `HttpError extends Error`. Конструктор принимает `(status, message, options)` и передаёт сообщение и `options` (с возможным `cause`) в `super`. Поля: `name` равно `'HttpError'`, `status` — код. Геттер `isClientError` истинен для статусов 400–499.

```js
const e = new HttpError(404, 'Не найдено');
e.status; // 404
e.isClientError; // true
String(e); // 'HttpError: Не найдено'
```
