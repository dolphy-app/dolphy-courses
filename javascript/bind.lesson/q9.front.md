Напишите функцию `bindAll(obj)`: она заменяет в `obj` каждый собственный метод (свойство-функцию) его версией с закреплённым `this = obj` и возвращает тот же объект `obj`. Остальные свойства не изменяются.

```js
const { hello } = bindAll({ name: 'Ира', hello() { return this.name; } });
hello(); // 'Ира'
```
