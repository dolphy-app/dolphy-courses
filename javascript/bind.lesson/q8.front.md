Напишите функцию `makeHandlers(user)`. Она возвращает объект `{ ok, fail }` из двух функций, которые можно вызывать отдельно от объекта (например, `const { ok } = makeHandlers(user); ok();`). Вызов `ok()` должен добавлять в `user.log` строку `user.name + ': вход'`, а `fail()` — `user.name + ': отказ'` (это делают методы `loginOk` и `loginFail` самого `user`, они используют `this`).

```js
const user = {
  name: 'Ира',
  log: [],
  loginOk() { this.log.push(this.name + ': вход'); },
  loginFail() { this.log.push(this.name + ': отказ'); },
};
```
