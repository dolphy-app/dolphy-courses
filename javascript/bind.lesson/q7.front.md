Напишите функцию `partial(func, ...fixed)`: она возвращает функцию, которая вызывает `func`, подставив `fixed` перед переданными аргументами. `this` обёртки должен передаваться в `func` (не используйте `bind`, ведь он закрепил бы контекст).

```js
const add3 = partial((a, b, c) => a + b + c, 1, 2);
add3(10); // 13
```
