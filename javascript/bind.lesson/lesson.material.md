# Привязка контекста: bind

Метод объекта, переданный как значение (в таймер, в обработчик, в другую функцию), теряет связь с объектом, и `this` оказывается не тем. Этот урок — о том, как закрепить контекст навсегда с помощью `bind`, и как заодно заранее подставлять часть аргументов.

## Потеря this

Когда вы пишете `user.hello()`, `this` определяется точкой в момент вызова. Но стоит взять метод как значение, точка пропадает:

```js
const user = {
  name: 'Ира',
  hello() {
    return 'Привет, ' + this?.name;
  },
};

const hello = user.hello;
console.log(hello()); // Привет, undefined

console.log(user.hello()); // Привет, Ира
```

В обычном режиме `this` при простом вызове — глобальный объект (у него нет `name`), в строгом — `undefined`; поэтому в примере стоит `this?.name`. Те же проблемы возникают с `setTimeout(user.hello, 10)`: таймер получает функцию без объекта.

## Решение 1: обёртка

Самое простое решение — стрелочная функция-обёртка, вызывающая метод «через точку»:

```js
setTimeout(() => console.log(user.hello()), 10); // Привет, Ира
```

Она работает, но есть тонкость: обёртка ссылается на переменную `user` в момент срабатывания таймера. Если за это время переменная получит другое значение, вызов уйдёт другому объекту.

## Решение 2: bind

Метод `func.bind(context)` возвращает **новую** функцию («экзотический» объект-обёртку), которая всегда вызывает `func` с `this = context`:

```js
const boundHello = user.hello.bind(user);
console.log(boundHello()); // Привет, Ира

const copy = { name: 'Другой' };
copy.hello = boundHello;
console.log(copy.hello()); // Привет, Ира
```

Видно, что `this` закреплён намертво: даже вызов через другой объект его не меняет. Исходная функция остаётся прежней; `bind` ничего не изменяет.

## Частичное применение

`bind` принимает и дополнительные аргументы: они подставляются в начало списка аргументов при каждом вызове. Такой приём называют частичным применением (partial application):

```js
function mul(a, b) {
  return a * b;
}

const double = mul.bind(null, 2);
console.log(double(5)); // 10
console.log(double(21)); // 42
```

Первым аргументом идёт контекст. Если он не нужен, передают `null`. Функция `double` — «заготовка» с уже зафиксированным `a = 2`.

Привязанная функция помнит и имя, и количество оставшихся параметров:

```js
console.log(double.name); // bound mul
console.log(double.length); // 1
```

Если нужно зафиксировать аргументы, но **не** трогать `this`, `bind` не подходит: он всегда закрепляет контекст. Тогда пишут вспомогательную функцию-обёртку:

```js
function partial(func, ...fixed) {
  return function (...rest) {
    return func.call(this, ...fixed, ...rest);
  };
}

const user2 = {
  name: 'Олег',
  say(greeting, mark) {
    return greeting + ', ' + this.name + mark;
  },
};
user2.hi = partial(user2.say, 'Привет');
console.log(user2.hi('!')); // Привет, Олег!
```

## Привязать можно только один раз

Результат `bind` — функция с зафиксированным контекстом. Повторный `bind` на ней контекст уже не сменит:

```js
function whoAmI() {
  return this.id;
}
const once = whoAmI.bind({ id: 1 });
const twice = once.bind({ id: 2 });
console.log(twice()); // 1
```

Второй `bind` создаёт ещё одну обёртку, но она вызывает первую, а та игнорирует чужой `this`. Аналогично `call` и `apply` не могут переопределить привязанный `this`:

```js
console.log(once.call({ id: 3 })); // 1
```

## Свойства функции после bind

У привязанной функции нет свойств исходной: `bind` создаёт новый объект.

```js
function tool() {}
tool.version = 2;
const bound = tool.bind(null);
console.log(bound.version); // undefined
```

## Привязка всех методов

Если в объекте много методов, которые будут передаваться как значения, привязывают их в цикле:

```js
const api = {
  prefix: '>',
  a() { return this.prefix + 'a'; },
  b() { return this.prefix + 'b'; },
};
for (const key of Object.keys(api)) {
  if (typeof api[key] === 'function') api[key] = api[key].bind(api);
}
const { a } = api;
console.log(a()); // >a
```

В классах для этого обычно используют поля-стрелки; об этом — в уроках про классы.

## Типичные ошибки

- `setTimeout(user.hello(), 10)` — вызов вместо передачи функции.
- Ожидать, что `bind` вызовет функцию: он только создаёт новую.
- Пытаться перепривязать уже привязанную функцию.
- Забыть, что первый параметр `bind` — всегда `this`: фиксируемые аргументы идут со второго.

## Коротко

- Метод, вынутый из объекта, теряет `this`; причина — в способе вызова, а не в самой функции.
- `func.bind(ctx, ...args)` возвращает новую функцию с закреплённым `this` и подставленными первыми аргументами.
- Привязка окончательна: ни повторный `bind`, ни `call`/`apply` её не меняют.
- Для фиксации аргументов без контекста пишут обёртку (`partial`) или передают `null` первым аргументом, если `this` не используется.
- Привязанная функция получает имя `bound имя` и теряет пользовательские свойства исходной.
