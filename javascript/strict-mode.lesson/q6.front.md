Функция `addAll(list)` возвращает сумму чисел, но случайно создаёт глобальную переменную `sum`. Исправьте её: включите строгий режим **внутри функции** директивой `'use strict'` и объявите переменную.

```js
addAll([1, 2, 3]); // 6
```
