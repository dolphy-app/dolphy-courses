Связный список — это цепочка объектов вида `{ value, next }`; у последнего узла `next === null`, пустой список — `null`.

```js
const list = { value: 1, next: { value: 2, next: { value: 3, next: null } } };
```

Напишите две функции:

- `listValues(list)` — возвращает массив значений от первого узла к последнему;
- `listValuesReversed(list)` — возвращает массив значений в обратном порядке.

```js
listValues(list); // [1, 2, 3]
listValuesReversed(list); // [3, 2, 1]
```

Список менять нельзя. Для `null` обе функции возвращают пустой массив.
