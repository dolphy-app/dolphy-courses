Числа Фибоначчи: `0, 1, 1, 2, 3, 5, 8, 13, …` — каждое следующее равно сумме двух предыдущих. Напишите функцию `fib(n)`, которая возвращает число с номером `n` (нумерация с нуля: `fib(0) = 0`, `fib(1) = 1`).

```js
fib(7); // 13
```

Функция должна быстро работать для `n` до 77 (результат ещё точно помещается в `Number`). Наивная рекурсия `fib(n - 1) + fib(n - 2)` здесь не успеет: подумайте, как избежать повторных вычислений.
