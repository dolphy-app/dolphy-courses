Отдел компании — это либо **массив** сотрудников (`{ salary: число }`), либо **объект**, значениями которого являются подотделы (каждый — снова массив или объект). Вложенность может быть любой глубины.

Напишите функцию `totalSalary(dep)`, которая возвращает суммарную зарплату всех сотрудников в отделе и во всех его подотделах.

```js
totalSalary({ dev: [{ salary: 10 }], ops: { lead: [{ salary: 5 }] } }); // 15
```

Для пустых отделов результат — `0`.
