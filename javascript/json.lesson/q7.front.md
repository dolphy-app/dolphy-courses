Напишите функцию `safeParse(text, fallback)`: возвращает результат `JSON.parse(text)`, а если строка некорректна — значение `fallback`. Значение `null` в корректном JSON — это не ошибка.

```js
safeParse('{"a":1}', {}); // { a: 1 }
safeParse('{a:1}', 0);    // 0
```
