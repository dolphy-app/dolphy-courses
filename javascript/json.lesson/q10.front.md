Напишите функцию `parseWithDates(text)`: разбирает JSON-строку, а все поля, имя которых заканчивается на `At` (например, `createdAt`) и значение которых — строка, превращает в объекты `Date`. Используйте второй аргумент `JSON.parse`.

```js
const r = parseWithDates('{"id":1,"createdAt":"2024-01-02T00:00:00.000Z"}');
r.createdAt instanceof Date; // true
```
