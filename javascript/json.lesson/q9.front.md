Напишите функцию `stringifyWithout(obj, keys)`: возвращает JSON-строку объекта (без отступов), из которой исключены все свойства с именами из массива `keys` — на любой глубине вложенности. Используйте функцию-`replacer`.

```js
stringifyWithout({ a: 1, b: { a: 2, c: 3 } }, ['a']); // '{"b":{"c":3}}'
```
