Напишите функцию `createUser(name, password)`. Она возвращает объект с полями `name` и `password` (оба доступны в коде как обычные свойства), но при `JSON.stringify` поле `password` в результат не попадает. Реализуйте это через метод `toJSON`.

```js
const u = createUser('ann', 'secret');
u.password;           // 'secret'
JSON.stringify(u);    // '{"name":"ann"}'
```
