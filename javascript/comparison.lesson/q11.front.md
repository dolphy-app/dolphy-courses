Напишите функцию `sortWords(words)`: она возвращает **новый** массив слов, отсортированный по алфавиту без учёта регистра. Исходный массив менять нельзя.

```js
sortWords(['b', 'a', 'C']); // ['a', 'b', 'C']
```
