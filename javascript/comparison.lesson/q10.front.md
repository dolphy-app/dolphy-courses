Напишите функцию `isNullish(value)`: она возвращает `true` только для `null` и `undefined`, а для всех остальных значений — `false`, в том числе для `0`, `''`, `false` и `NaN`.

```js
isNullish(undefined); // true
isNullish(0);         // false
```
