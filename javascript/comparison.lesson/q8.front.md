Напишите функцию `isSame(a, b)`: она возвращает `true`, если значения равны **без приведения типов**, причём `NaN` считается равным `NaN`. Значения `0` и `-0` считаются одинаковыми.

```js
isSame(1, 1);       // true
isSame(NaN, NaN);   // true
isSame('1', 1);     // false
```
