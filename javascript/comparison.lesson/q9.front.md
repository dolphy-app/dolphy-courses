Напишите функцию `isBetween(x, min, max)`: она возвращает `true`, если `x` лежит в отрезке от `min` до `max` **включительно**. Считайте, что `min <= max`.

```js
isBetween(5, 1, 10); // true
isBetween(11, 1, 10); // false
```
