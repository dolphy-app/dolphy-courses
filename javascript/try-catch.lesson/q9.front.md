Напишите функцию `syntaxOrValue(fn)`. Она вызывает `fn()` и возвращает результат. Если `fn` бросила `SyntaxError`, функция возвращает строку `'syntax'`. Любые другие ошибки нужно пробросить дальше без изменений.

```js
syntaxOrValue(() => 5); // 5
syntaxOrValue(() => JSON.parse('{')); // 'syntax'
syntaxOrValue(() => null.x); // бросит TypeError
```
