Напишите функцию `parseAge(value)`, которая превращает строку в возраст.

- Если `value` не строка, бросьте `TypeError`.
- Если строка не является целым числом от 0 до 150 включительно (в том числе пустая строка), бросьте `RangeError` с непустым сообщением.
- Иначе верните число.

```js
parseAge('25'); // 25
parseAge(25); // TypeError
parseAge('151'); // RangeError
```
