Напишите функцию `safeParse(json, fallback)`. Она возвращает результат `JSON.parse(json)`, а если строка не является корректным JSON, возвращает `fallback`.

```js
safeParse('{"a":1}', null); // { a: 1 }
safeParse('{oops', 'нет'); // 'нет'
safeParse('0', 5); // 0 (корректный JSON, fallback не нужен)
```
