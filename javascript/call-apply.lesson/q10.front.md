          const cache = new Map();
          return function (...args) {
            const key = hash(...args);
            if (cache.has(key)) return cache.get(key);
            const result = func.apply(this, args);

Напишите декоратор `cacheBy(func, hash)`. Ключ кэша вычисляется как `hash(...args)` (функция получает те же аргументы, что и обёртка). Если для ключа результат уже есть, `func` не вызывается. Обёртка должна сохранять `this`.

```js
const add = cacheBy((a, b) => a + b, (a, b) => a + ':' + b);
add(1, 2); // 3, func вызвана
add(1, 2); // 3, из кэша
```
