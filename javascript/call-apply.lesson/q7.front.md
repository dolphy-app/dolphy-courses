Напишите декоратор `spy(func)`. Он возвращает обёртку, которая вызывает `func` (с тем же `this` и аргументами, возвращая её результат) и сохраняет аргументы каждого вызова в массиве `wrapper.calls` (по одному вложенному массиву на вызов).

```js
const sum = spy((a, b) => a + b);
sum(1, 2); // 3
sum(4, 5); // 9
sum.calls; // [[1, 2], [4, 5]]
```
