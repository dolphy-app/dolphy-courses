Напишите декоратор `delay(func, ms)`: возвращает обёртку, которая вызывает `func` не сразу, а через `ms` миллисекунд, сохраняя `this` и аргументы вызова.

```js
const delayedLog = delay(console.log, 50);
delayedLog('привет'); // через 50 мс: привет
```
