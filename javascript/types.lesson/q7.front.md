Напишите функцию `typeOf(value)`, которая возвращает название типа значения строкой. Работает как `typeof`, но для `null` возвращает `'null'`, а для массивов — `'array'`.

```js
typeOf(5);    // 'number'
typeOf(null); // 'null'
typeOf([]);   // 'array'
```
