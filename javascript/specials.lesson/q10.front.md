Напишите функцию `findInMatrix(matrix, target)`. Матрица — массив строк (массивов). Функция ищет значение `target` (сравнение через `===`) и возвращает координаты **первого** найденного элемента при обходе по строкам слева направо в виде `[строка, столбец]`. Если значения нет, возвращает `null`. Длина строк может быть разной, строки могут быть пустыми.

```js
findInMatrix([[1, 2, 3], [4, 5, 6]], 5); // [1, 1]
findInMatrix([[1, 2], [3, 4]], 10);      // null
```
