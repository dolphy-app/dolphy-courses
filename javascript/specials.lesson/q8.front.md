Напишите функцию `typeName(value)`: она возвращает название типа значения как `typeof`, но для `null` возвращает строку `'null'`.

```js
typeName(5);         // 'number'
typeName(null);      // 'null'
typeName(() => {});  // 'function'
typeName([]);        // 'object'
```
