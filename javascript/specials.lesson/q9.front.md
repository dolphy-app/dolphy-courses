Напишите функцию `withDefaults(options)`. Она принимает объект настроек и возвращает **новый** объект с полями `retries`, `timeout` и `verbose`. Если поле в `options` отсутствует или равно `null`/`undefined`, берётся значение по умолчанию: `retries` — `3`, `timeout` — `1000`, `verbose` — `false`. Любое другое значение (включая `0`, `false`, `''`) сохраняется как есть. Исходный объект менять нельзя.

```js
withDefaults({ retries: 0 });
// { retries: 0, timeout: 1000, verbose: false }
```
