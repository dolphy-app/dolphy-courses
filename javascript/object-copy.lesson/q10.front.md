Функция `withDefaults(options)` должна вернуть объект с настройками: значения из `DEFAULTS`, поверх которых применены `options`. Сейчас после первого вызова «значения по умолчанию» оказываются испорчены. Исправьте функцию (объект `DEFAULTS` оставьте как есть).

```js
withDefaults({ retries: 9 }); // { retries: 9, timeout: 1000 }
withDefaults();               // { retries: 3, timeout: 1000 }
```
