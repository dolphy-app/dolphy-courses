Напишите функцию `deepClone(value)`, которая возвращает независимую (глубокую) копию значения. Достаточно поддержать примитивы, `null`, простые объекты и массивы (дат, функций и циклических ссылок в тестах нет). `structuredClone` в окружении недоступен.

```js
const src = { sizes: { width: 50 }, tags: ['a'] };
const c = deepClone(src);
c.sizes.width++;
c.tags.push('b');
src.sizes.width; // 50
src.tags;        // ['a']
```
