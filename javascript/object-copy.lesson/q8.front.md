Напишите функцию `mergeAll(...sources)`: она принимает любое число объектов и возвращает **новый** объект со свойствами из всех. При совпадении имён побеждает значение из более позднего аргумента. Переданные объекты изменять нельзя.

```js
mergeAll({ a: 1, b: 1 }, { b: 2 }); // { a: 1, b: 2 }
mergeAll();                          // {}
```
