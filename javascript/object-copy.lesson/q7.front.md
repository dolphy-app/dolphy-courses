Напишите функцию `shallowClone(obj)`, которая возвращает новый объект с теми же свойствами, что у `obj` (поверхностная копия). Вложенные объекты копировать не нужно: они остаются общими.

```js
const src = { name: 'John', age: 30 };
const c = shallowClone(src);
c.name = 'Pete';
src.name; // 'John'
```
