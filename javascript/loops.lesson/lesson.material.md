# Циклы while и for

Когда одно и то же действие нужно повторить много раз — обработать каждый товар из списка, перебрать числа от 1 до 100, дождаться нужного значения, — копировать код бессмысленно. Для этого есть циклы. После урока вы сможете выбрать подходящий цикл, прервать его в нужный момент и выйти сразу из нескольких вложенных циклов.

Здесь разбираются базовые циклы `while`, `do..while` и `for (;;)`. Циклы `for..of` и `for..in` для перебора коллекций и свойств объектов будут в уроках про массивы и объекты.

## Цикл while

```js
while (condition) {
  // тело цикла
}
```

Пока `condition` истинно, выполняется тело. Одно выполнение тела называется *итерацией*. Условие проверяется **перед** каждой итерацией, в том числе перед первой: если оно сразу ложно, тело не выполнится ни разу.

```js
const log = [];
let i = 0;
while (i < 3) {
  log.push(i);
  i++; // без этой строки цикл не закончится
}
console.log(log); // [ 0, 1, 2 ]
console.log(i);   // 3
```

Условием может быть любое выражение, а не только сравнение: оно приводится к логическому значению так же, как в `if`. Поэтому `while (n)` — это короткая запись `while (n !== 0)` для числа, которое уменьшается до нуля:

```js
let n = 3;
const seen = [];
while (n) {
  seen.push(n);
  n--;
}
console.log(seen); // [ 3, 2, 1 ]
```

Если тело состоит из одной инструкции, фигурные скобки можно опустить, но с ними код легче править: добавить вторую строку в тело без скобок — частый источник ошибок.

## Цикл do..while

```js
do {
  // тело цикла
} while (condition);
```

Здесь сначала выполняется тело, и только потом проверяется условие. Значит, тело выполнится **минимум один раз**:

```js
let a = 10;
let runsWhile = 0;
while (a < 3) { runsWhile++; a++; }

let b = 10;
let runsDo = 0;
do { runsDo++; b++; } while (b < 3);

console.log(runsWhile, runsDo); // 0 1
```

`do..while` оправдан, когда действие нужно выполнить хотя бы раз, а условие зависит от его результата: например, посчитать цифры числа (у нуля одна цифра, а не ноль). В остальных случаях чаще пишут `while`.

## Цикл for

Самый распространённый цикл. Он собирает в одной строке всё, что нужно для счётчика:

```js
for (начало; условие; шаг) {
  // тело цикла
}
```

| Часть | Когда выполняется |
|---|---|
| начало | один раз, при входе в цикл |
| условие | перед каждой итерацией; если ложно — цикл завершается |
| тело | если условие истинно |
| шаг | после тела, перед следующей проверкой условия |

Порядок: начало → (условие → тело → шаг) → (условие → тело → шаг) → … → условие ложно. Последнюю проверку, которая остановила цикл, легко забыть, а ведь именно поэтому после цикла `for (let i = 0; i < 3; i++)` счётчик равен 3, а не 2.

```js
const out = [];
for (let i = 0; i < 3; i++) {
  out.push(i);
}
console.log(out); // [ 0, 1, 2 ]
```

Форма записи шага не важна: `i++` и `++i` в третьей части делают одно и то же, потому что результат выражения там никто не использует.

### Переменная цикла

Переменная, объявленная через `let` в заголовке, существует только внутри цикла:

```js
for (let i = 0; i < 3; i++) {}
console.log(typeof i); // undefined (имени i снаружи нет)
```

Попытка прочитать такую `i` вне цикла даёт `ReferenceError: i is not defined`. Если значение счётчика нужно после цикла, объявите переменную заранее:

```js
let i;
for (i = 0; i < 3; i++) {}
console.log(i); // 3
```

У `let` в заголовке есть ещё одна особенность: на каждой итерации создаётся своя копия переменной. Это видно, когда функция «запоминает» счётчик, а вызывается позже (пример с `setTimeout`, он откладывает вызов; таймеры будут в одной из следующих тем):

```js
for (let i = 0; i < 3; i++) setTimeout(() => console.log('let', i));
for (var j = 0; j < 3; j++) setTimeout(() => console.log('var', j));
// let 0, let 1, let 2, var 3, var 3, var 3
```

С `var` переменная одна на весь цикл, и к моменту вызова в ней уже 3. Ещё одна причина не использовать `var`.

### Пропуск частей

Любая из трёх частей `for` необязательна, но точки с запятой остаются:

```js
let i = 0;
const r = [];
for (; i < 3;) { // нет ни начала, ни шага
  r.push(i++);
}
console.log(r, i); // [ 0, 1, 2 ] 3
```

Без условия цикл бесконечный: `for (;;) { … }`. Эквивалент для `while` — `while (true)`. Бесконечный цикл сам по себе не ошибка: его покидают через `break` (или `return` внутри функции). Если же выйти не получается, программа зависает: в браузере вкладка перестаёт отвечать, в Node.js процесс придётся остановить через `Ctrl+C`.

## break: выйти из цикла

Директива `break` немедленно завершает цикл, и управление переходит к коду после него. Это удобно, когда условие выхода находится в середине тела или в нескольких местах:

```js
const values = [4, 5, 0, 7];
let sum = 0;
let k = 0;
while (true) {
  const v = values[k++];
  if (!v) break; // ноль (и undefined после конца) останавливают цикл
  sum += v;
}
console.log(sum); // 9
```

## continue: перейти к следующей итерации

`continue` прекращает только текущую итерацию. В `for` после него выполняется шаг, затем проверяется условие; в `while` проверяется условие.

```js
const odd = [];
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue; // чётные пропускаем
  odd.push(i);
}
console.log(odd); // [ 1, 3, 5, 7, 9 ]
```

То же можно написать с `if (i % 2) { … }` вокруг тела, но `continue` избавляет от лишнего уровня вложенности, если тело длинное. Правило хорошего тона: отсеять «неинтересные» случаи в начале итерации, а основную работу оставить без отступов.

### break и continue — это инструкции, а не выражения

Их нельзя поставить в ветку тернарного оператора или в другое выражение:

```js
// (i > 5) ? console.log(i) : continue; // SyntaxError
```

Здесь нужен обычный `if..else`. Это ещё один довод против `?` вместо `if`.

## Метки: выход из вложенных циклов

Обычный `break` выходит только из ближайшего цикла. Чтобы разом выйти из внешнего, ставят *метку* — идентификатор с двоеточием перед циклом — и пишут `break имя`:

```js
const pairs = [];
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i * j === 2) break outer; // выход из обоих циклов
    pairs.push(`${i}${j}`);
  }
}
console.log(pairs.join(' ')); // 00 01 02 10 11
```

`continue имя` переходит к следующей итерации помеченного (внешнего) цикла:

```js
const firsts = [];
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (j === 1) continue outer;
    firsts.push(`${i}${j}`);
  }
}
console.log(firsts.join(' ')); // 00 10 20
```

Метка — не `goto`: прыгнуть можно только наружу, из тела помеченной конструкции. `break метка` допустим внутри помеченного блока, `continue метка` — только если метка стоит на цикле:

```js
label: {
  console.log('a');
  break label; // выход из блока
  console.log('b'); // не выполнится
}
console.log('c');
// a, c
```

`continue` вне цикла — `SyntaxError: Illegal continue statement`.

## Типичные ошибки

- **Забыли изменить счётчик** (`i++`) — бесконечный цикл. Обязательно проверяйте, что тело или шаг приближают условие к ложному.
- **Точка с запятой после заголовка.** `for (...);` — это цикл с пустым телом, а следующий за ним блок `{ … }` выполнится один раз после цикла:

  ```js
  let c = 0;
  for (let i = 0; i < 3; i++); { c++; }
  console.log(c); // 1
  ```

- **Ошибка на единицу.** `i <= n` вместо `i < n` (или наоборот) даёт на одну итерацию больше или меньше. Проверяйте границы на примере из двух-трёх элементов.
- **Дробный счётчик и `!==`.** Из‑за погрешности `0.1 + 0.2` равно `0.30000000000000004`, поэтому `for (let x = 0; x !== 1; x += 0.1)` никогда не остановится. Для счётчиков берите целые числа, а в условии — `<` или `<=`.
- **Изменение счётчика в теле** вместе с шагом в заголовке — цикл становится трудночитаемым. Если нужен нестандартный ход, подумайте о `while`.

## Коротко

- `while` проверяет условие до тела, `do..while` — после, поэтому его тело выполняется минимум раз.
- В `for (начало; условие; шаг)` начало выполняется один раз, условие — перед каждой итерацией, шаг — после тела.
- Переменная `let` из заголовка `for` видна только в цикле, и у каждой итерации она своя.
- `break` выходит из цикла, `continue` переходит к следующей итерации; это инструкции, их нельзя вставить в `?:`.
- Метка перед циклом позволяет `break`/`continue` управлять внешним циклом; перепрыгнуть в произвольное место кода метки не дают.
- «`while (true)` или `for (;;)` + `break`» — стандартный способ записать цикл, у которого условие выхода в середине.
