Напишите функцию `digitCount(n)`: она возвращает количество цифр в записи неотрицательного целого числа `n`. У `0` — одна цифра. Строки и `toString` использовать не обязательно: посчитайте цифры арифметикой.

```js
digitCount(0);     // 1
digitCount(12345); // 5
```
