Простое число — целое число больше `1`, которое делится только на `1` и на само себя. Напишите функцию `primesUpTo(n)`: она возвращает массив всех простых чисел от `2` до `n` включительно в порядке возрастания. Если простых чисел нет, верните пустой массив.

```js
primesUpTo(10); // [2, 3, 5, 7]
```
