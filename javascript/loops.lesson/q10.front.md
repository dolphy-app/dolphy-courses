Матрица — это массив строк, а строка — массив значений. Напишите функцию `findCell(matrix, target)`: она ищет значение `target` (строгое сравнение), просматривая строки сверху вниз, а каждую строку слева направо. Верните индексы первого найденного значения в виде `[строка, столбец]`, а если значения нет — `null`.

```js
findCell([[1, 2], [3, 4]], 3); // [1, 0]
findCell([[1, 2], [3, 4]], 9); // null
```
