Напишите функцию `firstDivisible(from, to, d)`: она возвращает первое целое число из диапазона `[from, to]` (обе границы включаются), которое нацело делится на `d` (`d > 0`). Если такого числа нет или `from > to`, верните `null`.

```js
firstDivisible(10, 20, 7); // 14
firstDivisible(15, 20, 7); // null
```
