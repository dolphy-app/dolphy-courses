Напишите функцию `sumOdd(limit)`: она возвращает сумму всех нечётных целых чисел от `1` до `limit` включительно. Если подходящих чисел нет, результат — `0`.

```js
sumOdd(10); // 25
sumOdd(0);  // 0
```
