Напишите функцию `installPolyfill(target, name, impl)`. Если у `target` уже есть свойство `name` (в том числе унаследованное), она ничего не делает и возвращает `false`. Иначе добавляет `target[name] = impl` как **неперечисляемое**, записываемое и настраиваемое свойство (как у встроенных методов) и возвращает `true`.

```js
const target = {};
installPolyfill(target, 'answer', () => 42); // true
Object.keys(target); // [] — свойство неперечисляемое
```
