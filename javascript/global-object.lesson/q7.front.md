Напишите функцию `listNewGlobals(fn)`: она вызывает `fn` один раз и возвращает массив имён собственных свойств `globalThis`, которые появились во время вызова. Имена отсортируйте по алфавиту. Учитывайте и неперечисляемые свойства.

```js
listNewGlobals(() => {
  globalThis.tmpA = 1;
}); // ['tmpA']
```

Изменение уже существующего свойства новым не считается.
