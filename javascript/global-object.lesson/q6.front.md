Напишите функцию `ensureGlobal(name, factory)`. Если в глобальном объекте уже есть свойство `name` (даже со значением `0`, `''` или `undefined`), функция ничего не меняет и не вызывает `factory`. Иначе она записывает в `globalThis[name]` результат `factory()`. В обоих случаях функция возвращает текущее значение `globalThis[name]`.

```js
ensureGlobal('appConfig', () => ({ debug: true })); // { debug: true }, записано в globalThis.appConfig
ensureGlobal('appConfig', () => ({ debug: false })); // прежний объект, factory не вызвана
```

Для обращения к глобальному объекту используйте `globalThis`.
