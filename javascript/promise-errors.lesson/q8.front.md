Функция `withLoading(state, task)` поднимает `state.loading`, вызывает `task()` (возвращает промис) и возвращает промис с результатом. Сейчас при ошибке флаг остаётся поднятым. Исправьте функцию так, чтобы флаг сбрасывался в любом исходе, а результат и ошибка задачи доходили до вызывающего кода без изменений.
