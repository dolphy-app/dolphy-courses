Напишите функцию `canHoldProps(value)`. Она присваивает значению свойство `marker` и возвращает `true`, если после этого оно читается обратно, иначе `false`. Функция не должна бросать ошибку ни для каких значений, включая `null` и `undefined`.

```js
canHoldProps({}); // true
canHoldProps('text'); // false
```
