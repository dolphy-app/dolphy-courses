Напишите функцию `safeCall(value, method, ...args)`. Она вызывает у `value` метод с именем `method`, передавая `args`, и возвращает результат. Если `value` равно `null` или `undefined`, либо такого метода нет — возвращает `undefined` и не бросает ошибку.

```js
safeCall('abc', 'toUpperCase'); // 'ABC'
safeCall(5, 'toFixed', 2); // '5.00'
safeCall(null, 'toString'); // undefined
```
