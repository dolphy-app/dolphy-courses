Напишите функцию `isPrimitiveString(value)`. Она возвращает `true`, только если `value` — строка-примитив. Для объекта-обёртки `new String('a')`, чисел и прочих значений — `false`.

```js
isPrimitiveString('hello'); // true
isPrimitiveString(new String('hello')); // false
```
