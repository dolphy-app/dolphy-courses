Напишите функцию `sumValues(obj)`: она принимает объект, все значения которого — числа, и возвращает их сумму. Для пустого объекта результат — `0`.

```js
sumValues({ John: 100, Ann: 160, Pete: 130 }); // 390
sumValues({});                                  // 0
```
