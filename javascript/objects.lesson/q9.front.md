Напишите функцию `scaleNumbers(obj, factor)`: она умножает на `factor` все свойства объекта, значения которых — числа (проверяйте через `typeof`). Остальные свойства остаются как есть. Объект нужно изменить на месте, возвращать ничего не требуется.

```js
const menu = { width: 200, height: 300, title: 'My menu' };
scaleNumbers(menu, 2);
// menu: { width: 400, height: 600, title: 'My menu' }
```
