Напишите функцию `isEmpty(obj)`: она возвращает `true`, если у объекта нет ни одного свойства, и `false` в противном случае.

```js
const schedule = {};
isEmpty(schedule);          // true
schedule['8:30'] = 'get up';
isEmpty(schedule);          // false
```
