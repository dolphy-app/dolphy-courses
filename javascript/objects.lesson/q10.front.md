Напишите функцию `makeOption(key, value)`. Она возвращает объект с тремя свойствами: `key` и `value` (со значениями аргументов) и свойством, имя которого равно значению `key`, а значение — `value`.

```js
makeOption('theme', 'dark');
// { key: 'theme', value: 'dark', theme: 'dark' }
```

Используйте короткую запись свойств и вычисляемое имя.
