В классе `Stack` внутренний массив доступен снаружи. Сделайте его приватным, не меняя публичный интерфейс: `push(x)`, `pop()`, `peek()`, геттер `size`. Метод `pop` пустого стека возвращает `undefined`.

```js
const s = new Stack();
s.push(1);
s.items; // undefined
```
