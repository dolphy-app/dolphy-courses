Напишите класс `Password`. Значение хранится приватно и недоступно для чтения. Методы:

- `set(value)` — сохраняет пароль; если длина меньше 6 символов, бросает `RangeError` и прежнее значение остаётся;
- `check(input)` — `true`, если `input` совпадает с сохранённым;
- геттер `masked` — строка из `*` длиной с пароль (пока пароль не задан — пустая строка).

```js
const p = new Password();
p.set('secret1');
p.check('secret1'); // true
p.masked; // '*******'
```
