Напишите класс `Account`. Баланс хранится в приватном поле, начальное значение — аргумент конструктора (по умолчанию `0`). Геттер `balance` возвращает баланс. Метод `deposit(sum)` пополняет счёт, `withdraw(sum)` списывает; оба принимают только положительные числа, иначе бросают `RangeError`, а `withdraw` ещё и `RangeError` при нехватке средств. Баланс при ошибке не меняется. Оба метода возвращают `this`.

```js
const acc = new Account(100);
acc.deposit(50).withdraw(30).balance; // 120
```
