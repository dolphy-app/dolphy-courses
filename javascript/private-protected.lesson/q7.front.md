Напишите класс `Brand` с приватным полем и статическим методом `Brand.isBrand(value)`. Он возвращает `true` только для объектов, действительно созданных конструктором `Brand`, и `false` для любых других значений (включая `null`, примитивы и объекты, у которых просто прототип `Brand.prototype`).

```js
Brand.isBrand(new Brand()); // true
Brand.isBrand(Object.create(Brand.prototype)); // false
Brand.isBrand(null); // false
```
