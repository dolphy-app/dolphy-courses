Напишите функцию `unique(items)`, которая возвращает новый массив без повторов. Порядок — по первому появлению элемента. Сравнение строгое (`1` и `'1'` — разные). Исходный массив менять нельзя.

```js
unique(['Hare', 'Krishna', 'Hare', 'Krishna']); // [ 'Hare', 'Krishna' ]
```
