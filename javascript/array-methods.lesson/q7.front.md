Напишите функцию `filterRangeInPlace(arr, a, b)`, которая **изменяет** массив `arr`: оставляет только элементы от `a` до `b` включительно, порядок сохраняется. Новый массив создавать не нужно.

```js
const arr = [5, 3, 8, 1];
filterRangeInPlace(arr, 1, 4);
console.log(arr); // [ 3, 1 ]
```
