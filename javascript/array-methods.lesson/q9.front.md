Есть массив пользователей вида `{ id, name, surname }`. Напишите функцию `toFullNames(users)`, которая возвращает новый массив объектов `{ fullName, id }`, где `fullName` — это имя и фамилия через пробел. Исходные объекты менять нельзя.

```js
toFullNames([{ id: 1, name: 'Вася', surname: 'Пупкин' }]);
// [ { fullName: 'Вася Пупкин', id: 1 } ]
```
