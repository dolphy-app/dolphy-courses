Напишите функцию `camelize(str)`, которая превращает строку вида `'background-color'` в `'backgroundColor'`: убирает дефисы, а буква после каждого дефиса становится заглавной. Дефис в начале тоже убирается, следующая буква становится заглавной: `'-webkit-transition'` → `'WebkitTransition'`.

```js
camelize('list-style-image'); // 'listStyleImage'
camelize('color'); // 'color'
```
