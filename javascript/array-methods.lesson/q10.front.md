Напишите функцию `groupById(users)`, которая принимает массив объектов с уникальными числовыми или строковыми полями `id` и возвращает объект-словарь: ключ — `id`, значение — сам объект пользователя. Решите задачу через `reduce`.

```js
groupById([{ id: 'a1', age: 20 }, { id: 'b2', age: 30 }]);
// { a1: { id: 'a1', age: 20 }, b2: { id: 'b2', age: 30 } }
```
