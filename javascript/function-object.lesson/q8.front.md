Напишите функцию `withCallCount(fn)`, которая возвращает обёртку над `fn`. Обёртка передаёт в `fn` все свои аргументы, возвращает её результат и увеличивает свойство `calls` — число своих вызовов (до первого вызова `calls` равно `0`).

```js
const f = withCallCount((x) => x * 2);
f(2); // 4
f(5); // 10
f.calls; // 2
```
