Напишите функцию `makeCounter()`, которая возвращает функцию-счётчик `counter`:

- каждый вызов `counter()` увеличивает значение на 1 и возвращает его (первый вызов даёт `1`);
- свойство `counter.current` содержит последнее значение (до первых вызовов — `0`);
- метод `counter.reset()` сбрасывает значение в `0`.

Значение должно храниться именно в свойстве `current`: если присвоить `counter.current = 10`, следующий вызов вернёт `11`. Счётчики, созданные разными вызовами `makeCounter`, независимы.

```js
const counter = makeCounter();
counter(); // 1
counter(); // 2
counter.current; // 2
```
