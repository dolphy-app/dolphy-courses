Функция `makeFactorial()` возвращает функцию, считающую факториал. Сейчас рекурсия выполнена через повторный вызов фабрики. Перепишите её так, чтобы возвращаемая функция была **именованным функциональным выражением** с именем `fact` и вызывала сама себя по этому имени.

```js
const f = makeFactorial();
f(5); // 120
f.name; // 'fact'
```
