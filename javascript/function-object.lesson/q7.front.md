Напишите функцию `sum`, которая работает с любым количеством последовательных вызовов:

```js
+sum(1)(2); // 3
+sum(1)(2)(3); // 6
+sum(1)(2)(3)(4); // 10
```

Результат любого вызова — функция, которую можно вызвать ещё раз, а при приведении к числу (унарный `+`, `==`) она даёт накопленную сумму. Подсказка: у объектов есть метод `valueOf`, а функция — тоже объект.
