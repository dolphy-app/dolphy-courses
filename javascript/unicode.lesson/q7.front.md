Напишите функцию `toCodePoints(str)`, которая возвращает массив кодовых точек строки в виде `'U+XXXX'`: hex-число в верхнем регистре, минимум четыре цифры (дополняйте нулями слева). Суррогатная пара — один элемент.

```js
toCodePoints('A');  // ['U+0041']
toCodePoints('😀'); // ['U+1F600']
```
