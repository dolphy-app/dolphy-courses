Напишите функцию `truncate(str, n)`: она возвращает первые `n` **символов** (кодовых точек) строки. Эмодзи и другие символы вне базовой плоскости нельзя разрезать пополам. Если `n` больше длины, вернуть строку целиком; при `n = 0` — пустую строку.

```js
truncate('a😀b', 2); // 'a😀'
```
