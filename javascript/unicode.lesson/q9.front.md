Напишите функцию `sameText(a, b)`, которая возвращает `true`, если строки состоят из одних и тех же символов с точностью до формы записи (составной или с combining-знаками). Регистр и сами буквы при этом различаются: `'a'` и `'A'` — разные.

```js
sameText('caf\u00e9', 'cafe\u0301'); // true
sameText('cafe', 'caf\u00e9');       // false
```
