          const result = {};

Эмулируйте `export { a as x }`. `renameExports(ns, map)` возвращает новый объект, в котором ключи из `map` (`{ старое: 'новое' }`) заменены, остальные остались как есть.

Бросайте `Error`, если в `ns` нет переименовываемого ключа или если в результате два экспорта получили одно имя. Обмен именами (`{ a: 'b', b: 'a' }`) допустим. `ns` не изменяется.
