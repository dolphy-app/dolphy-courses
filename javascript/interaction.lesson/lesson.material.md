# Взаимодействие: alert, prompt, confirm

Для первых экспериментов в браузере есть три встроенные функции, которые общаются с пользователем через модальные окна: `alert`, `prompt` и `confirm`. Они устарели для реальных интерфейсов, но на них удобно разобрать важную идею — что функция получает, что возвращает и какого типа это значение. Эти функции есть только в браузере: в Node.js (где выполняются задания курса) их нет.

## alert

`alert(message)` показывает окно с сообщением и кнопкой «OK». Пока окно открыто, выполнение страницы приостановлено.

```js
// только в браузере
alert('Привет!');
```

Возвращает `undefined`.

## prompt

`prompt(title, default)` показывает окно с полем ввода. Второй параметр — необязательное начальное значение поля.

```js
// только в браузере
const age = prompt('Сколько вам лет?', '18');
```

Что вернёт вызов:

- **строку** с введённым текстом, если пользователь нажал «OK» — даже если ввёл число;
- **пустую строку**, если поле осталось пустым и нажато «OK»;
- **`null`**, если пользователь нажал «Отмена» или Esc.

Из-за последнего пункта возвращаемое значение нужно проверять: `null` — не строка и ведёт себя иначе.

Самая частая ошибка — забыть, что ответ всегда строка. Тогда `+` склеивает, а не складывает:

```js
const a = '2';
const b = '3';
console.log(a + b);                  // 23
console.log(Number(a) + Number(b));  // 5
```

`Number(...)` переводит строку в число; подробно преобразования типов — в следующих уроках. Ввод, который не похож на число, превратится в `NaN`:

```js
console.log(Number('1.5')); // 1.5
console.log(Number(''));    // 0
console.log(Number('abc')); // NaN
```

## confirm

`confirm(question)` показывает окно с вопросом и двумя кнопками. Результат — булево значение: `true` для «OK» и `false` для «Отмена».

```js
// только в браузере
const isReady = confirm('Начать?');
```

## Как мы делаем это в курсе

Браузерных окон в Node.js нет, поэтому задачи про ввод пользователя формулируются иначе. Результат вызова `prompt` — просто значение; поэтому мы пишем **функцию, которая принимает такое значение** и возвращает результат. Например, «пользователь ввёл два числа» превращается в функцию двух строковых аргументов, а «нажал Отмена» — в аргумент `null`.

```js
function sumAnswers(a, b) {
  return Number(a) + Number(b);
}
console.log(sumAnswers('2', '3')); // 5
```

Такой подход полезен и в реальной работе: функция, которая не обращается к окнам, легко проверяется автоматически — достаточно подставить значения.

## Ограничения модальных окон

- Окно блокирует страницу: пользователь не может ничего сделать, пока не закроет его.
- Нельзя изменить оформление окон — это решает браузер.
- Положение окна выбирает браузер, а не разработчик.

Поэтому в реальных приложениях делают собственные диалоги на HTML и CSS. Но для обучающих примеров и быстрой отладки три функции остаются самым коротким способом получить ответ.

## Типичные ошибки

- Складывать ответы `prompt` как числа без преобразования: получится склейка строк.
- Не учитывать `null` при нажатии «Отмена».
- Вызывать `alert`, `prompt` или `confirm` в Node.js: будет `ReferenceError`.
- Ожидать, что `alert` вернёт что-то полезное.

## Коротко

- `alert` показывает сообщение и возвращает `undefined`.
- `prompt` возвращает строку или `null` (при отмене).
- `confirm` возвращает `true` или `false`.
- Все три — функции браузера, они блокируют страницу и не настраиваются.
- В заданиях курса вместо окон мы пишем функции, принимающие готовые значения.
