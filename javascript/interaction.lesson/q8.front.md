Напишите функцию `greet(answer)`, которая обрабатывает результат `prompt('Ваше имя?')`:

- `null` (нажата «Отмена») → `'Вход отменён'`;
- пустая строка → `'Привет, гость!'`;
- иначе → `'Привет, <answer>!'`.

```js
greet('Аня'); // 'Привет, Аня!'
greet('');    // 'Привет, гость!'
greet(null);  // 'Вход отменён'
```
