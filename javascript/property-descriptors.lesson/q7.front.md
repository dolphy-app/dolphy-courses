Напишите функцию `defineConstant(obj, name, value)`: она создаёт в `obj` свойство `name` со значением `value`, которое нельзя переписать и удалить, но которое видно при переборе. Верните `obj`.

```js
const cfg = defineConstant({}, 'LIMIT', 10);
cfg.LIMIT = 99;
cfg.LIMIT; // 10
```
