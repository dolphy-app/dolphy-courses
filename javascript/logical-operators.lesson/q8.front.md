Напишите функцию `isOpen(hour, isHoliday)`: `hour` — целый час от 0 до 23, `isHoliday` — булево значение (или `undefined`, тогда считаем, что не праздник). Функция возвращает `true`, если офис открыт, и `false` в остальных случаях. Результат всегда булев.

```js
isOpen(12, false); // true
isOpen(18, false); // false
isOpen(12, true);  // false
```
