# Логические операторы

Операторы `||` (ИЛИ), `&&` (И) и `!` (НЕ) нужны не только для составных условий в `if`. В JavaScript они работают с любыми значениями и возвращают не обязательно `true` или `false`, а один из своих операндов. Благодаря этому на них строятся значения по умолчанию, защитные проверки и «ленивые» вычисления. Ещё есть операторы присваивания `||=` и `&&=`. После урока вы сможете читать и писать такие выражения и будете знать, где они ведут себя неожиданно.

Четвёртый «логический» оператор, `??`, и его присваивание `??=` разбираются в следующей теме.

## || (ИЛИ)

Обычное применение — условие «выполнено хотя бы одно из». Результат `false` только тогда, когда ложны оба операнда:

```js
console.log(true || false);  // true
console.log(false || false); // false

const hour = 22;
const isHoliday = false;
console.log(hour < 9 || hour > 18 || isHoliday); // true
```

Операнды не обязаны быть булевыми. Внутри условия `if` значение приводится к `true`/`false`, как вы видели в теме про условные операторы. Но сам оператор возвращает не результат приведения, а исходное значение.

### Первое истинное значение

`a || b || c` работает так:

1. Вычисляет операнды слева направо.
2. Приводит каждый к булевому типу. Если получилось `true`, останавливается и **возвращает сам операнд** (не `true`).
3. Если все ложны, возвращает последний операнд.

```js
console.log(1 || 0);                  // 1
console.log(0 || 'text');             // text
console.log(null || 0 || 5);          // 5
console.log(undefined || null || 0);  // 0 (все ложны, вернулся последний)
console.log('' || 0);                 // 0
```

Типичное применение — значение по умолчанию:

```js
const firstName = '';
const lastName = '';
const nickName = 'Neo';

console.log(firstName || lastName || nickName || 'Аноним'); // Neo
```

Если бы все три переменные были пустыми, результатом стала бы строка `'Аноним'`.

### Сокращённое вычисление

Как только `||` находит истинное значение, остальные операнды **не вычисляются вообще**. Это важно, если справа стоит вызов функции или присваивание: побочный эффект не произойдёт.

```js
const calls = [];
const check = (name, value) => {
  calls.push(name);
  return value;
};

check('a', 0) || check('b', 'x') || check('c', 1);
console.log(calls); // [ 'a', 'b' ]  (c не вызывалась)
```

## && (И)

Результат `true` только если истинны оба операнда:

```js
console.log(true && true);   // true
console.log(true && false);  // false

const age = 20;
console.log(age >= 18 && age <= 65); // true
```

Для произвольных значений `&&` — зеркало `||`: он возвращает **первое ложное** значение, а если все истинны — последнее.

```js
console.log(1 && 5);               // 5
console.log(0 && 5);               // 0
console.log(1 && 2 && null && 3);  // null
console.log(1 && 2 && 3);          // 3
```

Сокращённое вычисление здесь тоже работает, но в обратную сторону: вычисление останавливается на первом ложном операнде.

```js
const calls = [];
const check = (name, value) => {
  calls.push(name);
  return value;
};

check('a', 1) && check('b', 0) && check('c', 2);
console.log(calls); // [ 'a', 'b' ]
```

Частый приём — защита от «пустого» значения перед обращением к свойству или вызовом:

```js
const user = { name: 'Ann' };
console.log(user && user.name); // Ann

const empty = null;
console.log(empty && empty.name); // null (обращения к .name не было)

function run(callback) {
  callback && callback(); // вызов только если callback передан
}
run();
```

### Приоритет

`&&` выполняется раньше `||`, так что `a && b || c && d` это то же, что `(a && b) || (c && d)`. Скобки лишними не бывают, когда в выражении встречаются оба оператора:

```js
console.log(null || 2 && 3 || 4);   // 3  (2 && 3 -> 3, затем null || 3)
console.log((null || 2) && 3);      // 3
console.log(true || false && false); // true
```

Сравнения (`<`, `>`, `===`) выполняются раньше `&&` и `||`, поэтому `hour < 9 || hour > 18` скобок не требует.

## ! (НЕ)

Оператор берёт один операнд, приводит его к булевому типу и возвращает противоположное значение. Результат всегда `true` или `false`:

```js
console.log(!true); // false
console.log(!0);    // true
```

Приоритет `!` выше, чем у `&&` и `||`, он применяется первым:

```js
console.log(!true || true);   // true  ((!true) || true)
console.log(!(true || true)); // false
```

Двойное отрицание `!!x` — короткий способ получить булево значение, как у `Boolean(x)`:

```js
console.log(!!'text');     // true
console.log(!!null);       // false
console.log(Boolean('text')); // true
console.log(!!'0', !![], !!{}); // true true true
console.log(!!NaN, !!' ');      // false true
```

Строка `'0'`, пустой массив `[]`, пустой объект `{}` и строка из пробела — истинные значения. Ложных всего несколько: `false`, `0` (и `-0`), `0n`, `''`, `null`, `undefined`, `NaN`.

## ||= и &&= (логическое присваивание)

Это сокращённая запись двух типичных конструкций:

```js
a ||= b;  // как a || (a = b): присвоить, только если a ложно
a &&= b;  // как a && (a = b): присвоить, только если a истинно
```

Правая часть вычисляется лишь в том случае, когда присваивание действительно происходит. Это не то же самое, что `a = a || b`: при обычной записи присваивание выполняется всегда, а `||=` вообще не трогает `a`, если оно истинно.

```js
let title = '';
title ||= 'Без названия';
console.log(title); // Без названия

let greeting = 'Привет';
greeting &&= greeting + ', мир!';
console.log(greeting); // Привет, мир!

let name = null;
name &&= name.trim(); // name ложно, правая часть не выполняется
console.log(name); // null
```

Операторы поддерживаются в Node.js начиная с 15-й версии и во всех современных браузерах. `||=` встречается часто, `&&=` заметно реже.

## Типичные ошибки

> [!WARNING]
>
> **`||` для значений по умолчанию подменяет и допустимые «ложные» значения.** Для `0`, `''` и `false` он тоже выберет запасное:
>
> ```js
> const volume = 0; // пользователь осознанно выключил звук
> console.log(volume || 50); // 50 (звук включился)
> console.log(volume ?? 50); // 0  (?? реагирует только на null и undefined)
> ```
>
> Если ноль, пустая строка или `false` — допустимые данные, используйте `??` (следующая тема).
>
> **`&&` и `||` вместо `if` ради краткости.** Запись `cond && doSomething()` работает, но читается хуже, чем `if (cond) doSomething()`. Оставьте `&&` для случаев, когда вам нужно именно значение выражения.
>
> **Забыли, что результат — не булево.** `1 && 'a'` вернёт `'a'`, а не `true`. Если нужен именно `true`/`false`, оберните в `Boolean(...)` или `!!`.
>
> **Путаница с приоритетом.** `a || b && c` — это `a || (b && c)`, а не `(a || b) && c`. Расставляйте скобки.
>
> **Смешивание с `??` без скобок.** Выражение `a || b ?? c` — синтаксическая ошибка (`SyntaxError`): нужно явно написать `(a || b) ?? c`.

## Коротко

> [!TIP]
>
> - `||` возвращает первый истинный операнд, а если таких нет — последний. `&&` возвращает первый ложный, а если таких нет — последний.
> - Оба оператора вычисляют операнды слева направо и останавливаются, как только результат ясен; оставшиеся операнды и их побочные эффекты пропускаются.
> - Приоритеты по убыванию: `!`, затем `&&`, затем `||`. При сомнении ставьте скобки.
> - `!x` всегда возвращает булево значение; `!!x` — то же, что `Boolean(x)`.
> - `a ||= b` присваивает, только если `a` ложно; `a &&= b` — только если `a` истинно.
> - Для значений по умолчанию `||` игнорирует допустимые `0`, `''` и `false`; в таких случаях нужен `??`.
