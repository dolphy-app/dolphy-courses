Напишите функцию `displayName(user)`. Она принимает объект с необязательными строковыми свойствами `nickName` и `firstName` и возвращает имя для показа:

- `nickName`, если он непустой;
- иначе `firstName`, если он непустой;
- иначе строку `'Аноним'`.

```js
displayName({ nickName: '', firstName: 'Tom' }); // 'Tom'
displayName({}); // 'Аноним'
```
