Напишите функцию `firstTruthy(...getters)`. Она принимает функции без аргументов и вызывает их по порядку, как это делала бы цепочка `getters[0]() || getters[1]() || ...`:

- возвращает результат первой функции, давшей истинное значение, и больше ничего не вызывает;
- если все результаты ложны, возвращает результат последней вызванной функции;
- если функций нет, возвращает `undefined`.

```js
firstTruthy(() => 0, () => 'a', () => 'b'); // 'a'
firstTruthy(() => null, () => 0);           // 0
```
