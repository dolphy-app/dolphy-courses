Напишите функцию `applyDefaults(options)`, которая **изменяет** переданный объект и возвращает его же:

- если `options.title` ложно (пустая строка, `undefined` и т. п.), записать в него `'Без названия'`;
- если `options.name` истинно, обрезать у него пробелы по краям (`trim()`); если оно ложно, свойство трогать не нужно (и не создавать, если его не было).

Подумайте, какие операторы присваивания здесь уместны (`||=`, `&&=`) и какие ограничения у каждого.

```js
const o = { title: '', name: '  Ann ' };
applyDefaults(o); // { title: 'Без названия', name: 'Ann' }
```
