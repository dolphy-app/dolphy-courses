Напишите функцию `loadAll(ids, load)`. Функция `load(id)` возвращает промис. `loadAll` запускает загрузки для всех `ids` **параллельно** (одновременно) и возвращает промис с массивом результатов в порядке `ids`. Если любая загрузка завершилась ошибкой, результат отклоняется. Функция `load` должна вызываться с одним аргументом — `id`.
