Напишите функцию `withTimeout(promise, ms)`. Если `promise` выполнился или отклонился в течение `ms` миллисекунд, результат повторяет его исход (ошибка пробрасывается как есть). Иначе результат отклоняется ошибкой `Error`, в сообщении которой есть слово `timeout`.
