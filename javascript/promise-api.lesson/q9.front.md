Напишите функцию `mapLimit(items, limit, worker)`. Функция `worker(item)` возвращает промис. `mapLimit` обрабатывает элементы **параллельно**, но одновременно выполняется не более `limit` задач: как только одна завершилась, стартует следующая. Результат — промис с массивом значений в порядке `items`. Если любой `worker` отклонился, результат отклоняется.
