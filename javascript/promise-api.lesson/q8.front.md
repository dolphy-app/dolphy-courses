          const results = await Promise.allSettled(promises);
          const values = [];
          const errors = [];

Напишите функцию `summarize(promises)`. Она ждёт завершения всех промисов (даже неудачных) и возвращает промис с объектом `{ values, errors }`:

- `values` — результаты успешных промисов в порядке входа;
- `errors` — сообщения (`message`) ошибок отклонённых промисов в порядке входа.

Результат функции никогда не отклоняется.
