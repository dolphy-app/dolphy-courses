Напишите стрелочную функцию `evenSquares(numbers)`: она принимает массив чисел и возвращает новый массив с квадратами только чётных элементов в исходном порядке. Исходный массив менять нельзя.

```js
evenSquares([1, 2, 3, 4]); // [4, 16]
evenSquares([5, 7]); // []
```

Подсказка: пригодятся методы `filter` и `map` со стрелками-коллбэками.
