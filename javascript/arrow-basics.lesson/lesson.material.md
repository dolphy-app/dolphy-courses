# Стрелочные функции: основы

Function Expression — не единственный способ создать функцию «на месте». Есть более короткая запись: стрелочная функция (arrow function). Она особенно хороша там, где функция нужна на одну строку: в коллбэках для `map`, `filter`, `sort` и в небольших вспомогательных обёртках. После урока вы сможете читать и писать стрелки во всех их базовых формах и знать, где они подводят.

## Базовый синтаксис

Общий вид: список параметров, стрелка `=>`, затем выражение. Значение выражения становится результатом вызова, слово `return` не нужно:

```js
const sum = (a, b) => a + b;
console.log(sum(1, 2)); // 3
```

Это короткая форма такого Function Expression:

```js
const sum = function (a, b) {
  return a + b;
};
console.log(sum(1, 2)); // 3
```

Стрелка — тоже значение: её можно присвоить переменной, передать аргументом, вернуть из другой функции или вызвать сразу:

```js
console.log((x => x + 1)(5)); // 6
console.log(typeof sum); // function
```

### Скобки вокруг параметров

Если параметр один и он «простой» (только имя), скобки можно опустить. Если параметров нет, скобки обязательны, но пустые:

```js
const double = n => n * 2;
const hello = () => 'Привет';

console.log(double(3)); // 6
console.log(hello()); // Привет
```

Для двух и более параметров скобки нужны всегда: запись `const f = n, m => n + m` — синтаксическая ошибка: движок читает `n, m` как два объявления через запятую. Скобки нужны и тогда, когда у параметра есть значение по умолчанию, rest-параметр или деструктуризация:

```js
const total = (a, b = 10, ...rest) => a + b + rest.length;
const area = ({ w, h }) => w * h;
const first = ([head]) => head;

console.log(total(1)); // 11
console.log(total(1, 2, 3, 4)); // 5
console.log(area({ w: 3, h: 4 })); // 12
console.log(first([7, 8])); // 7
```

Многие команды ставят скобки всегда, даже для одного параметра: `(n) => n * 2`. Оба варианта корректны, главное — единообразие в проекте.

## Тело в фигурных скобках

Когда нужно несколько инструкций, тело оборачивают в `{ ... }`. Но тогда это уже обычное тело функции: значение вернётся только через явный `return`:

```js
const sumSquares = (a, b) => {
  const sa = a * a;
  const sb = b * b;
  return sa + sb;
};
console.log(sumSquares(2, 3)); // 13
```

Самая частая ошибка новичков — поставить скобки и забыть `return`. Функция выполнится без ошибок и вернёт `undefined`:

```js
const broken = (a, b) => {
  a + b;
};
console.log(broken(1, 2)); // undefined
```

Из-за этого `[1, 2, 3].map(n => { n * 2 })` даёт `[undefined, undefined, undefined]`, а `[1, 2, 3].map(n => { return n * 2 })` или `[1, 2, 3].map(n => n * 2)` — `[2, 4, 6]`.

## Возврат объектного литерала

Фигурные скобки после стрелки движок всегда считает началом тела функции, а не объектом. Поэтому «короткая» запись возврата объекта ведёт себя неожиданно:

```js
const bad = () => { id: 1 };
console.log(bad()); // undefined
```

Здесь `{ ... }` — тело функции, а `id: 1` внутри него — метка (label) и выражение `1`. Никакой объект не создаётся. Запись `{ name, active: true }` в такой позиции вообще даёт `SyntaxError`. Выход — обернуть объект в круглые скобки, тогда это выражение:

```js
const makeUser = name => ({ name, active: true });
console.log(makeUser('Аня')); // { name: 'Аня', active: true }
```

Альтернатива — тело в фигурных скобках с явным `return { ... }`.

## Стрелки как значения и коллбэки

Стрелки хорошо читаются там, где функция передаётся как аргумент:

```js
console.log([1, 2, 3].map(x => x * x)); // [ 1, 4, 9 ]
console.log([1, 2, 3, 4].filter(x => x % 2 === 0)); // [ 2, 4 ]
console.log([3, 1, 2].sort((a, b) => a - b)); // [ 1, 2, 3 ]
```

Стрелку можно выбирать динамически, например тернарным оператором:

```js
const age = 20;
const welcome = age < 18
  ? () => 'Привет!'
  : () => 'Здравствуйте!';
console.log(welcome()); // Здравствуйте!
```

Стрелка может возвращать другую стрелку — получается цепочка вызовов:

```js
const add = a => b => a + b;
console.log(add(1)(2)); // 3
console.log(typeof add(1)); // function
```

Читается слева направо: `add` принимает `a` и возвращает функцию `b => a + b`, которая «помнит» `a` благодаря замыканию.

## Что ещё полезно знать

- **Имя.** Стрелка, присвоенная переменной, получает имя этой переменной, а `length` равна числу обязательных параметров: `sum.name` — `'sum'`, `sum.length` — `2`.
- **Стрелка до объявления недоступна.** Это не Function Declaration, а значение в `const`/`let`, поэтому вызов выше объявления даст `ReferenceError: Cannot access 'run' before initialization`.
- **Стрелка не конструктор.** `new sum(1, 2)` выбрасывает `TypeError: sum is not a constructor`.
- **Перед `=>` строку переносить нельзя.** Перенос между параметрами и `=>` — `SyntaxError`; после стрелки переносить можно.
- **Отличия «под капотом».** У стрелочной функции нет собственных `this` и `arguments`; они берутся из внешней области. Подробно это разберём в теме про стрелки в углублённой части курса, а пока используйте стрелки для простых действий и коллбэков.

## Типичные ошибки

- Забытый `return` при фигурных скобках (получаете `undefined`).
- Объект без круглых скобок: `() => { id: 1 }`.
- Скобки вокруг двух и более параметров опущены: `a, b => a + b`.
- `x => return x + 1` — `return` внутри выражения недопустим, используйте либо `x => x + 1`, либо `x => { return x + 1; }`.
- Слишком длинная однострочная стрелка: если выражение не помещается в строку, перейдите на тело в скобках — читаемость важнее краткости.

## Коротко

- `(a, b) => выражение` возвращает значение выражения без `return`.
- Скобки у параметров можно опустить только для одного простого параметра; для нуля параметров они пустые.
- С телом `{ ... }` нужен явный `return`, иначе результат — `undefined`.
- Объектный литерал в коротком теле оборачивайте в круглые скобки: `() => ({ a: 1 })`.
- Стрелки удобны для коллбэков и маленьких функций; у них нет `this`, `arguments` и вызова через `new`.
