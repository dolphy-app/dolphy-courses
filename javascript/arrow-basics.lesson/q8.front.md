Напишите функцию `createGreeter(formal)`. Она возвращает другую функцию: та принимает имя и возвращает строку-приветствие. Если `formal` истинно — `'Здравствуйте, <имя>!'`, иначе — `'Привет, <имя>!'`.

```js
createGreeter(false)('Аня'); // 'Привет, Аня!'
createGreeter(true)('Аня'); // 'Здравствуйте, Аня!'
```
