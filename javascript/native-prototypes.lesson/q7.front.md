Псевдомассив — объект с числовыми ключами и `length`. Напишите функцию `mapLike(arrayLike, fn)`, которая применяет `fn` к каждому элементу псевдомассива и возвращает **настоящий массив** результатов. Исходный объект не меняется.

```js
mapLike({ 0: 'a', 1: 'b', length: 2 }, (x) => x + x); // ['aa', 'bb']
```
