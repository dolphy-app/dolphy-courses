Напишите функцию `typeName(value)`. Она возвращает «внутренний тип» значения строчными буквами — то, что стоит после `object ` в результате `Object.prototype.toString.call(value)`.

```js
typeName(null); // 'null'
typeName([]); // 'array'
typeName(new Date()); // 'date'
```
