Добавьте в `String.prototype` метод `capitalize()`. Он возвращает строку, в которой первая буква заглавная, остальные символы не меняются. Для пустой строки результат — пустая строка. Метод должен быть **неперечислимым**: используйте `Object.defineProperty`.

```js
'привет мир'.capitalize(); // 'Привет мир'
```
