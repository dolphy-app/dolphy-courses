        function protoNames(value) {
          if (value === null || value === undefined) return [];
          const names = [];
          let proto = Object.getPrototypeOf(Object(value));
          while (proto !== null) {
            names.push(proto.constructor.name);
            proto = Object.getPrototypeOf(proto);

          return names;

Напишите функцию `protoNames(value)`. Она возвращает массив имён конструкторов всех прототипов значения (поле `constructor.name`), от ближайшего к дальнему. Для примитивов смотрите на прототип соответствующей обёртки. Для `null` и `undefined` результат — пустой массив.

```js
protoNames([]); // ['Array', 'Object']
protoNames(5); // ['Number', 'Object']
protoNames(null); // []
```
