Напишите функцию `withDefault(target, defaultValue)`, которая возвращает прокси над `target`.

- Чтение существующего свойства (включая значения `0` и `undefined`) работает как обычно.
- Чтение отсутствующего свойства возвращает `defaultValue`.
- Запись попадает в исходный `target`; сам `target` при чтении не меняется.

```js
const p = withDefault({ a: 1 }, 'none');
p.a;   // 1
p.zzz; // 'none'
```
