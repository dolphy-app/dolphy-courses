Напишите `logged(target, log)`: прокси, который при каждом чтении свойства добавляет в массив `log` строку `'get:<ключ>'`, а при записи — `'set:<ключ>'`. Чтение возвращает значение цели, запись сохраняет значение в цель и должна успешно работать и в строгом режиме.

```js
const log = [];
const p = logged({ a: 7 }, log);
p.a;      // 7
p.b = 1;
log;      // ['get:a', 'set:b']
```
