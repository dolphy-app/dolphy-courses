Напишите функцию `countReachable(root)`: она возвращает, сколько *различных* объектов достижимо из `root` по значениям свойств, включая сам `root`. Массивы тоже считаются объектами. Один и тот же объект, встреченный несколько раз, считается один раз; циклические ссылки не должны приводить к зацикливанию.

```js
const shared = {};
countReachable({ a: shared, b: shared, c: 1 }); // 2
```
