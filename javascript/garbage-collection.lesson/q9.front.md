        function sweep(graph, roots) {
          const seen = new Set();
          const stack = [...roots];
          while (stack.length > 0) {
            const name = stack.pop();
            if (seen.has(name)) continue;
            seen.add(name);
            for (const next of graph[name] || []) {
              stack.push(next);
            }
          }
          return Object.keys(graph).filter((name) => !seen.has(name)).sort();

Смоделируйте «вымётание» мусора. Память задана объектом `graph`: ключ — имя узла, значение — массив имён узлов, на которые он ссылается. `roots` — массив имён корней.

Напишите функцию `sweep(graph, roots)`, которая возвращает массив имён узлов, недостижимых из корней, в алфавитном порядке (`sort()`). Граф изменять нельзя.

```js
const graph = { root: ['a'], a: [], c: ['d'], d: ['c'] };
sweep(graph, ['root']); // ['c', 'd']
```
