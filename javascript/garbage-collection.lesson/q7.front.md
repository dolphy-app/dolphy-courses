Напишите функцию `isReachable(root, target)`: она возвращает `true`, если объект `target` достижим из `root` — то есть совпадает с ним или находится по цепочке значений свойств (в том числе внутри массивов). В данных могут быть циклические ссылки; примитивы и `null` нужно пропускать.

```js
const target = {};
isReachable({ a: { b: target } }, target); // true
isReachable({ a: {} }, target);            // false
```
