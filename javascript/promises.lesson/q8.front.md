Напишите функцию `loadUser(id)`, имитирующую загрузку. Она возвращает промис:

- если `id` не число, промис отклоняется `TypeError`;
- если `id` не положительное целое, отклоняется `RangeError`;
- иначе через 10–50 мс промис выполняется объектом `{ id, name: 'user' + id }`.

```js
loadUser(7).then(console.log); // { id: 7, name: 'user7' }
```
