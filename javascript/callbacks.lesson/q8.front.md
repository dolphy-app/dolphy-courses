Напишите функцию `mapSeries(items, worker, done)`.

- Для каждого элемента по очереди вызывается `worker(item, cb)`; следующий элемент запускается только после того, как предыдущий вызвал `cb(err, value)`.
- Когда все элементы обработаны, вызывается `done(null, results)`, где `results` — значения в порядке элементов.
- Если какой-то `worker` передал ошибку, обработка прекращается и вызывается `done(err)` (один раз).
