Напишите функцию `delayedSum(a, b, callback)`, которая вызывает `callback` **асинхронно** (не позднее чем через 50 мс) в стиле Node.js:

- если оба аргумента числа, то `callback(null, a + b)`;
- иначе `callback(error)`, где `error` — экземпляр `TypeError`.

Колбэк должен вызываться ровно один раз и никогда синхронно.

```js
delayedSum(2, 3, (err, sum) => console.log(err, sum)); // позже: null 5
```
