Асинхронные API иногда вызывают колбэк дважды. Напишите функцию `once(fn)`, которая возвращает обёртку: первый вызов выполняет `fn` с теми же аргументами и возвращает её результат, а все последующие вызовы ничего не делают и возвращают `undefined`.

```js
const cb = once((x) => console.log('получили', x));
cb(1); // получили 1
cb(2); // (ничего)
```
