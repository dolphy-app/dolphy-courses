Функция `safeParse(text, fallback)` должна разбирать JSON из строки `text` и возвращать результат, а при любой ошибке разбора — `fallback`. Сейчас она написана через `eval`, и поэтому выполняет любой код. Исправьте её так, чтобы принимался только настоящий JSON.

```js
safeParse('{"a":1}', null); // { a: 1 }
safeParse('{a:1}', null);   // null
```
