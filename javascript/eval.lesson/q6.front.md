Напишите `safeCalc(expr)`, которая вычисляет арифметическое выражение из строки: цифры, `+ - * /`, скобки, точка, пробелы. Любая строка с другими символами, пустая или синтаксически неверная должна приводить к исключению `Error`.

```js
safeCalc('2 * (3 + 4)'); // 14
safeCalc('process.exit()'); // бросает Error
```

Не используйте прямой `eval`.
