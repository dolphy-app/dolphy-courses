Напишите `evalWith(code, scope)`: вычисляет выражение из строки `code`, в котором как переменные доступны свойства объекта `scope`. Объект `scope` не изменяется. Используйте `new Function`, не прямой `eval`.

```js
evalWith('a * b + 1', { a: 2, b: 3 }); // 7
```
