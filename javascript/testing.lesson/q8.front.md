Напишите мини-раннер `runTest(title, fn)`. Он вызывает `fn` и возвращает объект:

- если `fn` завершилась без исключения: `{ title, ok: true }`;
- если бросила: `{ title, ok: false, message }`, где `message` — текст ошибки (`error.message` для `Error`, иначе `String(значение)`).

Исключение наружу выбрасываться не должно.
