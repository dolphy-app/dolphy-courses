Напишите функцию `sumUntilInvalid(inputs)`. Она получает массив введённых значений и суммирует их по порядку, пока не встретит значение, которое не является числом: `null`, пустую строку, строку из пробелов или нечисловую строку. Значения могут быть числами или числовыми строками (`'12'` считается числом 12). Остальное после первого некорректного значения игнорируется. Исходный массив менять нельзя.

```js
sumUntilInvalid([1, '2', 3.5]); // 6.5
sumUntilInvalid([4, 'abc', 10]); // 4
sumUntilInvalid([null, 5]); // 0
```
