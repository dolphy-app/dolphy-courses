Напишите функцию `maxSubSum(arr)`, которая принимает массив чисел и возвращает наибольшую сумму **непрерывной** части массива (подмассива). Подмассив может быть пустым, поэтому если все числа отрицательные (или массив пуст), ответ 0.

```js
maxSubSum([-1, 2, 3, -9]); // 5 (элементы 2 и 3)
maxSubSum([2, -1, 2, 3, -9]); // 6
maxSubSum([-1, -2, -3]); // 0
```
