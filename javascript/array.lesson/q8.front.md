Напишите функцию `editStyles(styles)`, которая **изменяет переданный массив** (чётной длины) по шагам:

1. добавляет в конец элемент `'Rock-n-Roll'`;
2. заменяет элемент в середине (теперь длина нечётная) на `'Classics'`;
3. удаляет первый элемент и запоминает его;
4. добавляет в начало `'Rap'` и `'Reggae'` (в таком порядке: сначала `'Rap'`).

Функция возвращает удалённый на шаге 3 элемент.

```js
const list = ['Jazz', 'Blues'];
editStyles(list); // 'Jazz'
console.log(list); // [ 'Rap', 'Reggae', 'Classics', 'Rock-n-Roll' ]
```
