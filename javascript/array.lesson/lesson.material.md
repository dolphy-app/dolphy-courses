# Массивы

Объекты хранят данные по ключам, но для упорядоченных списков — товаров в корзине, строк таблицы, очереди заданий — они неудобны. Для этого существует массив: коллекция значений, у каждого из которых есть номер. После урока вы сможете создавать массивы, менять их содержимое, перебирать элементы и понимать, почему массивы копируются «по ссылке».

## Создание и доступ

```js
const empty = [];
const fruits = ['яблоко', 'слива', 'груша'];
console.log(fruits[0]); // яблоко
console.log(fruits[2]); // груша
console.log(fruits.length); // 3
console.log(fruits.at(-1)); // груша — последний элемент
fruits[1] = 'персик'; // замена
fruits[3] = 'вишня'; // добавление в конец
console.log(fruits); // [ 'яблоко', 'персик', 'груша', 'вишня' ]
```

Нумерация идёт с нуля. Запись `new Array()` тоже работает, но почти не используется. Исключение — `new Array(3)` с одним числом: создаётся **пустой** массив длиной 3 (без самих элементов), а не массив `[3]`. Чтобы создать массив заданной длины с содержимым, пользуйтесь `new Array(3).fill(0)` или `Array.from({ length: 3 }, (_, i) => i * 2)`.

В массиве может лежать что угодно: числа, строки, объекты, функции, другие массивы. Последняя запятая допустима и ничего не значит.

## Массив — это объект

`typeof []` даёт `'object'`. Для проверки «это массив?» есть `Array.isArray`:

```js
console.log(typeof []); // object
console.log(Array.isArray([])); // true
console.log(Array.isArray({})); // false
```

Раз массив — объект, он копируется и сравнивается **по ссылке**. Присвоение не копирует содержимое:

```js
const a = [1, 2];
const b = a; // теперь обе переменные указывают на один массив
b.push(3);
console.log(a); // [ 1, 2, 3 ]
console.log(a === b); // true
console.log([1] == [1]); // false — два разных массива
```

Настоящие копии появятся в уроках про методы массивов и деструктуризацию.

## Методы концов массива

| Метод | Что делает | Возвращает |
|---|---|---|
| `push(...items)` | добавляет в конец | новую длину |
| `pop()` | удаляет последний | удалённый элемент |
| `shift()` | удаляет первый | удалённый элемент |
| `unshift(...items)` | добавляет в начало | новую длину |

```js
const c = ['x', 'y'];
console.log(c.push('z')); // 3
console.log(c.pop()); // z
console.log(c.shift()); // x
console.log(c.unshift('q', 'r')); // 3
console.log(c); // [ 'q', 'r', 'y' ]
```

Операции с концом (`push`, `pop`) быстрые. `shift` и `unshift` вынуждены перенумеровать все остальные элементы, поэтому на больших массивах медленнее. Для обычных задач разница не важна, но в очереди на миллионы элементов её стоит учитывать.

## Свойство length

`length` — это не количество элементов, а **наибольший индекс плюс один**. Его можно записывать: уменьшение обрезает массив, и данные не вернуть.

```js
const d = [1, 2, 3, 4];
d.length = 2;
console.log(d); // [ 1, 2 ]
d.length = 0; // быстрый способ очистить массив
console.log(d); // []

const sparse = [1];
sparse[3] = 4;
console.log(sparse.length); // 4
console.log(sparse); // [ 1, <2 empty items>, 4 ]
```

Если пропустить индексы, в массиве появляются «дыры». Так делать не стоит: многие методы ведут себя с дырами непредсказуемо, а движок хуже оптимизирует такой массив.

## Перебор

Для обычного обхода подходят цикл `for` с индексом и `for...of`, который выдаёт значения:

```js
const letters = ['a', 'b', 'c'];
for (let i = 0; i < letters.length; i++) {
  console.log(i, letters[i]); // 0 a, 1 b, 2 c
}
for (const letter of letters) {
  console.log(letter); // a, b, c
}
```

Цикл `for...in` тоже работает, но он перебирает **ключи** (строки '0', '1', …), включая любые дополнительные свойства массива, и медленнее. Для массивов его не применяют.

## Многомерные массивы и вывод

Массив массивов удобен для матриц: `matrix[1][0]` — элемент второй строки, первого столбца.

```js
const matrix = [
  [1, 2],
  [3, 4],
];
console.log(matrix[1][0]); // 3
```

У массивов своя реализация `toString`: элементы склеиваются через запятую, а вложенные массивы раскрываются. Поэтому арифметика с массивами порождает курьёзы:

```js
console.log(String([1, [2, 3]])); // 1,2,3
console.log([] + []); // '' — пустая строка
console.log([1, 2] + [3]); // 1,23
console.log([] == false); // true
```

Это следствие приведения объекта к примитиву, а не полезная возможность. Обычно такие выражения — признак ошибки в коде.

## Типичные ошибки

> [!WARNING]
>
> - Писать `arr.length()`: это свойство.
> - Считать `const arr = [...]` неизменяемым: константна ссылка, содержимое менять можно.
> - Присваивать `copy = arr` и ждать независимой копии.
> - Создавать `new Array(n)` и сразу вызывать `map`: «дыры» пропускаются.
> - Использовать `typeof` для проверки массива вместо `Array.isArray`.
> - Обращаться к элементу за границей и забывать, что результат — `undefined`, а не ошибка.

## Коротко

> [!TIP]
>
> - Массив — упорядоченная коллекция, индексы с нуля; последний элемент — `arr.at(-1)`.
> - `push`/`pop` работают с концом, `shift`/`unshift` — с началом; первые быстрее.
> - `length` равен наибольшему индексу плюс один и доступен для записи; `arr.length = 0` очищает массив.
> - Массив — объект: присваивание и `===` работают со ссылкой, а не с содержимым.
> - Обходите массив через `for...of` или `for` по индексу, не через `for...in`.
