Напишите функцию `ucFirst(str)`, которая возвращает строку, в которой первый символ переведён в верхний регистр, остальные не меняются. Для пустой строки возвращает пустую строку.

```js
ucFirst('вася'); // 'Вася'
ucFirst(''); // ''
```
