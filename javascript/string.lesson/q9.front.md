Напишите функцию `truncate(str, maxlength)`. Если длина `str` больше `maxlength`, функция возвращает строку длиной ровно `maxlength`: начало исходной строки и в конце один символ многоточия `'…'`. Если строка не длиннее, она возвращается без изменений. `maxlength` не меньше 1.

```js
truncate('Всё о JavaScript', 10); // 'Всё о Jav…'
truncate('Привет', 10); // 'Привет'
```
