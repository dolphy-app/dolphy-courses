# Строки

Строки хранят текст: от имени пользователя до целого HTML-документа. В JavaScript нет отдельного типа «символ» — символ это просто строка длиной 1. После урока вы будете уверенно записывать строки, обращаться к отдельным символам, искать подстроки, вырезать части и сравнивать тексты.

## Способы записи

Строку можно взять в одинарные, двойные или обратные кавычки. Первые два вида равнозначны. Обратные кавычки создают **шаблонную строку**: внутрь можно подставлять выражения через `${...}` и разносить текст на несколько строк.

```js
const a = 'одинарные';
const b = "двойные";
const price = 5;
const c = `Итого: ${price * 2} руб.`;
console.log(c); // Итого: 10 руб.

const multi = `первая
вторая`;
console.log(multi.length); // 13
```

Специальные символы записываются через обратную косую черту: `\n` — перевод строки, `\t` — табуляция, `\'` и `\"` — кавычки, `\\` — сама косая черта, `\u00a9` — символ по коду (`©`).

## Длина и доступ к символам

Свойство `length` — это число, а не метод: скобок нет. К символу обращаются по индексу в квадратных скобках (нумерация с нуля), либо через `at()`, который принимает отрицательные индексы — отсчёт с конца:

```js
const s = 'Hello';
console.log(s.length); // 5
console.log(s[0]); // H
console.log(s.at(-1)); // o
console.log(s[10]); // undefined
console.log(s.charAt(10) === ''); // true — charAt возвращает пустую строку
```

Строку можно перебрать циклом `for...of`. Он обходит строку по настоящим символам Unicode, а не по 16-битным частям:

```js
console.log('\u{1F600}'.length); // 2 — «смайлик» занимает два кодовых блока
console.log([...'\u{1F600}'].length); // 1
```

## Строки неизменяемы

Изменить символ внутри строки нельзя. Присваивание `s[0] = 'J'` в нестрогом режиме молча ничего не делает (в строгом — ошибка `TypeError`). Чтобы «изменить» строку, соберите новую:

```js
let s = 'Hello';
s = 'J' + s.slice(1);
console.log(s); // Jello
```

## Регистр

`toUpperCase()` и `toLowerCase()` возвращают новую строку. Они работают и с кириллицей, а иногда меняют длину: `'ß'.toUpperCase()` даёт `'SS'`.

## Поиск подстроки

- `indexOf(sub, from)` — позиция первого вхождения или `-1`; `lastIndexOf` ищет с конца.
- `includes(sub, from)`, `startsWith(sub)`, `endsWith(sub)` — возвращают boolean.

```js
const w = 'Widget with id';
console.log(w.indexOf('id')); // 1
console.log(w.indexOf('id', 2)); // 12 — ищем начиная с позиции 2
console.log(w.indexOf('xyz')); // -1
console.log(w.includes('with')); // true
console.log(w.startsWith('Wid')); // true
console.log(w.endsWith('get')); // false
```

Классическая ловушка: `indexOf` возвращает **0**, если подстрока в самом начале, а 0 в условии — ложь. Проверяйте результат явно: `if (str.indexOf(sub) !== -1)`, а лучше используйте `includes`.

## Получение подстроки

| Метод | Аргументы | Особенности |
|---|---|---|
| `slice(start, end)` | конец не включается | отрицательные значения считаются от конца |
| `substring(start, end)` | конец не включается | отрицательные считаются нулём; аргументы можно перепутать — поменяются местами |
| `substr(start, length)` | вторая цифра — длина | устарел, в новом коде не нужен |

```js
const t = 'stringify';
console.log(t.slice(0, 5)); // strin
console.log(t.slice(-4, -1)); // gif
console.log(t.slice(5, 2)); // '' — пустая строка
console.log(t.substring(5, 2)); // rin — аргументы поменялись местами
```

Для повседневной работы хватает `slice`: он предсказуем.

## Сравнение и сортировка

Строки сравниваются посимвольно по кодам Unicode, а не по алфавиту. Заглавные буквы идут перед строчными, а буквы с диакритикой оказываются в самом конце:

```js
console.log('a' > 'Z'); // true — код «a» (97) больше кода «Z» (90)
console.log(['Österreich', 'Zealand', 'Andorra'].sort());
// [ 'Andorra', 'Zealand', 'Österreich' ]
```

Для сравнения «по правилам языка» используйте `localeCompare`: он возвращает отрицательное число, 0 или положительное и подходит для сортировки:

```js
const names = ['Österreich', 'Zealand', 'Andorra'];
console.log(names.sort((x, y) => x.localeCompare(y)));
// [ 'Andorra', 'Österreich', 'Zealand' ]
```

## Полезные методы для преобразований

```js
console.log('  x '.trim() + '|'); // x|
console.log('5'.padStart(3, '0')); // 005
console.log('ab'.repeat(3)); // ababab
console.log('a,b,c'.split(',')); // [ 'a', 'b', 'c' ]
console.log('abc'.split('')); // [ 'a', 'b', 'c' ]
console.log(['a', 'b'].join('-')); // a-b
console.log('a-b-a'.replace('a', '_')); // _-b-a — только первое вхождение
console.log('a-b-a'.replaceAll('a', '_')); // _-b-_
console.log('a'.codePointAt(0)); // 97
console.log(String.fromCodePoint(90)); // Z
```

Пара `split` + `join` — стандартный способ заменить разделитель или перевернуть слова: `s.split(' ').reverse().join(' ')`.

## Типичные ошибки

- Вызывать `length()` как функцию.
- Ждать, что `toUpperCase()` изменит исходную переменную: нужно присвоить результат.
- Проверять `if (s.indexOf(x))` вместо сравнения с `-1`.
- Сортировать строки с национальными буквами без `localeCompare`.
- Считать `length` числом «видимых» символов: для эмодзи и составных знаков это не так.

## Коротко

- Три вида кавычек; шаблонные строки поддерживают `${выражение}` и многострочность.
- `length` — свойство; символ — `s[i]` или `s.at(i)`; строки неизменяемы.
- Поиск: `indexOf` (возвращает `-1` или позицию), `includes`, `startsWith`, `endsWith`.
- Подстрока: предпочтительно `slice(start, end)`; конец не включается.
- Сравнение идёт по кодам Unicode; для алфавитного порядка — `localeCompare`.
