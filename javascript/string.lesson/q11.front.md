Напишите функцию `countOccurrences(str, sub)`, которая возвращает, сколько раз непустая подстрока `sub` встречается в `str`. Вхождения не пересекаются: в `'aaaa'` подстрока `'aa'` встречается 2 раза.

```js
countOccurrences('abcabc', 'bc'); // 2
countOccurrences('aaaa', 'aa'); // 2
countOccurrences('abc', 'x'); // 0
```
