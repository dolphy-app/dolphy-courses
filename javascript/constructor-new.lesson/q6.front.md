Напишите конструктор `Calculator`. Объект, созданный через `new Calculator()`, должен иметь методы:

- `setValues(a, b)` — запоминает два числа;
- `sum()` — возвращает их сумму;
- `mul()` — возвращает их произведение.

```js
const calc = new Calculator();
calc.setValues(3, 4);
calc.sum(); // 7
calc.mul(); // 12
```
