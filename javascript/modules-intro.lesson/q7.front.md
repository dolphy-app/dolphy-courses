Эмулируйте живую привязку. `makeBinding(initial)` возвращает объект `{ binding, update }`:

- `binding.value` всегда возвращает **текущее** значение (как импортированное имя);
- `update(v)` меняет значение — это делает «экспортёр»;
- присваивание `binding.value = ...` должно бросать `TypeError`, значение при этом не меняется.
