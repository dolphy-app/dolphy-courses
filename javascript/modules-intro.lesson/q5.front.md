Эмулируйте «выполняется один раз». Напишите две функции:

- `defineModule(name, factory)` — регистрирует модуль: `factory` — функция без аргументов, возвращающая объект экспортов. Саму фабрику при регистрации **не вызывать**;
- `requireModule(name)` — при первом обращении вызывает фабрику и запоминает результат, при последующих возвращает **тот же** объект. Для незарегистрированного имени бросает `Error`.

Фабрика может сама вызывать `requireModule` для других модулей.
