Напишите функцию `extend(parent, props)`. Она возвращает **новый** объект, прототип которого — `parent`, а собственные свойства скопированы из `props`. Ни `parent`, ни `props` менять нельзя.

```js
const base = { hello() { return 'hi'; } };
const obj = extend(base, { id: 7 });
obj.id; // 7
obj.hello(); // 'hi'
Object.hasOwn(obj, 'hello'); // false
```
