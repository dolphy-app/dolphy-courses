Напишите функцию `findOwner(obj, key)`. Она возвращает тот объект цепочки прототипов (начиная с самого `obj`), у которого `key` является **собственным** свойством. Если свойства нет нигде, верните `null`.

```js
const a = { x: 1 };
const b = Object.create(a);
findOwner(b, 'x') === a; // true
findOwner(b, 'y'); // null
```
