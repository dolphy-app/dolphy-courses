Стеки, созданные `createStack`, делят один массив `items` из общего прототипа. Исправьте `createStack` так, чтобы у каждого стека был свой массив, а методы по-прежнему брались из `stackProto` (копировать их в объект нельзя).

```js
const s1 = createStack();
const s2 = createStack();
s1.push(1);
s2.size(); // 0
```
