Напишите функцию `getChain(obj)`. Она возвращает массив всех прототипов объекта: от ближайшего к самому далёкому. Сам `obj` в массив не входит. У объекта без прототипа результат — пустой массив.

```js
const a = {};
const b = Object.create(a);
getChain(b); // [a, Object.prototype]
getChain(Object.create(null)); // []
```
