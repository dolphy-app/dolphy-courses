Напишите асинхронный генератор `paginate(fetchPage)`, который скрывает постраничную загрузку. Функция `fetchPage(cursor)` возвращает промис с объектом `{ items, next }`: массив элементов страницы и курсор следующей страницы (`null`, когда страниц больше нет). Первый запрос делается с `cursor = undefined`.

Генератор должен отдавать элементы по одному, по порядку, и запрашивать следующую страницу только когда прочитана предыдущая.

```js
for await (const item of paginate(fetchPage)) {
  console.log(item);
}
```
