Напишите асинхронный генератор `takeAsync(source, count)`, который отдаёт первые `count` значений из `source` (асинхронно или обычно итерируемого, возможно бесконечного) и завершается.

Источник не должен запрашиваться дольше, чем нужно: после `count`-го значения лишних запросов быть не должно, а источник — закрыт (чтобы в нём отработал `finally`). При `count = 0` источник вообще не запрашивается.

```js
for await (const x of takeAsync(infiniteStream(), 2)) {
  console.log(x); // два значения
}
```
