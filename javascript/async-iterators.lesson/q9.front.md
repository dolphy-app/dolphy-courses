Напишите функцию `countdown(n)`, возвращающую асинхронно итерируемый объект, который отдаёт числа `n, n - 1, ..., 1` и завершается. Объект должен иметь метод `[Symbol.asyncIterator]()`, возвращающий итератор, у которого `next()` возвращает промис с `{ value, done }`.

Объект должен переиспользоваться: каждый новый `for await` начинает отсчёт заново.

```js
for await (const x of countdown(3)) console.log(x); // 3, 2, 1
```
