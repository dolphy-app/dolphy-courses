Напишите асинхронный генератор `mapAsync(source, fn)`: он перебирает `source` (асинхронно или обычно итерируемый) и для каждого значения отдаёт результат `fn(value)`. Функция `fn` может быть как обычной, так и `async` — отдаваться должно уже готовое значение, а не промис. Порядок значений сохраняется, обработка ленивая.

```js
for await (const x of mapAsync(source, async (v) => v * 2)) {
  console.log(x);
}
```
