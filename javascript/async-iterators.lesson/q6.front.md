Напишите функцию `collect(source)`, которая принимает асинхронно (или обычно) итерируемый объект и возвращает промис с массивом всех его значений в порядке поступления.

```js
async function* nums() {
  yield 1;
  yield 2;
}

await collect(nums()); // [1, 2]
```

Если источник бросил ошибку, возвращаемый промис должен быть отклонён этой ошибкой.
