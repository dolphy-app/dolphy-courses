Отладчик стоит на строке `const x = inner();`. Нужно, чтобы функция `inner` выполнилась целиком, а пауза наступила на следующей строке `return x + 1;`, без захода внутрь `inner`. Какую кнопку нажать?

```js
function inner() {
  return 1;
}

function outer() {
  const x = inner(); // пауза здесь
  return x + 1;
}
```
