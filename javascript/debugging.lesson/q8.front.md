Напишите функцию `sumWithTrace(list)`: она считает сумму элементов массива чисел и **возвращает** её, а на каждой итерации выводит через `console.log` одну строку вида `i=<индекс> item=<элемент> sum=<сумма после добавления элемента>`.

```js
sumWithTrace([2, 4]);
// выведет: i=0 item=2 sum=2
//          i=1 item=4 sum=6
// вернёт 6
```

Для пустого массива ничего не выводится, результат — `0`.
