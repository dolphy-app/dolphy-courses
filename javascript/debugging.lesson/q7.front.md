Функция `sumRange(from, to)` должна возвращать сумму всех целых чисел от `from` до `to` **включительно**. Если `from > to`, результат — `0`. Сейчас она возвращает не то. Найдите ошибку (в отладчике это видно по значению `i` на последней итерации) и исправьте.

```js
sumRange(1, 4); // 10
sumRange(5, 5); // 5
```
