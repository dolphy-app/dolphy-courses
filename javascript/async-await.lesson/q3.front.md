Примерно сколько времени пройдёт до вывода `готово`?

```js
const delay = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

async function main() {
  const p1 = delay(30);
  const p2 = delay(30);
  await p1;
  await p2;
  console.log('готово');
}

main();
```
