Что вернёт `count()`, то есть чему будет равно значение, с которым выполнится промис?

```js
const delay = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

async function count() {
  const out = [];
  [1, 2, 3].forEach(async (x) => {
    await delay(5);
    out.push(x);
  });
  return out.length;
}
```
