Функция `runInOrder(items, worker)` должна по очереди вызвать `worker(item)` (он возвращает промис) для каждого элемента и вернуть массив результатов в порядке элементов. Следующий элемент стартует только после завершения предыдущего; при ошибке обработка прекращается и результат отклоняется. Сейчас функция возвращает пустой массив. Исправьте её.
