Напишите функцию `createVisitCounter()`. Она возвращает объект с методами `hit(obj)` и `count(obj)`: `hit` увеличивает счётчик для объекта, `count` возвращает текущее значение (для неизвестного объекта — `0`). Данные хранятся во внутреннем `WeakMap`, свойства в самих объектах добавлять нельзя (они могут быть заморожены).

```js
const counter = createVisitCounter();
const user = {};
counter.hit(user);
counter.hit(user);
counter.count(user); // 2
```
