Напишите функцию `createOnce()`, которая возвращает функцию `isFirst(obj)`. Она возвращает `true`, если объект передан впервые, и `false` при всех последующих вызовах с тем же объектом. Используйте `WeakSet`, чтобы не удерживать объекты в памяти.

```js
const isFirst = createOnce();
const a = {};
isFirst(a); // true
isFirst(a); // false
```
