Напишите функцию `cacheByObject(fn)`. Она принимает функцию `fn(obj)` и возвращает её обёртку: для одного и того же объекта-аргумента `fn` вызывается только один раз, а повторные вызовы возвращают сохранённый результат. Кэш — `WeakMap`. Результат `undefined` тоже кэшируется.

```js
const size = cacheByObject((o) => Object.keys(o).length);
const data = { a: 1 };
size(data); // 1, fn вызвана
size(data); // 1, fn не вызывалась
```
