# Преобразование типов

Операторы и функции JavaScript сами приводят значения к нужному типу: `'6' / '2'` даёт `3`, а `if ('текст')` работает, хотя «текст» — не булево значение. Знание правил преобразования отделяет предсказуемый код от загадок вроде `[] + {}`. В уроке разберём три основных преобразования: в строку, в число и в булево значение. (Объекты в примитивы — отдельная большая тема, к ней вернёмся.)

## В строку

Строковое преобразование выполняется при выводе и склейке, а явно — функцией `String(value)`:

```js
console.log(String(123));       // 123
console.log(String(true));      // true
console.log(String(null));      // null
console.log(String(undefined)); // undefined
console.log(String([1, 2]));    // 1,2
console.log(1 + '');            // 1
```

Значение превращается в строку естественным образом: `false` — в `"false"`, `null` — в `"null"`. Для простых объектов результатом будет `[object Object]`.

## В число

Числовое преобразование происходит в математических выражениях и функциях. Явно его делают через `Number(value)` или унарный плюс `+value`.

```js
console.log('6' / '2');     // 3
console.log(Number('  12 ')); // 12
console.log(+'3.5');        // 3.5
```

Правила для строки: пробелы по краям отбрасываются; пустая строка (или только пробелы) — `0`; если после этого остаётся не число — результат `NaN`.

```js
console.log(Number('12px')); // NaN
console.log(Number(''));     // 0
console.log(Number('  '));   // 0
console.log(Number('1,5'));  // NaN
```

Для остальных типов:

| Значение | Результат `Number(...)` |
|---|---|
| `true` / `false` | `1` / `0` |
| `null` | `0` |
| `undefined` | `NaN` |
| `[]` | `0` |
| `[5]` | `5` |
| `[1, 2]` | `NaN` |

```js
console.log(Number(null));      // 0
console.log(Number(undefined)); // NaN
console.log(Number(true));      // 1
```

Разница между `null` и `undefined` пригодится позже: `null + 1` равно `1`, а `undefined + 1` — `NaN`.

### parseInt и parseFloat

Если нужно «вытащить» число из начала строки с лишним текстом, подходят `parseInt` и `parseFloat`. Они читают цифры слева направо и останавливаются на первом неподходящем символе:

```js
console.log(parseInt('12.9px'));   // 12
console.log(parseFloat('3.14abc')); // 3.14
console.log(parseInt('abc'));      // NaN
console.log(parseInt('101', 2));   // 5
```

У `parseInt` есть второй аргумент — основание системы счисления. Указывайте его, если важна система счисления: без него строки вида `'0x1f'` читаются как шестнадцатеричные.

## В булево значение

В булево значение преобразуют логические операции, `if` и явно — `Boolean(value)` (или `!!value`). Правило простое. **Ложными (falsy)** являются:

- `0`, `-0`, `0n`;
- пустая строка `''`;
- `null`, `undefined`, `NaN`.

Всё остальное — **истинно**, в том числе то, что кажется «пустым»:

```js
console.log(Boolean(0));       // false
console.log(Boolean(''));      // false
console.log(Boolean(NaN));     // false
console.log(Boolean('0'));     // true
console.log(Boolean(' '));     // true
console.log(Boolean('false')); // true
console.log(Boolean([]));      // true
console.log(Boolean({}));      // true
```

Именно поэтому `'0'` и `[]` в `if` считаются «истиной», хотя ведут себя по-разному при сравнении с числами. Это одна из частых причин путаницы.

## Неожиданности при сложении

Оператор `+` — особый: если хотя бы один из операндов строка, он склеивает строки. Остальные арифметические операторы (`-`, `*`, `/`) всегда приводят операнды к числам.

```js
console.log('6' + 2);       // 62
console.log(6 + '2');       // 62
console.log(1 + 2 + '3');   // 33
console.log('1' + 2 + 3);   // 123
console.log('6' - 2);       // 4
console.log('4px' * 2);     // NaN
```

В выражении `1 + 2 + '3'` вычисления идут слева направо: сначала `1 + 2 = 3`, затем `3 + '3'` — склейка. В `'1' + 2 + 3` склейка начинается сразу.

## Типичные ошибки

- Складывать строки из формы или `prompt` как числа без `Number`.
- Считать, что `'0'` и `[]` ложны: они истинны.
- Ждать, что `Number('12px')` вернёт 12 (для этого есть `parseInt`).
- Забывать, что пустая строка превращается в `0`, а не в `NaN`.
- Путать `Number(null)` (`0`) и `Number(undefined)` (`NaN`).

## Коротко

- Три преобразования: в строку (`String`), в число (`Number`, `+`), в булево (`Boolean`, `!!`).
- Ложные значения: `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`; остальное — истина.
- `Number('')` — `0`, `Number('12px')` — `NaN`; `parseInt` читает число из начала строки.
- `+` склеивает, если есть строка; `-`, `*`, `/` всегда считают.
