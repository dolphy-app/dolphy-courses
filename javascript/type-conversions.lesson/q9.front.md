Напишите функцию `parsePrice(text)`: она читает число, с которого начинается строка, и игнорирует остальной текст. Если строка не начинается с числа (допустимы пробелы в начале), верните `NaN`.

```js
parsePrice('12.5 руб'); // 12.5
parsePrice('100');      // 100
parsePrice('руб 5');    // NaN
```
