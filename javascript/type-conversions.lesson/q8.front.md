Напишите функцию `toNumberOrNull(text)`: она преобразует строку в число, а если строка пустая (или из пробелов) либо не является корректным числом, возвращает `null`. Значение `0` — корректное число.

```js
toNumberOrNull('12');   // 12
toNumberOrNull(' 3.5 ');// 3.5
toNumberOrNull('12px'); // null
toNumberOrNull('');     // null
```
