Напишите функцию `grade(score)`, которая по баллу возвращает оценку: от 90 включительно — `'A'`, от 75 до 90 — `'B'`, от 50 до 75 — `'C'`, всё остальное (включая отрицательные числа и `NaN`) — `'F'`.

Решите задачу через `switch (true)`: в `case` стоят условия, срабатывает первое истинное.

```js
grade(95); // 'A'
grade(75); // 'B'
grade(20); // 'F'
```
