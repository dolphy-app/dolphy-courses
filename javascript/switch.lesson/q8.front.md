Напишите функцию `calc(op, a, b)`, которая применяет операцию `op` (строка) к числам `a` и `b` и возвращает результат. Поддерживаются `'+'`, `'-'`, `'*'`, `'/'`, `'**'` и `'%'`.

- При делении (`'/'`) на ноль выбросьте `RangeError`.
- Для любой другой операции выбросьте `TypeError`, в сообщении которого упомянута эта операция.

```js
calc('-', 7, 5); // 2
calc('**', 2, 3); // 8
calc('^', 1, 2); // выбрасывает TypeError
```
