Напишите функцию `describe(n)`, которая возвращает строку по значению `n`:

- `0` — `'ноль'`;
- `1` — `'один'`;
- `2` или `3` — `'два или три'` (одна общая ветвь);
- всё остальное — `'другое'`.

Используйте `switch`. Значения других типов (например, строка `'1'`) под правила не подпадают.

```js
describe(3); // 'два или три'
describe('1'); // 'другое'
```
