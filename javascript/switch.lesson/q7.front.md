Напишите функцию `daysInMonth(month, year)`: по номеру месяца (от 1 до 12) и году возвращает число дней в месяце. Сгруппируйте месяцы с одинаковым результатом в общие ветви `switch`.

- В феврале 29 дней в високосном году и 28 в обычном. Год високосный, если он делится на 4, кроме годов, кратных 100, но не кратных 400.
- Для любого другого значения `month` (включая нечисловые и вне диапазона 1–12) выбросьте `RangeError`.

```js
daysInMonth(4, 2023); // 30
daysInMonth(2, 2024); // 29
daysInMonth(13, 2024); // выбрасывает RangeError
```
