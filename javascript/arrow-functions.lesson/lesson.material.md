# Стрелочные функции подробнее

Стрелочные функции появились не только ради короткой записи. У них иначе устроено окружение: нет собственного `this`, `arguments` и `super`, их нельзя вызывать через `new`. Это не недостатки, а осознанные свойства: стрелка нужна там, где контекст берут «снаружи».

## Нет собственного this

В обычной функции `this` определяется тем, как её вызвали. В стрелочной `this` вообще не создаётся: при обращении к нему движок ищет значение во внешней области, как для любой другой переменной.

```js
const group = {
  title: 'Курс',
  students: ['Аня', 'Борис'],

  showList() {
    return this.students.map((student) => this.title + ': ' + student);
  },
};

console.log(group.showList()); // [ 'Курс: Аня', 'Курс: Борис' ]
```

Стрелка внутри `map` берёт `this` у метода `showList`, где он равен `group`. Если заменить её обычной `function`, у колбэка `this` будет `undefined` (в строгом режиме) или глобальный, и `this.title` не найдётся:

```js
const broken = {
  title: 'Курс',
  students: ['Аня'],
  showList() {
    return this.students.map(function (student) {
      return this.title + ': ' + student;
    });
  },
};
console.log(broken.showList()); // [ 'undefined: Аня' ]
```

(Результат такой в обычном режиме; в модуле или `'use strict'` будет `TypeError`.)

Из-за этого стрелки удобны для колбэков: не нужно писать `bind(this)` или копить `const self = this`.

## Контекст нельзя изменить

Раз `this` у стрелки не собственный, `call`, `apply` и `bind` не могут его заменить. Они лишь передадут аргументы, а `this` останется внешним:

```js
const outer = {
  id: 'outer',
  make() {
    return () => this.id;
  },
};
const arrow = outer.make();
console.log(arrow.call({ id: 'other' })); // outer
console.log(arrow.bind({ id: 'bound' })()); // outer
```

## Нет arguments

Внутри стрелки нет собственного объекта `arguments`: имя разрешается во внешней функции. Это можно использовать в декораторах, чтобы передать аргументы внешней функции:

```js
function outerFn() {
  const inner = () => arguments.length;
  return inner('a', 'b', 'c', 'd');
}
console.log(outerFn(1, 2)); // 2
```

Видно, что `inner` возвращает длину аргументов `outerFn`, а не свои четыре. В собственном коде вместо `arguments` лучше использовать остаточные параметры `(...args) => ...`: они работают и в стрелках.

## Нельзя вызвать с new

Для `new` нужен объект `this`, а у стрелки его нет, поэтому у неё нет и внутреннего метода `[[Construct]]`, и свойства `prototype`:

```js
const Maker = () => {};
try {
  new Maker();
} catch (err) {
  console.log(err.message); // Maker is not a constructor
}
console.log(Maker.prototype); // undefined
```

## Нет super

Стрелка не создаёт собственный `super`, а берёт его (как и `this`) из внешнего метода. Поэтому внутри метода класса можно писать колбэк-стрелку, обращающийся к `super.method()`.

## Нюансы синтаксиса

- Если параметр один, скобки можно опустить: `x => x * 2`.
- Тело без фигурных скобок — это выражение, оно же и результат. С фигурными нужен явный `return`.
- Чтобы вернуть объектный литерал, оберните его в круглые скобки: `() => ({ a: 1 })`. Без скобок `{` откроет тело функции.

```js
const makeUser = (name) => ({ name, active: true });
console.log(makeUser('Ира')); // { name: 'Ира', active: true }

const wrong = () => {
  a: 1;
};
console.log(wrong()); // undefined
```

В `wrong` фигурные скобки — тело функции, а `a:` — метка. Вернуть оттуда ничего нельзя.

## Когда стрелка не подходит

- Метод объекта, использующий `this` объекта. Стрелка возьмёт `this` снаружи, а не владельца:

```js
const counter = {
  count: 3,
  getArrow: () => this.count,
  getMethod() {
    return this.count;
  },
};
console.log(counter.getMethod()); // 3
console.log(counter.getArrow()); // undefined
```

В `getArrow` `this` — это `this` модуля или скрипта, а не `counter`. В CommonJS-файле Node.js это пустой объект `{}`, поэтому `count` не находится; в ES-модуле `this` на верхнем уровне — `undefined`, и обращение к `count` бросит `TypeError`.

- Конструкторы и функции, создающие `prototype`.
- Обработчики, где фреймворк намеренно устанавливает `this` (например, в браузере `this` в обработчике — элемент, но стрелка эту возможность отнимет).

## Типичные ошибки

- Стрелка как метод объекта, использующий `this`.
- Попытка вызвать стрелку через `new` или переопределить `this` через `call`.
- Ожидание `arguments` внутри стрелки (получите аргументы внешней функции или `ReferenceError` на верхнем уровне модуля).
- Возврат литерала объекта без круглых скобок.

## Коротко

- У стрелочной функции нет своих `this`, `arguments`, `super`; они берутся из внешней области.
- Из-за этого `call`/`apply`/`bind` не меняют её `this`.
- Стрелки нельзя вызывать с `new`, у них нет `prototype`.
- Идеальны для колбэков внутри методов; для методов объектов и конструкторов используйте обычные функции или методы.
- Для возврата объекта оборачивайте литерал в скобки.
