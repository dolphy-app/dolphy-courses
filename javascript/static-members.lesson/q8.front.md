Напишите класс `Plugin` со статическими методами:

- `Plugin.register(name, Ctor)` — запоминает конструктор под именем;
- `Plugin.create(name, ...args)` — создаёт экземпляр зарегистрированного класса, передавая аргументы; для неизвестного имени бросает `Error` с текстом, содержащим `unknown`;
- `Plugin.has(name)` — `true`, если имя зарегистрировано.

Хранилище не должно быть доступно как публичное свойство `Plugin.registry`.

```js
Plugin.register('logger', Logger);
Plugin.create('logger', 'debug'); // new Logger('debug')
```
