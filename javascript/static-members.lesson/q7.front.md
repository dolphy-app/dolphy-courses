Статическая фабрика `Model.create` всегда создаёт `Model`, даже когда её вызывают у наследника. Исправьте её так, чтобы `User.create('Аня')` возвращала `User`.

```js
class User extends Model {
  constructor(name) { super(); this.name = name; }
}
User.create('Аня') instanceof User; // true
```
