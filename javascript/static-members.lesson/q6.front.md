Напишите класс `Ticket`. Каждый новый экземпляр получает свойство `id` — порядковый номер, начиная с 1. Статическое свойство `Ticket.count` хранит число созданных билетов, статический метод `Ticket.reset()` обнуляет нумерацию.

```js
Ticket.reset();
new Ticket().id; // 1
new Ticket().id; // 2
Ticket.count; // 2
```
