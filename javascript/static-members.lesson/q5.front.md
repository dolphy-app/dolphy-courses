Напишите класс `Version` с конструктором `(major, minor)`, статической фабрикой `Version.parse('1.4')` (строка `"major.minor"`) и статическим `Version.compare(a, b)`, возвращающим отрицательное число, если `a` меньше `b`, `0` при равенстве и положительное, если `a` больше `b`. Сначала сравниваются `major`, потом `minor` (как числа).

```js
[Version.parse('1.10'), Version.parse('1.4')].sort(Version.compare); // 1.4, 1.10
```
