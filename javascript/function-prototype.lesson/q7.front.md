В коде ниже прототип заменён литералом, поэтому `constructor` потерян. Исправьте так, чтобы `new Shape(...).constructor === Shape`, метод `describe` продолжал работать, а в `Object.keys(Shape.prototype)` оставался только `describe` (то есть `constructor` неперечислимый).

```js
new Shape('круг').describe(); // 'Фигура круг'
```
