Напишите конструктор `Temperature(celsius)`, который сохраняет число в свойстве `celsius`. Метод `toFahrenheit()` (значение `celsius * 9 / 5 + 32`) должен лежать в `Temperature.prototype` и быть общим для всех экземпляров.

```js
const t = new Temperature(100);
t.toFahrenheit(); // 212
```
