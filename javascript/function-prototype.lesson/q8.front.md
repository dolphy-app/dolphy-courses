Напишите функцию `addMethods(F, methods)`. Она добавляет все функции из объекта `methods` в `F.prototype` — так, чтобы их получили и уже созданные экземпляры. Сам объект `F.prototype` заменять нельзя. Функция возвращает `F`.

```js
function Dog() {}
const d = new Dog();
addMethods(Dog, { bark() { return 'гав'; } });
d.bark(); // 'гав'
```
