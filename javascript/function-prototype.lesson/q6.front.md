Напишите функцию `makeTwin(obj, ...args)`. Она создаёт новый объект тем же конструктором, что и `obj` (через его свойство `constructor`), передавая `args` в конструктор.

```js
function Rabbit(name) { this.name = name; }
const r = new Rabbit('Белый');
makeTwin(r, 'Серый').name; // 'Серый'
```
