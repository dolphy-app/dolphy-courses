Напишите объект-примесь `eventMixin` с методами:

- `on(name, handler)` — подписка на событие;
- `off(name, handler)` — отписка (если такой подписки нет — ничего не происходит);
- `emit(name, ...args)` — вызывает обработчики в порядке подписки, `this` внутри обработчика — объект, на котором вызван `emit`; возвращает число вызванных обработчиков.

Подписки должны храниться в каждом объекте отдельно.

```js
class Menu {}
Object.assign(Menu.prototype, eventMixin);
const m = new Menu();
m.on('pick', (x) => console.log(x));
m.emit('pick', 'чай'); // выведет 'чай', вернёт 1
```
