Напишите функцию-примесь `Countable(Base)`. Она возвращает класс, расширяющий `Base`, с полем `count` (начально `0`), методом `inc()` (увеличивает `count` на 1 и возвращает `this`) и геттером `isZero`. Аргументы конструктора должны передаваться в `Base` без изменений.

```js
class Named { constructor(name) { this.name = name; } }
class Task extends Countable(Named) {}
const t = new Task('сборка');
t.inc().inc().count; // 2
t.name; // 'сборка'
```
