Напишите функцию `mixin(Target, ...mixins)`. Она копирует собственные свойства каждой примеси (обычного объекта) в `Target.prototype` вместе с дескрипторами — так геттеры и сеттеры остаются геттерами и сеттерами и не вызываются при копировании. При совпадении имён побеждает примесь, указанная позже. Функция возвращает `Target`.

```js
class Item { constructor(id) { this.id = id; } }
mixin(Item, { get label() { return '№' + this.id; } });
new Item(7).label; // '№7'
```
