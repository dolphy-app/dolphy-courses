Примесь `tagMixin` подмешивают в разные классы, и их экземпляры делят один массив `tags`. Исправьте примесь так, чтобы у каждого экземпляра были свои теги. Способ подмешивания (`Object.assign(Class.prototype, tagMixin)`) менять нельзя, конструкторы классов тоже.

```js
tagMixin.addTag; // метод добавляет тег
tagMixin.getTags; // метод возвращает копию списка тегов (изначально пустого)
```
