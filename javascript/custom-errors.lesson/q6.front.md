Создайте класс `FormatError`, который наследует от встроенного `SyntaxError`. У экземпляра должны быть свойства `message`, `name` (равное `'FormatError'`) и `stack`.

```js
const err = new FormatError('ошибка формата');
err.message; // 'ошибка формата'
err.name; // 'FormatError'
err instanceof SyntaxError; // true
```
