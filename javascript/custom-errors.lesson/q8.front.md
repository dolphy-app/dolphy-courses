Напишите:

- класс `ValidationError` (наследник `Error`, `name` равно `'ValidationError'`);
- класс `PropertyRequiredError` (наследник `ValidationError`) с конструктором `(property)`: он сохраняет имя свойства в поле `property`, а `name` у него равно `'PropertyRequiredError'`;
- функцию `validateUser(user)`. Сначала проверяется поле `name`, потом `age`. Если поля нет (значение `undefined`), функция бросает `PropertyRequiredError`. Если `age` не число, бросает `ValidationError`. Иначе возвращает тот же объект.
