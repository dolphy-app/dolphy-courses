Напишите функцию `rootCause(error)`. Она идёт по цепочке `error.cause` и возвращает самую глубокую причину: первое значение, у которого нет `cause`. Если `cause` содержит не объект `Error` (строку, число), то это и есть первопричина. Цепочка может оказаться зациклена: функция не должна зависать.

```js
const low = new TypeError('low');
const top = new Error('top', { cause: new Error('mid', { cause: low }) });
rootCause(top) === low; // true
```
