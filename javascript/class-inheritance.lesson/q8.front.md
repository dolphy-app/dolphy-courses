Класс `Counter` уже написан. Напишите `LimitedCounter extends Counter`: конструктор `(max)`; метод `inc()` увеличивает счётчик с помощью родительского `inc()`, но не даёт значению стать больше `max`. Метод возвращает текущее значение.

```js
const c = new LimitedCounter(2);
c.inc(); c.inc(); c.inc(); // 1, 2, 2
```
