Класс `Person` уже написан. Напишите `Employee extends Person`: конструктор принимает `name` и `salary`, метод `describe()` возвращает строку родителя и добавляет к ней `", зарплата <salary>"`.

```js
new Employee('Ира', 100).describe(); // 'Я Ира, зарплата 100'
```
