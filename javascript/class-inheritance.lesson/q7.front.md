Напишите три класса и функцию:

- `Shape` — метод `area()` бросает `Error` с текстом «not implemented»;
- `Square extends Shape` — конструктор `(side)`, `area()` возвращает `side * side`;
- `Circle extends Shape` — конструктор `(r)`, `area()` возвращает `Math.PI * r * r`;
- `totalArea(shapes)` — сумма площадей фигур из массива (для пустого массива — `0`).

```js
totalArea([new Square(2), new Square(3)]); // 13
```
