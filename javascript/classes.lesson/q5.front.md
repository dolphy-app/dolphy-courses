          constructor(width, height) {

          get perimeter() {

Напишите класс `Rectangle`. Конструктор принимает `width` и `height`. Геттер `area` возвращает площадь, геттер `perimeter` — периметр, метод `scale(k)` возвращает **новый** `Rectangle` с размерами, умноженными на `k` (исходный не меняется).

```js
const r = new Rectangle(2, 3);
r.area; // 6
r.scale(2).perimeter; // 20
```
