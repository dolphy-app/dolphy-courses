Напишите функцию `makeGreeter(word)`. Она возвращает **класс**, у экземпляров которого есть метод `greet(name)`, возвращающий строку `"<word>, <name>!"`. Классы от разных вызовов независимы.

```js
const Hello = makeGreeter('Привет');
new Hello().greet('мир'); // 'Привет, мир!'
```
