Метод `tick` класса `Clock` передают в колбэк без объекта, и он падает. Исправьте класс так, чтобы `const { tick } = clock; tick();` увеличивало счётчик именно этого экземпляра. Метод по-прежнему должен вызываться и как `clock.tick()`.

```js
const clock = new Clock();
const { tick } = clock;
tick(); // 1
tick(); // 2
```
