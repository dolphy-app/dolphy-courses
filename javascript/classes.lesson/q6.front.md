Напишите класс `Temperature`. Конструктор принимает градусы Цельсия. Свойство-аксессор `celsius` читает и записывает значение; при попытке записать число ниже `-273.15` сеттер выбрасывает `RangeError` (в том числе в конструкторе). Аксессор `fahrenheit` пересчитывает значение: `c * 9 / 5 + 32`; запись во `fahrenheit` обновляет `celsius`.

```js
const t = new Temperature(100);
t.fahrenheit; // 212
t.fahrenheit = 32;
t.celsius; // 0
```
