Напишите функцию `addDays(date, n)`: возвращает **новую** дату, сдвинутую на `n` суток (может быть отрицательным). Исходный объект менять нельзя. Работайте в UTC (`getUTCDate` / `setUTCDate`).

```js
addDays(new Date(Date.UTC(2024, 1, 28)), 2); // 2024-03-01 (год високосный)
```
