Напишите функцию `weekdayName(date)`: возвращает сокращённое русское название дня недели в UTC: `'Вс'`, `'Пн'`, `'Вт'`, `'Ср'`, `'Чт'`, `'Пт'`, `'Сб'` (индекс `getUTCDay()`: 0 — воскресенье).

```js
weekdayName(new Date(Date.UTC(2024, 0, 1))); // 'Пн'
```
