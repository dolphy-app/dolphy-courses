Напишите функцию `daysBetween(a, b)`: возвращает количество **полных** суток между датами `a` и `b` (по модулю, порядок аргументов не важен). Неполные сутки отбрасываются.

```js
daysBetween(new Date(Date.UTC(2024, 0, 1)), new Date(Date.UTC(2024, 0, 4))); // 3
```
