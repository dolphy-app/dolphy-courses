Напишите функцию `almostEqual(a, b)`, которая возвращает `true`, если числа отличаются меньше чем на `1e-9`, и `false` в противном случае. Нужна для сравнения результатов вычислений с дробями.

```js
almostEqual(0.1 + 0.2, 0.3); // true
almostEqual(1, 1.1); // false
```
