Напишите функцию `parseNumber(input)`, которая принимает строку и возвращает число. Если строка не является корректным конечным числом (в том числе пустая, из одних пробелов или содержит лишние символы, как `'12px'`), верните `null`. Значения `Infinity` тоже считаем некорректными.

```js
parseNumber('42'); // 42
parseNumber(' 3.5 '); // 3.5
parseNumber('12px'); // null
parseNumber(''); // null
```
