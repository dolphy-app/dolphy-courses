Напишите функцию `randomInt(min, max)`, которая возвращает случайное **целое** число от `min` до `max` включительно, все значения должны быть равновероятны. Используйте `Math.random()`. Границы — целые числа, `min <= max`, возможны отрицательные.

```js
randomInt(1, 5); // 1, 2, 3, 4 или 5
```
