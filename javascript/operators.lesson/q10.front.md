Напишите функцию `compound(principal, ratePercent, years)`, которая возвращает сумму вклада через `years` лет при годовой ставке `ratePercent` процентов с капитализацией раз в год: `principal * (1 + ratePercent / 100) ** years`. Округлять результат не нужно.

```js
compound(1000, 10, 2); // примерно 1210
```
