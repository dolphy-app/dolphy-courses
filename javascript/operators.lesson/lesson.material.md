# Базовые операторы и математика

Операторы — это значки действий: `+`, `*`, `=`, `++`. Часть из них вы уже видели. В уроке соберём арифметику, остаток, возведение в степень, сокращённые присваивания, инкремент и декремент, приоритеты операторов и поймём, чем `+` отличается от остальных.

## Термины

**Операнд** — то, к чему применяется оператор. В `5 * 2` два операнда: `5` и `2`. Оператор с одним операндом называют **унарным**, с двумя — **бинарным**. Минус бывает и тем и другим: `-x` (унарный, меняет знак) и `a - b` (бинарный, вычитает).

## Арифметика

Доступны `+`, `-`, `*`, `/`, остаток `%` и возведение в степень `**`:

```js
console.log(7 / 2);   // 3.5
console.log(5 % 2);   // 1
console.log(2 ** 3);  // 8
console.log(4 ** 0.5);// 2
```

Деление всегда даёт обычное число с дробной частью: целочисленного деления в JavaScript нет. Чтобы отбросить дробь, пользуются `Math.floor` или `Math.trunc`:

```js
console.log(Math.trunc(7 / 2));  // 3
console.log(Math.floor(-7 / 2)); // -4
```

Знак остатка совпадает со знаком делимого — это важно для отрицательных чисел, например при проверке на чётность:

```js
console.log(-5 % 2); // -1
console.log(5 % 2);  // 1
```

## Плюс и строки

Бинарный `+` умеет и складывать, и склеивать: если хотя бы один операнд — строка, результат тоже строка. Остальные арифметические операторы строки превращают в числа.

```js
console.log('1' + 2);       // 12
console.log(2 + 2 + '1');   // 41
console.log('x' + 1 + 2);   // x12
console.log('6' * '2');     // 12
```

Унарный плюс переводит значение в число — это самый короткий способ записать `Number(value)`:

```js
console.log(+'5' + 1); // 6
console.log(+true);    // 1
console.log(+'');      // 0
console.log(+{});      // NaN
```

## Приоритет операторов

Если в выражении несколько операторов, порядок определяется приоритетом: умножение и деление выполняются раньше сложения, унарные операторы — раньше бинарных, присваивание — после всех вычислений. Скобки меняют порядок, и если есть сомнение, лучше поставить скобки.

```js
console.log(1 + 2 * 3);   // 7
console.log((1 + 2) * 3); // 9
console.log(2 ** 3 ** 2); // 512
```

Возведение в степень выполняется справа налево: `2 ** 3 ** 2` — это `2 ** (3 ** 2)`. Остальные арифметические операторы идут слева направо.

## Присваивание

Присваивание `=` — тоже оператор и возвращает присвоенное значение. Поэтому можно писать цепочки (хотя читаются они плохо):

```js
let c;
const d = c = 5;
console.log(c, d); // 5 5
```

Для обновления переменной есть сокращённые формы: `+=`, `-=`, `*=`, `/=`, `%=`, `**=`:

```js
let n = 2;
n += 5;  // 7
n *= 2;  // 14
n **= 2; // 196
console.log(n); // 196
```

## Инкремент и декремент

`++` увеличивает число на 1, `--` уменьшает на 1. У них есть префиксная (`++i`) и постфиксная (`i++`) формы. Обе меняют переменную, но возвращают разное: постфиксная — **старое** значение, префиксная — **новое**.

```js
let i = 1;
console.log(i++); // 1 (вернулось старое значение)
console.log(i);   // 2
console.log(++i); // 3 (вернулось новое значение)
```

```js
let a = 1;
const b = 2 * a++;
console.log(a, b); // 2 2
let c = 1;
const d = 2 * ++c;
console.log(c, d); // 2 4
```

Если результат выражения не используется, форма безразлична: `i++` и `++i` делают то же самое. Инкремент применим только к переменным: `5++` — ошибка.

## Оператор запятая

Запятая вычисляет все выражения слева направо, а результатом становится последнее. Она бывает в циклах, а в остальных местах встречается редко и ухудшает читаемость.

```js
const x = (1 + 2, 3 + 4);
console.log(x); // 7
```

## Типичные ошибки

- Складывать числа из строк без преобразования: `'2' + '3'` равно `'23'`.
- Проверять нечётность как `n % 2 === 1`: для отрицательных чисел остаток равен `-1`.
- Использовать `i++` внутри сложного выражения и путать, какое значение получится.
- Забывать скобки в выражениях со смешанными операторами.
- Ждать целочисленного деления от `/`.

## Коротко

- Арифметика: `+ - * / % **`; деление всегда дробное.
- Знак `%` берётся от делимого; `**` вычисляется справа налево.
- Бинарный `+` склеивает, если есть строка; унарный `+` превращает в число.
- `i++` возвращает старое значение, `++i` — новое.
- Сокращённое присваивание (`+=`, `*=` и др.) меняет переменную на месте.
- Приоритеты упрощают запись, а скобки делают её понятной.
