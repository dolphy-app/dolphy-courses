Функция `scheduleAll(count, callback)` должна вызвать `callback(0)`, `callback(1)`, …, `callback(count - 1)` — каждый вызов асинхронно через `setTimeout` с задержкой `10 * i` мс. Сейчас `callback` получает не те числа. Исправьте код.

```js
scheduleAll(3, (i) => console.log(i)); // позже: 0, 1, 2
```
