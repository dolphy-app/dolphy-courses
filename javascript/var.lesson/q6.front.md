Функция `makeGetters(values)` должна вернуть массив функций: i-я функция при вызове возвращает `values[i]`. Сейчас все функции возвращают `undefined`. Найдите причину и исправьте код.

```js
const g = makeGetters(['a', 'b']);
g[0](); // 'a'
g[1](); // 'b'
```
