Функция `promisify(f)` — стандартная обёртка из урока: добавляет в конец аргументов колбэк `(err, result)`, который вызывает `reject(err)` или `resolve(result)`. Что выведет код?

```js
function f(callback) {
  callback(null, 'a');
  callback(null, 'b');
  callback(new Error('c'));
}

promisify(f)().then(console.log, (e) => console.log('err', e.message));
```
