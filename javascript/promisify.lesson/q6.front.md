Напишите функцию `promisify(f)`. Она принимает функцию `f`, последним аргументом которой служит колбэк в стиле Node.js `(err, result)`, и возвращает новую функцию, которая вызывается без колбэка и возвращает промис:

- если `err` «истинно», промис отклоняется этой ошибкой, иначе выполняется значением `result`;
- аргументы передаются в `f` без изменений, колбэк добавляется последним;
- `this` вызова сохраняется (функция может быть методом объекта).
