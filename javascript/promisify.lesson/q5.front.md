Обёртка написана так:

```js
function promisify(f) {
  return (...args) =>
    new Promise((resolve, reject) => {
      f(...args, (err, result) => {
        if (err) reject(err);
      });
    });
}
```

Что произойдёт, когда оригинальная функция вызовет `callback(null, 42)`?
