Напишите функцию `transform(list, fn)`: она вызывает колбэк `fn` для каждого элемента массива `list` с двумя аргументами — элементом и его индексом — и возвращает **новый** массив из результатов. Исходный массив не меняется.

```js
transform([1, 2, 3], function (x) { return x * x; }); // [1, 4, 9]
transform(['a', 'b'], function (item, i) { return item + i; }); // ['a0', 'b1']
```

Готовые методы массивов (`map`, `forEach` и т. д.) использовать не нужно — задача в том, чтобы вызвать переданную функцию самостоятельно.
