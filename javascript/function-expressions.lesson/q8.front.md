Напишите функцию `getOperation(sign)`. Она возвращает **функцию** от двух аргументов `(a, b)`: для `'+'` — сумму, для `'-'` — разность `a - b`, для `'*'` — произведение. Для любого другого значения `sign` возвращается `null`. Саму операцию `getOperation` не выполняет, а только выбирает.

```js
getOperation('+')(2, 3); // 5
getOperation('-')(10, 4); // 6
getOperation('%'); // null
```
