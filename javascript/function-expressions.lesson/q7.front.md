Напишите функцию `ask(isYes, yes, no)`. Если `isYes` истинно, она вызывает колбэк `yes`, иначе — колбэк `no`. Колбэки вызываются без аргументов, а `ask` возвращает то, что вернул вызванный колбэк.

```js
ask(true, function () { return 'да'; }, function () { return 'нет'; }); // 'да'
ask(false, function () { return 'да'; }, function () { return 'нет'; }); // 'нет'
```

В браузере ответ дал бы `confirm`, здесь он приходит готовым значением.
