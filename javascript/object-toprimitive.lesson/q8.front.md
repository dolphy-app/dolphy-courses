Напишите функцию `makeTemp(celsius)`. Возвращаемый объект реализует `Symbol.toPrimitive`:

- при хинте `"string"` даёт строку вида `"21°C"`;
- при остальных хинтах — число `celsius`.

```js
const t = makeTemp(21);
String(t); // "21°C"
t + 1;     // 22
t > 20;    // true
```
