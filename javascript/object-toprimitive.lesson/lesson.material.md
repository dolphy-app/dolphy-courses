# Преобразование объектов в примитивы

Что будет, если сложить два объекта, вычесть их друг из друга или вывести объект в строку? JavaScript не позволяет переопределять операторы для объектов (как в C++ или Ruby): сначала объект превращается в примитив, и только затем выполняется операция. Результат `obj1 + obj2` поэтому никогда не бывает объектом. В этом уроке вы разберёте правила преобразования и научитесь их настраивать.

## Что конвертируется

- В логическом контексте любой объект — `true`. Настроить это нельзя.
- Числовое и строковое преобразование выполняются по описанным ниже правилам.

Зачем это знать? Чтобы понимать случайные ошибки вроде `"[object Object]"` в тексте и осознанно работать с объектами `Date`, которые можно вычитать.

## Три хинта

Перед преобразованием операция сообщает «подсказку» (hint) — какой примитив ей нужен:

| hint | где используется |
|---|---|
| `"string"` | `String(obj)`, шаблонные строки, объект как ключ `{[obj]: 1}` |
| `"number"` | `Number(obj)`, унарный `+obj`, `-`, `*`, `/`, сравнения `<`, `>`, математические функции |
| `"default"` | бинарный `+`, `obj == примитив` |

Бинарный плюс не знает, нужна ему строка или число, поэтому передаёт `"default"`. Операторы `<` и `>` по историческим причинам используют `"number"`.

## Алгоритм

Движок ищет способ получить примитив в таком порядке:

1. Если у объекта есть метод `obj[Symbol.toPrimitive]`, вызывается он: `obj[Symbol.toPrimitive](hint)`.
2. Иначе для хинта `"string"` вызываются `toString()`, затем `valueOf()`.
3. Иначе для `"number"` и `"default"` вызываются `valueOf()`, затем `toString()`.

Следующий метод пробуется, если предыдущий отсутствует или вернул объект (не примитив).

## Symbol.toPrimitive

Один метод обрабатывает все случаи, а хинт приходит аргументом:

```js
const user = {
  name: "Мира",
  balance: 100,
  [Symbol.toPrimitive](hint) {
    return hint === "string" ? `{${this.name}}` : this.balance;
  }
};
console.log(String(user)); // {Мира}
console.log(+user);        // 100
console.log(user + 50);    // 150
```

Метод обязан вернуть примитив, иначе будет `TypeError`. Тип примитива не обязан совпадать с хинтом: для `"number"` можно вернуть строку.

```js
const bad = { [Symbol.toPrimitive]() { return {}; } };
try { +bad; } catch (e) { console.log(e.name); } // TypeError
```

## toString и valueOf

Старые методы с обычными строковыми именами делают то же самое по умолчанию: `toString` возвращает `"[object Object]"`, а `valueOf` возвращает сам объект, и потому игнорируется.

```js
const plain = { a: 1 };
console.log(String(plain));               // [object Object]
console.log(plain.valueOf() === plain);   // true
```

Типичное разделение ролей — `toString` для строки, `valueOf` для числа:

```js
const price = {
  value: 10,
  toString() { return `${this.value} руб.`; },
  valueOf() { return this.value; }
};
console.log(`${price}`);   // 10 руб.
console.log(price * 2);    // 20
console.log(price + 1);    // 11
console.log(price > 5);    // true
```

Обратите внимание на `price + 1`: хинт `"default"` ведёт к `valueOf`, поэтому получили число, а не строку. Если же определить только `toString`, он станет универсальным обработчиком:

```js
const tag = { toString() { return "2"; } };
console.log(tag * 3);   // 6
console.log(tag + 3);   // 23
```

Сначала объект превращается в примитив (`"2"`), потом с ним работает оператор: `*` приводит строку к числу, `+` склеивает строки.

Если `toString` вернул объект, он пропускается, и пробуется `valueOf`:

```js
const odd = {
  toString() { return {}; },
  valueOf() { return 7; }
};
console.log(String(odd)); // 7
```

Вызов `odd + ""` в такой же ситуации дал бы `"7"`, а `odd * 1` — `7`.

## Date: исключение

Встроенные объекты реализуют `"default"` как `"number"`, кроме `Date`: для него `"default"` означает строку. Поэтому `+` склеивает, а `-` вычитает:

```js
const d = new Date(0);
console.log(typeof (d + 1)); // string
console.log(typeof (d - 1)); // number
console.log(d - new Date(1000)); // -1000
```

## Как увидеть хинты

Удобно написать «шпиона»:

```js
const hints = [];
const spy = {
  [Symbol.toPrimitive](hint) {
    hints.push(hint);
    return 1;
  }
};
+spy; `${spy}`; spy + 1; spy < 2; spy == 1;
console.log(hints); // [ 'number', 'string', 'default', 'number', 'default' ]
```

## Типичные ошибки

- Ждать, что `obj1 + obj2` вернёт объект. Результат — всегда примитив.
- Забыть, что бинарный `+` использует `"default"`, и получить склейку строк вместо сложения.
- Вернуть из `toString`/`valueOf`/`Symbol.toPrimitive` объект: первые два молча пропускаются, третий бросает `TypeError`.
- Видеть `[object Object]` в тексте — значит, объект превратился в строку без своего `toString`.
- Считать, что объект в `if` проходит преобразование: любой объект там `true`, преобразование не вызывается.

## Коротко

- Операторы для объектов не перегружаются: объект сначала приводится к примитиву.
- Хинты: `"string"`, `"number"`, `"default"`; `+` и `==` используют `"default"`.
- Порядок: `Symbol.toPrimitive`, затем `toString`/`valueOf` в порядке, зависящем от хинта.
- Методы обязаны возвращать примитив; тип примитива не обязан совпадать с хинтом.
- Часто достаточно одного `toString()` — он обслуживает все преобразования.
