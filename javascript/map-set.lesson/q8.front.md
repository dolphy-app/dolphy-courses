Напишите функцию `common(a, b)`: возвращает массив значений, которые есть и в `a`, и в `b`. Без повторов, порядок — как в `a`. Сами массивы не изменяйте.

```js
common([1, 2, 2, 3, 4], [4, 2, 5]); // [2, 4]
```
