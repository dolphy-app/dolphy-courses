# Map и Set

Обычные объекты и массивы не всегда подходят для хранения данных. Объект умеет работать только со строковыми и символьными ключами, а массив не гарантирует уникальность значений. Для таких случаев в язык добавили две коллекции: `Map` — «словарь» с ключами любого типа и `Set` — множество уникальных значений. После урока вы сможете выбирать между объектом, массивом, `Map` и `Set` осознанно и пользоваться их методами и итерацией.

## Map: ключи любого типа

`Map` хранит пары «ключ — значение». В отличие от объекта, ключом может быть что угодно: число, объект, функция, `null`.

```js
const map = new Map();

map.set('a', 1);
map.set(2, 'two');
map.set(true, 'yes');

console.log(map.get(2));    // 'two'
console.log(map.get('2'));  // undefined — число 2 и строка '2' разные ключи
console.log(map.size);      // 3
```

Основные методы:

| Метод | Что делает |
|---|---|
| `new Map([[k, v], ...])` | создаёт коллекцию из итерируемого набора пар |
| `map.set(key, value)` | записывает значение и возвращает саму `map` |
| `map.get(key)` | возвращает значение или `undefined` |
| `map.has(key)` | проверяет наличие ключа |
| `map.delete(key)` | удаляет пару, возвращает `true`, если она была |
| `map.clear()` | очищает коллекцию |
| `map.size` | текущее число пар (это свойство, не метод) |

Поскольку `set` возвращает `map`, вызовы можно соединять в цепочку:

```js
const prices = new Map().set('apple', 10).set('pear', 14).set('plum', 7);
console.log(prices.size); // 3
```

### Объекты как ключи

Главное преимущество `Map` — ключи сравниваются по алгоритму «SameValueZero»: почти как `===`, но `NaN` считается равным `NaN`. Объекты сравниваются по ссылке:

```js
const user = { id: 1 };
const visits = new Map();
visits.set(user, 5);

console.log(visits.get(user));       // 5
console.log(visits.get({ id: 1 }));  // undefined — это другой объект
console.log(new Map([[NaN, 'n']]).get(NaN)); // 'n'
```

Благодаря этому в `Map` удобно хранить служебные данные «про объект», не изменяя сам объект. В обычном объекте ключ-объект превратился бы в строку `"[object Object]"`, и все такие ключи слились бы в один.

### Не путайте `map.set` и `map[key]`

`map['k'] = 1` сработает без ошибки, но создаст обычное свойство объекта `map`, а не запись коллекции:

```js
const map = new Map();
map['k'] = 1;
console.log(map.size);     // 0
console.log(map.get('k')); // undefined
```

Всегда используйте `set`/`get`.

## Перебор Map

Три метода возвращают итераторы: `keys()`, `values()`, `entries()`. Сама `Map` тоже итерируема и по умолчанию отдаёт пары `[key, value]`, как `entries()`. Порядок — **порядок вставки**; повторная запись существующего ключа позицию не меняет.

```js
const stock = new Map([['x', 1], ['y', 2]]);

console.log([...stock.keys()]);   // ['x', 'y']
console.log([...stock.values()]); // [1, 2]

for (const [name, count] of stock) {
  console.log(name, count); // x 1, затем y 2
}

stock.forEach((value, key, map) => {
  console.log(key, value, map === stock); // x 1 true, y 2 true
});
```

Обратите внимание на порядок аргументов в `forEach`: сначала значение, потом ключ — как у массива.

## Превращения между объектом и Map

Для `Map` и объектов есть пара удобных преобразований: `Object.entries` даёт массив пар, а `Object.fromEntries` собирает объект из пар.

```js
const fromObj = new Map(Object.entries({ a: 1, b: 2 }));
console.log(fromObj.get('b')); // 2

const obj = Object.fromEntries(new Map([['x', 1], ['y', 2]]));
console.log(obj); // { x: 1, y: 2 }
```

Если ключи `Map` не строки, при превращении в объект они станут строками (или потеряются при совпадении).

## Set: множество уникальных значений

`Set` хранит значения без повторов. Добавление уже существующего значения ничего не меняет.

```js
const set = new Set([1, 2, 2, 3, 1]);
console.log(set.size);   // 3
console.log([...set]);   // [1, 2, 3]

set.add(2);
console.log(set.size);   // 3
console.log(set.has(3)); // true
set.delete(1);
console.log([...set]);   // [2, 3]
```

Методы: `add(value)` (возвращает сам `Set`), `has`, `delete`, `clear`, свойство `size`. Сравнение — тот же SameValueZero, поэтому `0` и `-0` считаются одним значением, а два разных литерала `[1]` — разными:

```js
console.log(new Set([0, -0]).size);     // 1
console.log(new Set([[1], [1]]).size);  // 2 — разные массивы
```

Классический приём — убрать дубликаты из массива или строки:

```js
const unique = (arr) => [...new Set(arr)];
console.log(unique([3, 1, 3, 2, 1])); // [3, 1, 2]
console.log([...new Set('hello')].join('')); // 'helo'
```

Порядок — тоже порядок первой вставки. Если значение удалить и добавить снова, оно окажется в конце.

### Перебор Set

У `Set` есть `forEach`, `keys()`, `values()`, `entries()`. Для совместимости с `Map` сигнатуры сохранены: `keys` и `values` — одно и то же, `entries` возвращает пары `[value, value]`, а в `forEach` значение приходит дважды.

```js
const set = new Set(['x']);
set.forEach((value, valueAgain) => console.log(value, valueAgain)); // x x
console.log([...set.entries()]); // [['x', 'x']]
console.log(set.keys === set.values); // true
```

## Когда что выбирать

- Нужны записи с фиксированными известными именами полей — объект.
- Нужен упорядоченный список, возможны повторы, важны индексы — массив.
- Ключи нетривиальные (объекты, числа без приведения к строке), частые добавления/удаления, нужен быстрый `size` — `Map`.
- Нужно быстро проверять принадлежность и хранить без дублей — `Set`. Проверка `set.has(x)` в среднем не зависит от размера, в отличие от `array.includes(x)`.

## Типичные ошибки

> [!WARNING]
>
> - Обращение `map.size()` как к методу — это свойство, вызов даст `TypeError`.
> - Ожидание, что `map.get({ id: 1 })` найдёт объект, созданный другим литералом.
> - Запись через `map[key] = value` вместо `map.set`.
> - Ожидание `Set` уникальности «по содержимому» для объектов и массивов — сравнение идёт по ссылке.

## Коротко

> [!TIP]
>
> - `Map` — пары «ключ — значение» с ключами любого типа; сравнение ключей — SameValueZero.
> - Методы: `set`, `get`, `has`, `delete`, `clear`, свойство `size`; `set` возвращает коллекцию, поэтому его можно вызывать цепочкой.
> - Итерация идёт в порядке вставки; по `Map` перебираются пары `[key, value]`.
> - `Object.entries` и `Object.fromEntries` связывают объекты и `Map`.
> - `Set` хранит уникальные значения; `[...new Set(arr)]` убирает дубликаты.
> - Объекты в `Map` и `Set` сравниваются по ссылке.
