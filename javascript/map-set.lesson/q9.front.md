          const result = new Map();
          for (const item of items) {
            const key = keyFn(item);
            if (!result.has(key)) result.set(key, []);

Напишите функцию `groupBy(items, keyFn)`: возвращает `Map`, в котором ключ — результат `keyFn(item)`, значение — массив элементов с этим ключом в исходном порядке. Ключи могут быть любого типа.

```js
groupBy([1, 2, 3, 4, 5], (n) => n % 2);
// Map { 1 => [1, 3, 5], 0 => [2, 4] }
```
